# 快速开始

本指南帮助你完成 FatNotes 的基础设置，并建立第一个知识工作空间。全程大约需要 5 分钟。

## 1. 下载与安装

前往项目的 [GitHub 页面](https://github.com/LazyChun/fat-notes) 查看当前版本与安装说明。

系统要求：Windows 10 及以上版本，需要 WebView2 运行时（Win10/11 一般已自带）。下载安装包后按提示安装即可，无需额外配置环境。

## 2. 创建工作空间

启动 FatNotes 后，选择一个本地目录作为工作空间。工作空间是存放笔记、附件和配置的根目录，所有内容都保存在你自己的电脑上。

建议为不同项目使用独立目录，例如：

```text
D:\notes\            # 日常工作空间
D:\notes-study\      # 学习笔记空间
```

## 3. 创建第一篇笔记

在左侧资源管理区域右键新建 Markdown 文档，输入标题和正文。你可以使用标题、列表、代码块和链接组织内容：

```md
# 我的第一篇 FatNotes 笔记

今天要完成：

- 整理项目资料
- 建立数据看板
- 创建自动化流程
```

保存后内容即时生效。FatNotes 的页面基于「块」构建——除了普通文本，你还可以在页面里插入表格、图表、终端、流程图等 60 多种块类型，自由拖拽排版。

## 4. 三个值得马上尝试的功能

- **按 `Ctrl + K` 打开命令面板**：搜索文件、执行命令、打开 AI 对话都在这里。
- **建一个数据看板**：连接一个 SQLite 数据库，把查询结果变成图表，见[数据看板](../guides/data-dashboard.md)。
- **编排一条自动化流程**：比如输入时间戳一键转成可读时间，见[流程自动化](../guides/flow-automation.md)。
