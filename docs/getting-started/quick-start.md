# 快速开始

本指南帮助你完成 FatNotes 的基础设置，并建立第一个知识工作空间。

## 1. 获取 FatNotes

前往项目的 [GitHub 页面](https://github.com/LazyChun/fat-notes) 查看当前版本与安装说明。安装前请确认系统满足对应版本的要求。

## 2. 创建工作空间

启动 FatNotes 后，选择一个本地目录作为工作空间。建议为不同项目使用独立目录，以便清晰地管理笔记、附件与配置。

## 3. 创建第一篇笔记

在资源管理区域中新建 Markdown 文档，输入标题和正文。你可以使用标题、列表、代码块和链接组织内容。

```md
# 我的第一篇 FatNotes 笔记

今天要完成：

- 整理项目资料
- 建立数据看板
- 创建自动化流程
```

## 4. 探索更多能力

完成第一篇笔记后，可以继续了解：

- [知识工作台](../guides/knowledge-workspace.md)
- [数据看板](../guides/data-dashboard.md)
- [流程自动化](../guides/flow-automation.md)
