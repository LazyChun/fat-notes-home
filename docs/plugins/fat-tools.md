# 工具箱（FatTools）

> 装好 FatTools 后，左侧活动栏会多出一枚**扳手图标**：点开是「左边工具菜单 + 右边一个工具页」的双栏工作台，侧栏顶部写着「共 100 个工具」。文本对比、JSON 格式化、哈希计算、二维码、发票归档……工具内容各不相同，但**用法是同一套**：搜索找到 → 点开 → 输入 → 复制或导出结果 → 自动留下可恢复的操作记录。本文重点讲**怎么用**和**所有工具共用的机制**，工具本身只挑几个代表。

## 一、它是什么：一枚「界面型」工具插件

[热门插件总览](./index.md)里的 FatTools（`fat-tools`，清单名 `Fat Tools`）和[肥・图表](./fat-charts.md)、[肥・Ai基座](./fat-ai-base.md)不太一样：它不往流程画布里加节点，也不给仪表盘加图表，而是**直接贡献一整块界面**——活动栏入口、主侧边栏菜单、工作台整页，以及每个工具各自的路由页。

| 维度 | 说明 |
| --- | --- |
| 工具数量 | 当前版本 **100 个**，按 11 个分类组织；以侧栏「共 N 个工具」为准 |
| 界面贡献 | 活动栏扳手图标、主侧边栏工具菜单、工作台整页、`/tools/<toolId>` 路由页、设置页、全局搜索项 |
| 计算位置 | 绝大多数工具是**纯前端实现**：文本、编码、图片 / PDF 都在本机浏览器里算，文件不上传 |
| 插件后端 | 只用于操作记录（`history.db`）与少数格式转换；不监听业务端口，不参与普通工具的计算 |
| 额外贡献 | 2 个仪表盘块类型、2 个命令、显示配置面板；plugin.json 中 `panel` / `footer` 为 `false` |

![FatTools 在 FatNotes 中的位置](pathname:///fat-notes-home/img/instruction/fatTools/zh/ft-arch.png)

*自上而下：三段式界面 → 工具页的四段结构 → 路由 / 搜索 / 记录等公共机制 → 仪表盘块、命令与设置页等延伸入口。* · <a href="/fat-notes-home/img/instruction/fatTools/zh/ft-arch.png" target="_blank" rel="noopener">查看大图</a>

:::note 界面语言
插件内部的工具名、按钮和提示目前**固定为中文**；宿主菜单、全局搜索等外壳文案跟随应用语言设置。因此本文的英文版配图中，宿主菜单是英文，工具箱内仍是中文。
:::

## 二、打开与使用：三步走

### 2.1 安装、入口与整体布局

在[扩展中心](../guides/extensions.md)安装并启用 `fat-tools` 后，活动栏出现扳手图标。点一下，界面分成三块（下图红框）：左侧细条是**活动栏**，中间是**工具菜单**（搜索框 + 工具卡片），右边是**工具工作区**。插件处于激活状态时会自动隐藏右侧次侧栏与底部面板，给工具页留出更宽的空间。

![工具箱的三段式界面](pathname:///fat-notes-home/img/instruction/fatTools/zh/ft-layout.png)

*红框从左到右：活动栏扳手图标、工具菜单（搜索框 + 卡片列表）、右侧工具页；工具页底部还能看到本工具的历史记录面板。* · <a href="/fat-notes-home/img/instruction/fatTools/zh/ft-layout.png" target="_blank" rel="noopener">查看大图</a>

### 2.2 找到工具：四种方式

100 个工具不需要翻页找。菜单顶部的搜索框会同时匹配**标题、描述、分类和工具 id**，并且支持中文、英文、拼音全拼与拼音首字母：

| 方式 | 操作 | 适合场景 |
| --- | --- | --- |
| 侧栏搜索 | 输入 `json`，得到 JSON 工具、数据格式转换、JSON 转类型等相关卡片 | 只记得关键词或大概用途 |
| 拼音首字母 | 输入 `zstj`，直接命中「字数统计」（zi shu tong ji） | 中文输入法不方便时 |
| 全局搜索直达 | `Ctrl + K` 后直接输入算式、时间戳、JSON 文本、颜色值等 | 内容已经在剪贴板里，想省掉「找工具 + 粘贴」两步 |
| 命令 / 路由 | 命令 `fat-tools.openTool` 传工具 id，或直接访问 `/tools/<toolId>` | 从流程、其它扩展或脚本里跳转 |

![侧栏搜索 json 的相关工具](pathname:///fat-notes-home/img/instruction/fatTools/zh/ft-search.png)

*红框为搜索框与命中的第一张卡片；下方还会列出描述里含 `json` 的其它工具，卡片上的灰色标签就是分类。* · <a href="/fat-notes-home/img/instruction/fatTools/zh/ft-search.png" target="_blank" rel="noopener">查看大图</a>

![拼音首字母 zstj 命中字数统计](pathname:///fat-notes-home/img/instruction/fatTools/zh/ft-search-pinyin.png)

*只输入四个首字母就收敛到唯一结果；拼音全拼（如 `zishutongji`）同样有效。*

更有意思的是**内容直达**：插件给一批工具注册了「输入内容模式」，全局搜索里输入算式 `1+2*3`，会直接列出「计算器」「科学计算器」；点结果不只打开工具，还会把这段文本自动填进输入框。

![全局搜索输入算式直达计算器](pathname:///fat-notes-home/img/instruction/fatTools/zh/ft-global-search.png)

*结果项右侧标着「工具」标签；按 `Enter` 打开，输入内容随工具一起带过去。* · <a href="/fat-notes-home/img/instruction/fatTools/zh/ft-global-search.png" target="_blank" rel="noopener">查看大图</a>

### 2.3 打开与记忆

点任意卡片 → 插件调用 `sdk.router.navigate`，跳到 `/tools/<toolId>`，右侧工作台整页随即渲染对应工具。切换工具不会刷新应用，也不会丢失当前页面；同时这个工具会被记进 `localStorage`，**下次打开工具箱（甚至重启应用）会直接回到上次用的那个工具**。首次使用或记忆失效时，兜底打开工具清单里的第一个工具。

:::tip 工具页显示「正在打开工具箱…」？
这是路由还没落到 `/tools/*` 时的占位。回到活动栏再点一次扳手图标，或在菜单里随便点一张卡片即可恢复；不需要重启插件。
:::

## 三、公共特性：所有工具共用的一套约定

![一次工具使用的完整链路与公共特性速查](pathname:///fat-notes-home/img/instruction/fatTools/zh/ft-common.png)

*「找 → 开 → 算 → 取 → 记 → 复用」六步，100 个工具基本一致；表格里每条都给了可直接复现的例子。* · <a href="/fat-notes-home/img/instruction/fatTools/zh/ft-common.png" target="_blank" rel="noopener">查看大图</a>

### 3.1 工具页的四段结构

绝大多数工具页都由同一组组件拼成：**标题栏 + 操作区**、**输入区**、**结果区**、**历史记录区**。用「JSON 工具」举一次完整流程：把压缩的 JSON 粘进输入框 → 点右上角「格式化」（旁边还能切缩进 2 / 4、点「压缩」）→ 结果区给出「JSON 合法」标记和格式化文本 → 点「复制结果」带走。解析失败时，结果区会指出出错位置附近的文本，而不是只报一句「无效 JSON」。

![JSON 工具的格式化结果](pathname:///fat-notes-home/img/instruction/fatTools/zh/ft-tool-json.png)

*红框分别是右上的「格式化」按钮与结果区上方的「复制结果」；画面底部露出的就是本工具的历史记录面板。* · <a href="/fat-notes-home/img/instruction/fatTools/zh/ft-tool-json.png" target="_blank" rel="noopener">查看大图</a>

| 区域 | 所有工具的共同约定 | 具体表现 |
| --- | --- | --- |
| 标题栏 + 操作区 | 工具名、可选「返回」，右侧放该工具的动作 | 格式化、生成、清空、对比、导出等按钮 |
| 输入区 | 文本域 / 文件上传 / 选项组；部分工具支持从全局搜索带入内容 | 算法多选、缩进、颜色格式、行列数等 |
| 结果区 | 统计行、预览或错误提示，配一键复制 | 复制按钮点击后短暂显示「已复制」；二维码、条形码、格子图可导出 PNG / SVG / ZIP |
| 历史记录区 | 默认展示本工具最近 15 条记录，可刷新 / 收起 / 清空 | 无记录时整块不显示，不占页面空间 |

### 3.2 两种执行模式：输入即算 vs 点按钮

工具之间最大的差别只是「什么时候出结果」：

| 模式 | 触发方式 | 代表工具 | 记录时机 |
| --- | --- | --- | --- |
| **输入即算** | 内容变化后自动计算（如哈希工具停顿约 150 ms 后出结果） | 哈希计算、正则测试、字数统计、颜色转换、进制转换、时间戳转换 | 停止输入约 **1.5 秒**后防抖写入一条，避免逐键刷库 |
| **显式动作** | 填好输入后点按钮才执行 | JSON 格式化 / 压缩、编码解码、密码 / 二维码生成、PDF 合并、发票归档 | 动作成功时立即写入一条 |

「哈希计算」是前者的典型：输入 `FatNotes fat-tools`，勾选 MD5 与 SHA-256，两行结果同时出现，右侧各有复制按钮；上方还能切换「文本哈希 / 文件哈希」，文件模式支持流式分块读取、进度显示与取消。

![哈希计算的实时结果](pathname:///fat-notes-home/img/instruction/fatTools/zh/ft-tool-hash.png)

*红框内为 MD5 与 SHA-256 两行结果；输出格式可切小写 HEX、大写 HEX 或 Base64，还能粘贴已知摘要做比对。* · <a href="/fat-notes-home/img/instruction/fatTools/zh/ft-tool-hash.png" target="_blank" rel="noopener">查看大图</a>

### 3.3 结果、主题与本地性

- **带走结果**：共用复制按钮（1.5 秒成功态）、统计行，以及各工具自己的导出按钮（PNG / SVG / ZIP / CSV）；文本类工具常直接把结果放回只读文本域，方便全选复制。
- **主题**：插件外壳跟随宿主的明暗主题，工具卡片、边框与文字颜色随之切换，不需要单独设置。
- **本地计算**：PDF 合并 / 分割、发票解析、图片拆合等都在浏览器内完成，发票内容不会上传到服务器；这也是「文件」分类敢处理敏感材料的前提。
- **少数联网能力**：DNS 查询（DoH）、汇率在线更新、智能取名（可调用大模型）等会访问网络，其余工具离线可用。
- **语言**：见前文说明，插件内文案固定中文，宿主外壳随应用语言。

## 四、操作记录：所有工具共享的「后悔药」

记录不是某个工具的私货，而是一套插件级机制。多数工具页底部都有统一的面板：**刷新、清空、收起/展开**，每条记录带动作标签、摘要和相对时间；**点一条记录即可把当时的完整输入恢复回输入框**（恢复动作本身不会再产生一条新记录）。

![工具页底部的历史记录面板](pathname:///fat-notes-home/img/instruction/fatTools/zh/ft-history-panel.png)

*红框内是「文本对比」的记录面板：三条历史都可直接点回输入；右侧依次是刷新、清空、收起。* · <a href="/fat-notes-home/img/instruction/fatTools/zh/ft-history-panel.png" target="_blank" rel="noopener">查看大图</a>

想看全局，就打开菜单里的「**操作记录**」工具：它显示全部工具的记录总数、数据库文件路径，可按工具过滤、刷新、清空，点任意一条还会跳回对应工具。

![操作记录工具：全库统计与记录列表](pathname:///fat-notes-home/img/instruction/fatTools/zh/ft-history-tool.png)

*顶部是记录总数与 `history.db` 路径，右上可按工具过滤；列表按时间倒序，标签区分计算、格式化、编码等动作。* · <a href="/fat-notes-home/img/instruction/fatTools/zh/ft-history-tool.png" target="_blank" rel="noopener">查看大图</a>

| 机制 | 行为 |
| --- | --- |
| 落库位置 | 工作区下的 `fatTools/history.db`，由插件 Python 后端用标准库 `sqlite3` 维护 |
| 后端接口 | `history.add` / `history.list` / `history.clear` / `history.stats` / `history.dbPath` |
| 保留策略 | 每个工具只保留最近 **500 条**，字段过长会自动截断 |
| 降级 | 后端不可用时自动改用浏览器 `localStorage`（最多 200 条），工具功能不受影响 |
| 防抖 | 「输入即算」类工具停顿 1.5 秒后才落库，避免逐键产生垃圾记录 |
| 恢复 | 多数记录会保存当时的输入值，点击即回填；从历史恢复不会再写一条 |

:::caution 记录会保存输入内容
历史记录包含你粘贴的文本、算式、JSON 等内容。处理密码、身份证号、合同片段之后，建议随手在工具页面板或「操作记录」里清空对应记录。记录只存在本机（数据库或浏览器本地存储），**不会跨设备同步**；换一台电脑或清理工作区后，历史不会跟过去。
:::

## 六、进阶：把工具带出工具箱

工具不只存在于工具箱里。插件还注册了两个**仪表盘块类型**，可以像普通组件一样拖到看板页面上：

| 块类型 | 分类 / 默认尺寸 | 用途 | 私有配置 |
| --- | --- | --- | --- |
| `fat-tools.calcCard`（计算器） | `tools` / 4×10 | 看板上放一个迷你计算器 | 无，不查询数据源（`dataConfig: false`） |
| `fat-tools.toolSwitcher`（工具） | `other` / 6×24 | 一张卡片内切换多个常用工具 | 见下表；自带「显示配置」面板 |

`fat-tools.toolSwitcher` 的私有配置写在 `options.toolSwitcher`：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `tools` | `calculator`、`json`、`timestamp`、`uuid` | 可切换的工具 id 列表 |
| `defaultTool` | `calculator` | 打开卡片时默认展示的工具 |
| `showSwitch` | `true` | 是否显示切换控件 |
| `switchStyle` | `segmented` | `segmented` 按钮组或 `select` 下拉框 |
| `switchPosition` | `top` | 切换控件放在 `top` 或 `bottom` |

另外还有三个不显眼但好用的入口：命令 `fat-tools.openTool(toolId)`（从流程或其它扩展里直达工具）、`fat-tools.ping`（自检插件是否加载），以及设置页里列出的**全部工具名称与对应路由**。给插件开发者：这套「活动栏 + 主侧边栏 + 工作台整页」的布局由 `registerActivityBarItem`、`registerPrimarySidebar`、`registerWorkbenchPage` 三个贡献点组成，活动栏项 id 必须与工作台页 id 一致，详见[插件开发](../plugin-dev/index.md)。

## 七、常见问题与边界

| 现象 | 优先检查 |
| --- | --- |
| 活动栏没有扳手图标 | 插件是否已在[扩展中心](../guides/extensions.md)安装并启用；未启用时菜单与工作台页都不会注册 |
| 右侧一直显示「正在打开工具箱…」 | 当前路由不属于 `/tools/*`，重扳手或点一张卡片即可 |
| 搜索不到某个工具 | 换个关键词：中文名、工具 id、拼音全拼或首字母；搜索会同时匹配标题 / 描述 / 分类 |
| 输入即算的工具没留下记录 | 它有 1.5 秒防抖，停止输入后才落库；另外无记录时历史面板整块隐藏 |
| 复制按钮没反应 | 浏览器剪贴板权限；插件会自动回退到临时文本域复制，仍失败时手动全选结果区文本 |
| 文件类工具处理很慢 | 大 PDF / 图片在浏览器内解析，取决于本机性能；文件不会上传，也不消耗服务端资源 |
| 换电脑后历史没了 | 记录只在本机 `history.db` 或浏览器本地存储中，没有云同步 |
| 英文界面里工具名还是中文 | 符合预期：插件内文案目前固定中文，宿主外壳跟随应用语言 |

最后几条边界值得记住：

- **它是界面插件，不是数据源插件**：工具不与书籍、数据表或仪表盘查询绑定，普通工具页不需要配置数据源。
- **后端不是计算引擎**：插件清单虽启用 Python 后端，但主要服务操作记录与少量格式转换；卸载 / 后端不可用时，多数工具仍然能用，只是记录降级到浏览器存储。
- **记录属于本机**：包含输入内容，敏感操作后随手清空；工作区备份时也会一并带上 `fatTools/history.db`。
- **版本差异**：工具数量、分类与部分按钮文案可能随插件版本调整，以当前安装版本的界面为准。
