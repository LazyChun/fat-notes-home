# 肥图（FatPhoto）

![FatPhoto 可完成的图像编辑效果示例](pathname:///fat-notes-home/img/instruction/fatPhoto/zh/fp-example.jpg)

*示例：一张在图像编辑器中制作 / 编辑的扁平风格插画（卡通猪在电脑前打字），代表 FatPhoto 所支持的创作与编辑效果；图中可见工具栏、图层、属性、历史记录与状态栏等典型布局。* · <a href="/fat-notes-home/img/instruction/fatPhoto/zh/fp-example.jpg" target="_blank" rel="noopener">查看大图</a>

> 肥图是 FatNotes 的**内置 Canvas 图片编辑器**插件（`fat-photo`）。它把一整块「图片处理工作台」搬进笔记里：左侧工具条 + 图层面板 + 历史记录，中间是带棋盘格画布的多标签编辑区，右侧是随图层类型变化的属性面板，底部是状态栏。从随手裁剪一张截图，到用画笔、文字、形状拼贴海报，再到导出 PNG / JPEG / WebP / SVG，都可以在这里完成，工程还能存成可再次编辑的 `.fpproj` 文件。

## 一、它是什么：一块「图片处理工作台」

[热门插件总览](./index.md)里的肥图（`fat-photo`）和[肥图表](./fat-charts.md)、[工具箱](./fat-tools.md)不同：它不往流程里加节点，也不给仪表盘加图表，而是**直接贡献一整块图片编辑界面**——活动栏的图片图标、主侧边栏、工作台整页，以及自己的文件与导出流程。

| 维度 | 说明 |
| --- | --- |
| 界面贡献 | 活动栏图片图标、主侧边栏（工具条 + 图层 + 历史）、工作台整页、底部状态栏 |
| 文档模型 | **多标签文档**：每个标签是一张图（或一份工程），可同时打开多张、独立编辑 |
| 图层系统 | 像素 / 文字 / 形状三类图层；支持不透明度、**混合模式**、拖拽排序、显隐与锁定 |
| 工具集 | 移动、抓手、裁剪、画笔、橡皮、油漆桶、文字、7 种形状、吸管 / 颜色取样器 / 标尺、仿制图章、3 种套索、对象选择 / 快速选择 / 魔棒 |
| 调整与色彩 | 亮度 / 对比度 / 饱和度 / 色温，前景 / 背景色；调整可「烘焙到像素」 |
| 历史记录 | 逐步快照，可撤销 / 重做 / 任意跳转（最多保留 40 步） |
| 文件 | 打开图片 / 导入为新图层 / 新建空白文档 / 保存 `.fpproj` 工程 / 导出 PNG·JPEG·WebP·SVG |
| 后端 | `backend/main.py`（`depsStrategy: vendor`），用于工程文件的本地持久化与体积较大的依赖 |

![肥图编辑器总览](pathname:///fat-notes-home/img/instruction/fatPhoto/zh/fp-overview.png)

*红框自上而下：左侧工具条 + 图层面板 + 历史记录；中间多标签画布（已绘制矩形 / 椭圆 / 星形 / 文字）；右侧随文字图层切换的属性面板；底部状态栏。* · <a href="/fat-notes-home/img/instruction/fatPhoto/zh/fp-overview.png" target="_blank" rel="noopener">查看大图</a>

:::note 界面语言
插件内部的工具名、面板标题（图层、历史记录、属性等）目前**固定为中文**；宿主的菜单、全局搜索等外壳文案跟随应用语言设置。因此英文版文档里配图仍是中文界面。
:::

## 二、界面布局：三栏 + 标签 + 状态栏

进入肥图后，界面被清晰地切成几块：

- **主侧边栏（最左）**：顶部一条水平**工具条**（含工具组按钮），往下是**图层面板**，再往下是可拖拽分隔的**历史记录面板**。
- **中间工作区**：顶部是**标签栏**（打开的图片各占一个标签，带 `*` 表示未保存），其下是随工具切换的**上下文工具栏**，主体是带棋盘格背景的**画布**。
- **右侧属性面板**：根据当前图层类型显示不同内容——文字、形状或普通像素图层。
- **底部状态栏**：左显示就绪状态与当前工具名，中显示画布尺寸与光标坐标，右显示缩放比例、色彩模式与图层数。

![左侧栏：工具条 / 图层 / 历史](pathname:///fat-notes-home/img/instruction/fatPhoto/zh/fp-leftsidebar.png)

*主侧边栏三段：工具条（图标）、图层面板（新建 / 复制 / 删除 + 不透明度 + 混合模式下拉）、历史记录（按步骤列出，当前步高亮）。* · <a href="/fat-notes-home/img/instruction/fatPhoto/zh/fp-leftsidebar.png" target="_blank" rel="noopener">查看大图</a>

![底部状态栏](pathname:///fat-notes-home/img/instruction/fatPhoto/zh/fp-statusbar.png)

*状态栏示例：就绪 / 文字工具 · 128 × 80 px · 100% · RGB / 8bit · 5 图层。*

## 三、工具箱详解

工具按「组」排布：同一组共享工具条上的一个按钮位，长按 / 右键 / 点右下小箭头会弹出同组其它工具；按对应快捷键也可在组内循环切换。完整清单：

| 工具 | 快捷键 | 作用 |
| --- | --- | --- |
| 移动工具 | `V` | 拖动当前图层；空格 / 中键 / 抓手平移视图，滚轮缩放 |
| 抓手工具 | `H` | 平移画布，滚轮缩放 |
| 裁剪工具 | `C` | 拖动选区手柄框定范围，点「应用裁剪」裁掉外部 |
| 画笔工具 | `B` | 软笔刷（大小 / 硬度 / 不透明度 / 流量 / 模式），笔尖实时预览 |
| 橡皮擦 | `E` | 与画笔同参数，直接擦除当前图层像素 |
| 油漆桶 | `G` | 按颜色容差填充区域（连续 / 所有图层 / 不透明度） |
| 文字工具 | `T` | 画布内就地编辑；`Ctrl+Enter` 或失焦提交，`Esc` 取消 |
| 形状组（矩形 / 椭圆 / 圆形 / 三角形 / 多边形 / 星形 / 直线） | `U` | 拖动绘制，可切换填充；多边形 / 星形可调边数（3–12） |
| 吸管组（吸管 / 颜色取样器 / 标尺） | `I` | 吸管拾取前景色；取样器放最多 4 个监测点；标尺量距离 / 角度 / 宽高 |
| 仿制图章 | `S` | `Alt+点击`设源点后拖动仿制；支持大小 / 硬度 / 不透明度 / 流量 / 对齐 / 所有图层取样 |
| 套索组（套索 / 多边形套索 / 磁性套索） | `L` | 自由轨迹、逐点、或沿边缘自动吸附取点 |
| 对象选择组（对象选择 / 快速选择 / 魔棒） | `W` | 矩形 / 自由套索框选、笔刷涂抹加选、同色区域泛洪选择 |

:::tip 快捷键循环
同一组的工具**重复按同一个键会循环切换**：例如连续按 `U` 会在 矩形 → 椭圆 → 圆形 → 三角形 → 多边形 → 星形 → 直线 之间轮转；`L`、`W`、`I` 同理。
:::

选中不同工具时，中间工作区上方的**上下文工具栏**会显示对应参数。例如画笔会显示大小 / 硬度 / 不透明度 / 流量 / 模式：

![画笔工具的上下文工具栏](pathname:///fat-notes-home/img/instruction/fatPhoto/zh/fp-toolbar.png)

*画笔 / 橡皮激活时的工具栏：大小、硬度、不透明度、流量，画笔另含「模式」下拉（正常 / 变暗 / 变亮 / 色相 / 饱和度 / 颜色 / 明度）。*

## 四、图层系统

肥图的图层分三类，决定了它能「改到什么程度」：

- **像素图层**：普通位图，画笔、橡皮、油漆桶直接作用其上。
- **文字图层**：可二次编辑——双击图层面板里的文字图层即可重新输入、改字号 / 字体 / 颜色，无需重画。
- **形状图层**：矩形 / 椭圆 / 圆 / 三角形 / 多边形 / 星形 / 直线，可重新编辑几何与描边 / 填充 / 颜色。

图层面板支持：新建、复制、删除、拖拽排序、**显隐**（眼睛图标）、**锁定**（锁图标）、**不透明度**滑杆，以及 **5 种混合模式**（正常 / 正片叠底 / 滤色 / 叠加 / 柔光）。

![随图层类型变化的属性面板](pathname:///fat-notes-home/img/instruction/fatPhoto/zh/fp-rightsidebar.png)

*选中文字图层时，右侧属性面板显示「文本」（字体 / 字号 / 样式 / 颜色 + RGB·HSL）与「变换」「信息」；选中普通图层还会多出「调整」「色彩」。*

## 五、属性面板（随图层变化）

右侧面板是上下文敏感的，按当前图层类型分节：

**文本图层** — 字体（内置系统默认 / 宋体 / 黑体 / 微软雅黑 / 楷体等 29 款，含中文与西文）、字号（8–200px）、样式（粗体 / 斜体 / 下划线 / 删除线）、颜色（拾色器 + 十六进制，实时显示 RGB 与 HSL）。

**形状图层** — 类型切换、多边形 / 星形的**边数**（3–12）、描边粗细（1–100px）、是否填充、颜色。

**普通像素图层** — 四组：
- **变换**：X / Y / 宽 / 高 / 旋转（带锁定比例）；
- **调整**：亮度 / 对比度 / 饱和度 / 色温（−100~+100），可「应用到像素」烘焙；
- **色彩**：前景 / 背景色（可交换）、RGB 与 HSL 读数；
- **信息**：文件、尺寸、图层数、历史步数、色彩模式、原始大小。

## 六、选区工具

肥图提供完整的选区能力，且都支持**修饰键组合**：`Shift` 添加、`Alt` 减去、`Shift+Alt` 取交集；并可在工具栏一键**全选 / 取消 / 反选**（`Ctrl+A` / `Ctrl+D` / `Ctrl+Shift+I`）。

| 工具 | 行为 |
| --- | --- |
| 套索 | 自由拖拽轨迹，松开自动闭合 |
| 多边形套索 | 逐点单击，双击 / `Enter` / 回到起点闭合，`Backspace` 删上一点 |
| 磁性套索 | 拖拽时沿边缘自动吸附取点，可调宽度 / 对比度 / 频率 |
| 对象选择 | 矩形或自由套索框选（可切「套索模式」） |
| 快速选择 | 笔刷涂抹添加选区，可调笔刷大小 |
| 魔棒 | 点击同色区域泛洪选择，可调容差与「连续」 |

![对象选择工具画出的矩形选区（蚂蚁线）](pathname:///fat-notes-home/img/instruction/fatPhoto/zh/fp-selection.png)

*对象选择工具拖出的矩形选区以蚂蚁线（marching ants）显示，选区外有半透明蓝色蒙版。*

## 七、调整、历史与文件

**调整**：在属性面板「调整」里拖动亮度 / 对比度 / 饱和度 / 色温，效果实时预览；满意后点「应用到像素」把调整烘焙进背景层，或「重置」清零。

**历史记录**：每一次操作（新建图层、绘制形状、移动、调整……）都会写入左侧历史面板。点击任意一步可**跳回当时状态**，撤销 / 重做按钮（`Ctrl+Z` / `Ctrl+Shift+Z`）亦可用，最多保留 40 步。

**文件操作**（标签栏右侧按钮）：

- **打开图片**：从本地选择一张或多张图片，各自成为新标签。
- **打开工程（`.fpproj`）**：重建含图层 / 历史 / 选区的完整工程；普通图片则走打开流程。
- **导入为新图层**：把图片加进当前文档（也支持拖拽或 `Ctrl+V` 粘贴）。
- **新建空白文档**：默认 1920×1280 的空白画布。
- **保存工程**：存成 `.fpproj`（含图层像素、调整、完整历史、选区，等价 PSD）；`Ctrl+S` 有句柄时静默直写原位置。
- **导出**：PNG / JPEG / WebP / SVG，弹出系统保存对话框选择格式与文件名。
