# 肥图表（FatCharts）

> 肥图表是一枚**给数据看板补图表块**的扩展插件。装好之后，组件面板的「图表」分类里会多出 6 种卡片；它们本身不存数据，只负责把**查询结果**画成可配置的图形。本文只讲这 6 种卡片**怎么取数、怎么配置**；标题、外框、关联标签、浮层、图例等所有卡片共用的设置见[公共配置](../guides/system-components/common-config.md)，不再重复。

## 一、插件提供了什么

在[扩展中心](../guides/extensions.md)安装并启用 `fat-charts` 后，打开页面右上角的「组件」面板，展开 **图表** 分类。红框圈出的 6 个就是插件追加的图表块，其余（折线图、列表、饼图、K线、雷达、热力图）是应用内置的：

![组件面板的图表分类，红框标出 6 个扩展图表块](pathname:///fat-notes-home/img/instruction/fatCharts/zh/fc-panel.png)

*「时序图 / 数值 / 分布 / 排行 / 蜂窝 / 仪表」与内置块交错排列，按索引顺序为：时序图 → 数值 → 列表 → 分布 → 饼图 → 排行 → 蜂窝 → 仪表 → K线 → 雷达 → 热力图。* · <a href="/fat-notes-home/img/instruction/fatCharts/zh/fc-panel.png" target="_blank" rel="noopener">查看大图</a>

| 卡片 | 类型标识 | 回答什么问题 | 默认尺寸（列 × 行） |
| --- | --- | --- | --- |
| **时序图** | `fat-charts.trend` | 指标随时间怎么变，多系列怎么比 | 8 × 32 |
| **数值** | `fat-charts.number` | 当前这个数是多少 | 4 × 20 |
| **分布** | `fat-charts.distribution` | 数值落在哪些区间、各有多少 | 8 × 32 |
| **排行** | `fat-charts.rank` | 谁排前几名、差多少 | 8 × 32 |
| **蜂窝** | `fat-charts.honey` | 很多对象各自是什么状态 | 8 × 32 |
| **仪表** | `fat-charts.dial` | 当前值离上限还有多远 | 8 × 32 |

把 6 类卡片放在同一张画布上，就是下面这张示例页（前四行即插件的 6 种块，最后一行是内置图表）：

![六类扩展图表块同屏的示例看板](pathname:///fat-notes-home/img/instruction/fatCharts/zh/fc-overview.png)

*自上而下：数值卡、时序图（折线 / 柱状 / 面积）、排行卡（文字 / 条形 / 柱状）、分布 / 蜂窝 / 仪表。所有卡片取自同一份演示订单数据，只因「显示配置」不同而呈现完全不同的图形。* · <a href="/fat-notes-home/img/instruction/fatCharts/zh/fc-overview.png" target="_blank" rel="noopener">查看大图</a>

:::info 与内置图表块的关系
插件不是替换内置图表，而是**补充**：内置折线图、饼图、列表、K线、雷达、热力图仍在，配置方式见[系统组件 · 图表](../guides/system-components/chart.md)。时序图走轻量时序渲染（uPlot），分布 / 排行 / 仪表基于 ECharts，蜂窝为自绘六边形；因此同一份数据可以同时喂给两种图，互不干扰。
:::

## 二、先取数，后绘图

6 种卡片共用同一套**数据查询配置**，位于配置抽屉左下方。配置抽屉分三块：顶部是**时间范围**与「运行 / 保存」，左下是**查询**，右侧是**显示配置**（本文的重点）。

![配置抽屉左下角的查询区](pathname:///fat-notes-home/img/instruction/fatCharts/zh/fc-config-query.png)

*一条查询项就是一条取数逻辑，按 `A / B / C` 编号；可切换「指标查询 / 数据表查询」、设置过滤与选项，也可添加「表达式」对已有查询做二次计算。*

| 概念 | 在哪里配 | 说明 |
| --- | --- | --- |
| 查询项 | 「查询」区，点 `+ 查询` 或 `+ 表达式` | 每条查询生成一个系列 / 一组数据，用 `A / B / C` 标识。插件按查询项生成序列样式、值颜色映射等配置行。 |
| 数据源与数据项 | 查询项第一行 | 选数据源（dbSource）与数据表 / 指标（dsTableId）。没有配好时卡片显示「暂无数据」。 |
| 指标查询 `metric` | 查询模式切换 | 按时间轴聚合：指标、聚合函数（求和 / 平均 / 最大 / 最小 / 计数）、过滤条件、最小步长、查询类型 Range / Instant。适合趋势、监控。 |
| 数据表查询 `table` | 查询模式切换 | 按类别取值：**名称项**（X 轴 / 类别）、**值项**、聚合方式、排序、行数上限。适合排行、分布、蜂窝、仪表。 |
| 表达式 | `+ 表达式` | 用 `A + B` 之类对已有查询项做二次计算，不必回数据源改表。 |
| 时间范围 | 抽屉顶部 | 支持「今年 / 最近 N 天 / 自定义区间」。改完先点**运行**重查预览，确认后点**保存**才写入页面。 |
| 数据格式 | 右侧「数据格式」分组 | 小数精度、数值单位换算、每个查询项的显示名与颜色，由宿主统一提供，属于通用设置，本文不展开。 |

:::tip 三条最常见的「暂无数据」原因
1. 查询项里数据源或数据项为空；过滤条件把数据全滤掉了。
2. 时间范围没有覆盖数据（例如数据只到上个月，却选了「今天」）。
3. 数据表查询没填**名称项 / 值项**，或行数上限设成了 0。

先检查左下方「查询」，再去右侧调样式；样式改得再漂亮也变不出数据。
:::

:::caution 名称项尽量用时间列
查询引擎会**按时间轴合并多个数据帧**。若把纯类别列（如商品名、渠道）当作名称项，跨帧合并时标签可能变成 `Invalid Date` 或 `NaN`。趋势、分布、蜂窝这类按帧取数的卡片，建议用时间列做名称项；确实要按类别展示时，用「数据表查询」并限制在一帧内。
:::

## 三、六张卡片共用的两条规则

### 1. 值颜色映射：按规则给数值上色

数值、分布、排行、蜂窝、仪表 5 种卡片在配置抽屉里都有「**值颜色映射**」分组，时序图则用「序列样式」实现类似能力。它是一份**自上而下匹配**的规则列表：

| 规则字段 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 操作符 | 默认、等于、不等于、大于、小于、大于等于、小于等于、包含、不包含；新增规则默认「大于」 | 「默认」不需要比较值，作为兜底规则，通常保留在最后。 |
| 比较值 | 数值或文本 | 与操作符搭配，例如「大于 1000」。 |
| 背景色 / 字体色 | 颜色值；默认蓝底白字 | 命中规则后应用于该数值、柱子、格子或表盘色段。 |
| 展示值 | 文本 | 可选：把原始值替换成更易读的文字（如「达标」「告警」）。 |
| 添加规则 / 删除 | 按钮 | 规则按顺序匹配，命中即停；新建卡片自带一条「默认」规则。 |

![数值卡配置里的「值颜色映射」规则](pathname:///fat-notes-home/img/instruction/fatCharts/zh/fc-config-number.png)

*图中「文本前缀」「值颜色映射」均已展开：一条默认规则包含操作符、背景色、字体色、展示值与「添加规则」按钮。*

### 2. 点击联动：卡片能驱动别的卡片

插件注册时给每种卡片绑定了触发方式与可选动作；在块配置的「动作」里选用即可（联动配置本身属通用能力）：

| 卡片 | 触发方式 | 可用动作 |
| --- | --- | --- |
| 时序图 | 点击数据点、点击折线 | 联动、下钻、更新、过滤、跳转（最完整） |
| 数值 / 分布 | 点击卡片 | 联动、跳转 |
| 排行 | 点击行 | 联动、跳转 |
| 蜂窝 | 点击格子 | 联动、跳转 |
| 仪表 | 点击表盘 | 联动、跳转 |

## 四、逐块详解

下面每节都给出**单独的效果图**、**配置抽屉里的私有分组**和完整的私有配置表。标题、外框、关联标签、浮层、图例等公共项不再列出。

### 4.1 时序图 `fat-charts.trend`

**做什么**：把一条或多条查询按时间轴画成折线、面积、柱状、虚线或散点，适合看趋势、比高低、盯异常。它是 6 个块里配置项最多的一个。

![时序图显示效果：每日销售额折线](pathname:///fat-notes-home/img/instruction/fatCharts/zh/fc-block-trend.png)

*X 轴为日期、Y 轴为金额，底部图例来自查询项；同一张图可叠加多条查询。*

![时序图的私有配置：样式与右 Y 轴](pathname:///fat-notes-home/img/instruction/fatCharts/zh/fc-config-trend.png)

*「样式」「右Y轴」默认展开；「标记」「区域填充」「序列样式」是三个折叠的私有分组，需要时点左侧箭头展开。*

**样式**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 展示 | 折线图 / 面积图 / 柱状图 / 散点图 / 虚线；默认 `折线图` | 决定整张图的绘制方式。柱状适合离散对比，面积强调累积量，散点只看分布。 |
| 色彩 | 经典 / 冷峻 / 热烈；默认 `经典` | 一次性切换整套系列配色；单系列要精确控色请改用「序列样式 · 自定义颜色」。 |
| 折线 | 默认（折角） / 平滑 / 阶梯；默认 `默认` | 仅在折线、面积、虚线模式下出现。阶梯适合表现档位式变化。 |

**右 Y 轴**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 是否开启 | 开 / 关；默认 `关` | 显示右侧第二根 Y 轴。 |
| 指标 | 多选查询项 `A / B / C` | 被选中的查询按右轴刻度绘制，用来把金额与件数这类量纲差异大的指标放进同一张图。 |

**标记**（折叠分组）

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 类型 / 标记值 | 横线 / 竖线 + 数值 | 横线标阈值（如目标线），竖线标时间点。 |
| 颜色 / 线型 / 加粗 | 颜色、实线 / 虚线、`B` 按钮 | 让参考线在密集曲线里仍然醒目。 |
| 标记名称 | 勾选后输入自定义文本 | 在线旁显示「目标值」「大促开始」等说明。 |

**区域填充**（折叠分组）

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| Y 轴范围 / X 轴范围 | 最小值、最大值；X 轴可用「时间」或「数值」两种输入 | 圈定一块矩形区域，突出异常区间或活动周期。 |
| 填充颜色 / 折线颜色 / 透明度 | 颜色、0–1 | 可只填色、只改区间内折线颜色，或两者都开（至少保留一项）。 |

**序列样式**（折叠分组，按查询项逐条设置）

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 图表类型 | 五种图形，留空则继承全局「展示」 | 让 A 查询画柱、B 查询画线，做组合图。 |
| 线宽 / 点宽 | 0–100，常用 1 / 2 / 4 / 6 / 8 / 10 | 散点模式下这一项控制点半径。 |
| 主题色 / 自定义颜色 | 经典 / 冷峻 / 热烈；任意颜色值 | **自定义颜色优先于主题色**，是多系列精确配色的推荐做法。 |
| 折线类型 / 面积透明度 / 填充色 | 默认 / 平滑 / 阶梯；0–1；颜色值 | 面积模式下调低透明度可避免多条面积互相遮挡。 |

> **提示**：序列样式与查询项一一对应；增删查询后列表会自动同步。查询项别名不会被当作出图标签，图例文字来自「数据格式」里的显示名设置。

### 4.2 数值 `fat-charts.number`

**做什么**：用大号数字显示一个或一组当前值，是驾驶舱顶部的 KPI 行。多个查询项时会并排显示多个数值。

![数值卡显示效果：销售额大数字](pathname:///fat-notes-home/img/instruction/fatCharts/zh/fc-block-number.png)

*标题下方是指标名，中间是大号数值；颜色来自「值颜色映射」的默认规则。*

![数值卡的私有配置：文本前缀与值颜色映射](pathname:///fat-notes-home/img/instruction/fatCharts/zh/fc-config-number.png)

*「样式」里只有「展示」，其余私有项在「文本前缀」「值颜色映射」两个折叠分组里。*

**样式 / 文本前缀 / 值颜色映射**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 展示 | 基础数值 / 背景趋势图 / 趋势图；默认 `基础数值` | 后两种会在数字旁 / 背后再画一条走势线，需要查询按时间轴返回多帧数据。 |
| 前缀文本 | 任意文本；默认空 | 数字前的说明，如 `¥`、`今日`。 |
| 方位 | 上方 / 左侧；默认 `上方` | 前缀相对数字的位置。 |
| 颜色 | 自动 / 自定义；默认 `自动` | 选「自定义」后出现取色器，可单独指定前缀文字颜色。 |
| 值颜色映射 | 规则列表；默认一条「默认」规则 | 见上一节「值颜色映射」；可把超额、告警等区间染成不同颜色。 |

> **提示**：卡片默认高 20 行，若把高度压得太矮，数字会被裁切；趋势类展示在部分版本里对数据帧要求较高，看不到小图时先切回「基础数值」并检查查询是否含时间列。

### 4.3 分布 `fat-charts.distribution`

**做什么**：把查询返回的一批数值划成区间，统计每个区间里有几个值（或占百分之几），用直方图看数据集中在哪。

![分布卡显示效果：每日销售额区间直方图](pathname:///fat-notes-home/img/instruction/fatCharts/zh/fc-block-distribution.png)

*X 轴是区间边界，Y 轴默认显示区间内的个数；示例里销售额集中在低区间。*

![分布卡的私有配置：分布区间与值颜色映射](pathname:///fat-notes-home/img/instruction/fatCharts/zh/fc-config-distribution.png)

*「样式」里是 Y 轴含义与标签开关，「分布区间」决定怎么分桶。*

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| Y 轴含义 | 分布数值（个数） / 分布占比；默认 `分布数值` | 占比模式把每根柱换算成百分比，便于比较不同样本量。 |
| 展示标签 | 开 / 关；默认 `关` | 开启后可选标签位置：内部 / 外部 / 上方 / 下方。柱子多时建议关闭。 |
| 区间类型 | 自动 / 自定义；默认 `自动` | 自动按数值范围均分；自定义用一串分隔值手工切分。 |
| 均分等分 | 1–20；默认 `5` | 仅在「自动」下出现，决定分成几段。 |
| 区间 | 分隔值列表，可增删 | 仅在「自定义」下出现；填 `100, 500, 1000` 即得到四段区间。 |
| 值颜色映射 | 规则列表；默认一条「默认」规则 | 让不同区间的柱子按规则着色。 |

> **提示**：分桶对象是**查询返回的结果值**（例如每天的销售额），不是原始明细行；想改变样本量，先改查询的聚合、排序与行数上限。

### 4.4 排行 `fat-charts.rank`

**做什么**：按指标把条目排成名次，可显示为文字榜单、横向条形或竖向柱状。

![排行卡显示效果：横向条形排行](pathname:///fat-notes-home/img/instruction/fatCharts/zh/fc-block-rank.png)

*左侧是名称，条形长度代表数值；图中名称带时间前缀，是「数据表查询」的名称项用了时间列的缘故。*

![排行卡的另一种形态：竖向柱状](pathname:///fat-notes-home/img/instruction/fatCharts/zh/fc-block-rank-vbar.png)

![排行卡的私有配置：展示与值颜色映射](pathname:///fat-notes-home/img/instruction/fatCharts/zh/fc-config-rank.png)

*「样式」里的「展示」决定三种形态；切换成条形 / 柱状后才会多出「Y轴」设置。*

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 展示 | 文字 / 条形图 / 柱状图；默认 `文字` | 文字榜适合长名称，条形适合比大小，柱状适合看分布。 |
| Y 轴 | 左侧 / 右侧；默认 `左侧` | 仅条形 / 柱状模式出现，控制名称标签在左还是在右。 |
| 值颜色映射 | 规则列表；默认一条「默认」规则 | 可把前三名、超标项单独染色；文字榜下作用于文字底色。 |

> **提示**：谁排第一、显示几条，**不是卡片配置决定的**，而是查询里的排序（`orderBy`）与行数上限（`limit`）。名称项尽量用短类别列，像示例里带完整时间戳的名称会把条形标签撑得很长。

### 4.5 蜂窝 `fat-charts.honey`

**做什么**：把很多对象画成六边形格子，用颜色深浅表示数值大小，一眼扫出「哪个高、哪个低」。

![蜂窝卡显示效果：每日订单量蜂窝图](pathname:///fat-notes-home/img/instruction/fatCharts/zh/fc-block-honey.png)

*每格对应一个查询结果，颜色越深数值越大；左下角是数值到颜色的视觉映射图例。*

![蜂窝卡的私有配置：染色项、排序与颜色](pathname:///fat-notes-home/img/instruction/fatCharts/zh/fc-config-honey.png)

*「样式」里选染色项与排序，「颜色」分组默认展开，可切换渐变 / 自定义。*

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 染色项 | 查询项 `A / B / C`；默认第一条 | 决定**用哪个查询的数值给格子上色**。多查询时必须选一个，否则格子可能全部同色。 |
| 排序 | 由大到小 / 由小到大；默认 `由大到小` | 格子的排列顺序，只影响位置，不影响数值。 |
| 展示维度值 | 开 / 关；默认 `开` | 是否在格子内显示维度文字；格子多或文字长时建议关闭。 |
| 渐变区间 | 自动 / 自定义；默认 `自动` | 自动按数值范围生成色阶；自定义改用「值颜色映射」里的规则分段。 |
| 渐变色系 | 预置色板（如蓝色、紫色） | 一键切换整套色阶。 |
| 颜色翻转 | 开 / 关；默认 `关` | 反转深浅方向，让「数值越大越浅」也能表达。 |
| 值颜色映射 | 规则列表 | 「自定义」模式下按规则给不同数值区间指定颜色。 |

> **提示**：格子数量由查询的行数上限决定；染色项在卡片数据里对应 `commonOptions.coloration`，用脚本或 AI 建卡时记得把它指向某个查询项的 id，否则蜂窝会退化成一片同色。

### 4.6 仪表 `fat-charts.dial`

**做什么**：用刻度盘显示一个当前值落在量程的哪个位置，适合完成率、温度、负载这类有明确上下限的指标。

![仪表卡显示效果：速度表形态](pathname:///fat-notes-home/img/instruction/fatCharts/zh/fc-block-dial.png)

*绿色圆弧表示当前进度，表盘中央是指标名与当前值。*

![仪表卡的私有配置：范围与值颜色映射](pathname:///fat-notes-home/img/instruction/fatCharts/zh/fc-config-dial.png)

*「范围」分组里设置量程，「值颜色映射」决定色段颜色。*

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 展示 | 速度表 / 阶段速度 / 基础；默认 `速度表` | 速度表是完整圆弧；阶段速度按分段着色；基础是简化表盘。 |
| 最小值 / 最大值 | 数值；默认 `0 / 100` | 指针位置按 `（当前值 - 最小值）/（最大值 - 最小值）` 计算，超出量程会被夹在边界。 |
| 值颜色映射 | 规则列表；默认一条「默认」规则 | 规则会收成表盘上的色段，例如「小于 30 红、30–70 黄、大于 70 绿」。 |

> **提示**：仪表建议只绑**一条查询**，且查询返回一个聚合值。卡片高度建议不小于 30 行，太矮时「阶段速度」「基础」两种形态会退化成简单指针；要展示分段效果优先用「速度表」+ 值颜色映射。

## 六、典型组合

| 场景 | 卡片搭配 | 配置要点 |
| --- | --- | --- |
| 经营驾驶舱 | 4 个数值卡 + 面积时序图 + 柱状时序图 + 条形排行 | 数值卡用「值颜色映射」标红负增长；时序图两条查询放同一张图，量纲不同的那条挂右 Y 轴。 |
| 设备 / 服务监控 | 多系列时序图 + 仪表 + 蜂窝 | 时序图加横线标记（告警阈值）与区域填充（故障时段）；仪表量程设为告警上下限；蜂窝按设备编号铺开。 |
| 分布与构成分析 | 分布 + 文字排行 + 内置饼图 | 分布用「占比」看区间，排行按降序 + 行数上限 10 取头部，饼图看类别占比；三者共用一份查询的过滤条件。 |

## 七、注意事项

- **改配置务必「运行 → 保存」**：只改不运行看到的是旧数据；只运行不保存，刷新后配置会回退。
- **公共配置不在此文**：标题、外框、阴影、关联标签、浮层、图例、数据格式由宿主统一提供，见[公共配置](../guides/system-components/common-config.md)。
- **系列配色**：多系列时优先在「序列样式」里给每条查询设自定义颜色，比整体切主题色更可控；查询项别名不会自动成为图例文字。
- **版本差异**：数值的趋势 / 背景趋势、仪表的阶段速度 / 基础形态依赖较新的前端组件与足够卡片高度；若显示为空或退化，请以基础形态为准，并检查当前插件版本。
- **插件升级**：卡片配置写在页面数据里（`options` / `reqParams` / `commonOptions`），升级插件一般不丢配置；但新增图形或字段在旧版页面上可能按默认值渲染。
