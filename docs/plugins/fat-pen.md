# 肥笔（FatPen）

> 装好插件后，左侧活动栏会多出一枚**铅笔图标（EditOutlined）**。点开是一套「左边菜单 + 右边整页工作台」的**小说创作空间**，界面标题叫**肥笔写手**：以「小说项目」为单位，把章节正文、世界观设定、故事线、大纲、地图、词库和 AI 助手放在同一个工作区里。所有内容都写成工作区 `fatPen/` 目录下的 JSON 文件，**不上云、不需要联网**。

![肥笔写手总览：侧栏世界九宫格与章节树、工作台当前项目卡片](pathname:///fat-notes-home/img/instruction/fatPen/zh/fp-overview.png)

*打开插件后的首屏：左侧是项目信息与五大分组（世界 / 章节列表 / 工具盒子 / 风格设定 / 设置），右侧工作台显示当前项目。* · <a href="/fat-notes-home/img/instruction/fatPen/zh/fp-overview.png" target="_blank" rel="noopener">查看大图</a>

这不是手写笔记或白板工具，而是**给长篇虚构写作准备的结构化工作台**：正文按「卷 → 章 → 段落」拆成可拖拽、可锁定、可交给 AI 续写的单元；角色、阵营、事件、时间线等设定是独立的结构化记录，彼此还能关联；地图则是真正可绘制的地形画布。本文按「先建项目 → 再写正文 → 再搭世界观 → 再画地图 → 最后用工具与 AI」的顺序介绍。

## 一、它是什么：一枚「带后端」的创作插件

| 维度 | 说明 |
| --- | --- |
| 插件 id / 版本 | `fat-pen` / `0.1.0`，UI 名称「肥笔写手」 |
| 界面贡献 | 活动栏铅笔图标、主侧边栏（菜单）、工作台整页、底部面板、状态栏 `[fat-pen] ready`；另注册 `Block 1` / `Block 2` 两块脚手架示例卡片 |
| 组织单位 | **小说项目**（名称、描述、通用 / 私有类型），可拖拽排序，支持编辑与删除 |
| 写作单位 | 卷（`part`）→ 章（`chapter`）→ 段落；段落可锁定，锁定后 AI 不可改 |
| 世界观 | 9 个内置体系 + 任意多个自定义体系（节点 / 关系 / 关系类型拓扑） |
| 地图 | Konva 画布：地形生成、9 种地形笔刷、9 类标记模板、5 个预设图层、边界与区域 |
| 工具与素材 | 取名工具、敏感词 / 推荐词 / 灵感句子三组可导入导出的词库、风格设定 |
| AI | 字段级 AI 修改、9 类 AI 创建弹窗、Agent 与默认模型管理、4 个 MCP 元工具 |
| 数据与后端 | Python 后端（`backend/main.py`，JSON-RPC over stdin/stdout，约 180 个 handler），数据写入工作区 `fatPen/` 下的 JSON 文件 |

技术上，前端是 React 18 + antd 6，关系图用 AntV X6、地图画布用 Konva / react-konva、词云与统计用 ECharts、表格导入导出用 SheetJS；后端由宿主拉起常驻 Python 子进程，前端统一通过 `sdk.backend.invoke(handler, params)` 调用。

:::note 界面语言
插件内部菜单、按钮与表单文案以**中文**为主（随宿主语言可切换）；本文及英文版文档使用的都是中文界面实拍截图。
:::

## 二、开始使用：项目、侧栏与「即时保存」

![项目列表：可新建、拖拽排序、切换项目](pathname:///fat-notes-home/img/instruction/fatPen/zh/fp-projects.png)

第一次进入是空态，点「**添加项目**」即可新建小说项目：名称（必填，≤60 字）、描述（≤200 字）、类型（**通用 / 私有**，默认私有）。项目列表支持拖拽排序、编辑、删除；点击某项目后，工作台就与这个项目绑定，标题区显示项目名、类型与创建时间。

![主侧边栏：世界九宫格、章节树与三个折叠分组](pathname:///fat-notes-home/img/instruction/fatPen/zh/fp-sidebar.png)

选中项目后，主侧边栏分成五个可折叠、可拖拽排序的分组：

| 分组 | 内容 |
| --- | --- |
| **世界** | 2 列网格里的 9 个内置体系；右上角 `+` 可新建自定义体系 |
| **章节列表** | 卷与章的树形列表，`+` 新增章节，拖拽手柄排序 |
| **工具盒子** | 取名工具 |
| **风格设定** | 小说类型、叙事套路、受众、字数、写作风格、风格备注 |
| **设置** | AI 管理、敏感词、推荐词、灵感句子 |

:::tip 没有「保存」按钮
全插件都是**即时写入**：段落失焦即保存，弹窗点确定即落盘，风格设定输入停顿 600ms 自动保存，拖拽松手即写入顺序。成功提示由宿主的 toast 给出。
:::

## 三、章节与正文：卷 → 章 → 段落

![章节写作页：段落列表、锁定高亮、AI 生成整章与添加段落](pathname:///fat-notes-home/img/instruction/fatPen/zh/fp-chapter.png)

点开任意一章，工作台变成专注的正文页：顶部是「返回 / 章节名 / **AI 生成整章** / **添加段落**」，下方是段落列表（卷则显示子章节列表）。

- **段落编辑**：双击进入编辑，失焦保存，`Esc` 取消；左侧拖拽手柄可调整顺序；
- **右键菜单**：编辑段落、锁定 / 解锁、删除；**锁定**后 AI 生成与改写都会跳过这一段，适合已经定稿的关键情节；
- **AI 生成整章**：选择 AI Agent、填写生成段落数与创作指令，一次生成整章草稿，再逐段人工打磨；
- 章与卷都能在左侧树里改名、删除、拖拽排序；卷下的子章节由层级自动推断。

段落是独立的 JSON 记录（`content`、`locked`、排序字段），所以长篇正文既能整体浏览，也便于后续做检索、统计或按段落交给 AI 处理。

## 四、世界观：九宫格里的结构化设定

「世界」分组默认提供 9 个内置体系，各自有独立的页面与数据文件：

| 体系 | 主要能力 |
| --- | --- |
| **角色** | 别名、标签、性别 / 年龄 / 种族 / 阵营 / 职业、描述、时间标签、角色图片、标记「已使用」 |
| **阵营** | 阵营资料、角色—阵营关联、阵营之间的关系、标记已使用 |
| **故事线** | 主线 / 支线，节点连线与断开，节点上挂时间、地点、情节，保存 / 重置布局 |
| **人物关系** | 基础关系类型管理（师徒、恋人、仇敌……）+ 可拖拽的关系拓扑，支持显示边标签 |
| **事件** | 事件卡片、详情抽屉、与时间线的关联、时间排序 |
| **时间线** | 时间节点排序与排序模式设置 |
| **物品系统** | 物品分类、归属关系、标签与标记已使用 |
| **大纲** | 卷 / 章 / 场景的树形节点、父子层级、字数进度与节点标签 |
| **地图** | 见下一节 |

![角色管理：左侧角色卡片，右侧沈砚的详情面板](pathname:///fat-notes-home/img/instruction/fatPen/zh/fp-role.png)

以**角色**为例：卡片上直接显示别名、属性、标签与「未使用」状态，点开右侧详情面板可切换「基本信息 / 详细资料 / 时间标签」三个页签；鼠标悬停卡片还能就地编辑、删除或标记已使用。角色图片、时间标记都是独立存储，写正文时随时回查设定，不必再翻旧文档。

![故事线：主线与支线节点用连线串起剧情](pathname:///fat-notes-home/img/instruction/fatPen/zh/fp-storyline.png)

**故事线**把剧情摊成一张可编辑的拓扑：每个节点写清时间、地点与事件，主线节点之间用箭头连接，支线节点用不同颜色标出所属支线，再汇入主线。配合「保存布局」，改完的图下次打开还在原位。

![大纲：卷 / 章 / 场景的树形结构与字数进度](pathname:///fat-notes-home/img/instruction/fatPen/zh/fp-outline.png)

**大纲**则是写作前更常用的视图：树形节点按卷 → 章 → 场景展开，右侧显示目标字数进度与「开端 / 伏笔 / 转折」等节点标签，拖拽即可重排结构。

### 自定义体系

九宫格右上角的 `+` 可以「**新建自定义体系**」：给它起名、选图标后，就得到一套自己的「节点 + 关系 + 关系类型」拓扑（基于 AntV X6）。例如「宗门谱系」「法器等级」「势力疆域」都可以做成独立体系，节点与关系类型都能自定义，布局可保存。

多数体系页面右上角还有「**AI 创建 / AI 生成**」入口（角色、阵营、物品、事件、时间线、大纲、故事线、人物关系、章节共 9 类），按当前设定批量起草，再人工筛选。

## 五、地图工坊：把世界真正画出来

![地图画布：地形色块、城池标记、工具条与地图列表](pathname:///fat-notes-home/img/instruction/fatPen/zh/fp-map.png)

「地图」是肥笔里最不像「笔记插件」的部分：左侧是地图列表，右侧是 Konva 画布，默认 960×640、24×16 网格、羊皮纸底色；可设主地图，缩放范围 0.3×–4×，一键适应窗口。

### 地形生成与笔刷

![生成地形弹窗：预设、随机种子、九项参数与实时预览](pathname:///fat-notes-home/img/instruction/fatPen/zh/fp-map-generate.png)

点工具条的「**生成地形**」打开参数面板：地形预设（**大陆 / 群岛 / 内陆 / 岛屿 / 自定义**）、随机种子、海平面、山地阈值、森林湿度、沙漠干旱度、河流数量、湖泊数量、噪声频率与噪声层数。右侧预览随参数实时重绘，满意后「应用生成」写回地图。也可以「**导入图片生成**」：用 PNG / JPG / WEBP / BMP 图片按匹配阈值与颜色映射反推地形。

![地形画笔：9 种地形色板与地图工具条](pathname:///fat-notes-home/img/instruction/fatPen/zh/fp-map-tools.png)

「**地形画笔**」面板给出 9 种地形色块（平原、山川、草原、海水、河流、湖泊、沙漠、路径、森林），选中后在画布上拖动即可涂抹；面板第一格是空框，用来**取消绘制**。工具条还集成放大 / 缩小 / 适应窗口 / 缩放百分比、隐藏地形符号、标记模板、边界线、区域等按钮。

:::warning 没有独立橡皮擦
笔刷只做「覆盖式涂抹」；要清掉大片地形，用重新生成地形，或在边界 / 区域面板里「一键清空」。
:::

### 标记、图层、边界与角色位置

![图层管理：5 个预设图层与可见 / 锁定控件](pathname:///fat-notes-home/img/instruction/fatPen/zh/fp-map-layers.png)

地图默认带 5 个图层：**地形层 / 标记层 / 图片标记层 / 轨迹层 / 边界层**，每层可切换可见、锁定、不透明度与顺序，也能新建图层。

- **标记**：内置 9 类模板（城池、大殿、塔楼、房屋、军营、港口、圣殿、遗迹、自定义），支持文字图标或图片两种渲染；从模板面板拖到地图放置，可填名称、颜色、尺寸、描述、背景、功能与坐标；右键可编辑 / 复制 / 删除。
- **角色位置**：把角色钉在地图上，形成行动轨迹，配合「轨迹层」看人物迁移。
- **边界与区域**：国界 / 省界 / 区域 / 自定义四类，可调颜色、线宽、线型、透明度、曲线张力、闭合与填充；支持「基于海岸线生成国界」「基于区域划分生成边界」，以及清空海岸线 / 一键清空。

:::note 导出边界
地图本身**只即时保存、不提供导出 PNG / SVG**；真正的文件导出是下面三组素材库。
:::

## 六、工具盒子与三组素材库

![取名工具：性别 / 姓氏 / 字数 / 数量与候选名字](pathname:///fat-notes-home/img/instruction/fatPen/zh/fp-nametool.png)

**取名工具**按性别（男 / 女 / 中性）、姓氏（留空随机）、名字字数（随机 / 1 / 2）和数量（默认 8，上限 50）批量生成姓名；点候选名即收藏，也能手动输入自定义名字并去重，「换一批」随时重抽。

「设置」分组下还有三组结构对称的素材库，都支持**卡片 / 列表**（或标签云）两种视图：

| 词库 | 分类维度 | 用途 |
| --- | --- | --- |
| **敏感词** | 程度：低 / 中 / 高 | 标出需要规避或改写的内容，避免发布时踩线 |
| **推荐词** | 词汇 / 表达 / 修辞 / 氛围 / 其他 | 积累本作语感，供 AI 与人工写作取用 |
| **灵感句子** | 开头 / 结尾 / 过渡 / 描写 / 对话 / 其他 | 收集可复用的句式、开场与场景描写，附推荐度与使用说明 |

![灵感句子库：双列卡片、分类标签与导入 / 导出按钮](pathname:///fat-notes-home/img/instruction/fatPen/zh/fp-sentences.png)

### 导入与导出

![导出弹窗：XLSX / CSV 与可选导出列](pathname:///fat-notes-home/img/instruction/fatPen/zh/fp-export.png)

三组词库右上角都有「导入 / 导出」：

- **导出**：选 XLSX 或 CSV，勾选导出列（内容等必选列不可取消），前端直接生成文件下载，文件名分别为 `sensitive_words`、`recommended_words`、`inspiration_sentences`；
- **导入**：拖拽 `.csv / .xlsx / .xls`，列名兼容中英文（如 `content / 句子 / 内容`），预览里标出 `新增 / 重复`，确认后逐条写入，不会覆盖已有数据。

## 七、风格设定与 AI 辅助

![风格设定：类型、套路、受众、字数、写作风格与风格备注](pathname:///fat-notes-home/img/instruction/fatPen/zh/fp-style.png)

**风格设定**写在侧栏分组里，分「基础设定 / 进阶设定」：小说类型（玄幻、仙侠、科幻、都市……14 项预设）、叙事套路（英雄之旅、三幕剧、伏笔流、升级流……14 项）、受众定位、目标字数（万字）、写作风格（鲁迅、金庸、托尔金、刘慈欣……16 项）与风格备注。每项都支持自定义输入，底部自动汇总成一段「类型 / 套路 / 受众 / 字数 / 风格」摘要，作为整部作品的基调说明。

![AI 管理：默认模型配置与 Agent 卡片](pathname:///fat-notes-home/img/instruction/fatPen/zh/fp-ai.png)

**AI 管理**页分两块：

- **默认模型配置**：文本生成、图片生成、大纲生成、角色生成、章节生成各自绑定模型；
- **Agent 配置**：新建 Agent，指定名称、描述、**工作点**（全局 / 角色 / 阵营 / 物品 / 大纲 / 章节 / 地图 / 事件 / 故事线 / 时间线 / 人物关系）、模型、知识库、向量库、MCP 工具、技能、系统提示、`temperature`、最大迭代次数、自动 MCP 与启用开关；按工作点筛选后，各页面的 AI 入口就会使用对应 Agent。

此外还有两类 AI 能力：

- **字段级 AI 修改**：表单字段旁的小图标可对单个字段发起「AI 修改」，支持执行、复制指令、历史指令、重填输入框与恢复原值，结果缓存在 `aiCache.json`；
- **MCP 工具**：注册 4 个元工具（列出工具分类 / 加载分类详情 / 搜索工具 / 调用工具），把约 40 类后端能力（项目、章节、角色、地图、词库……）暴露给 Agent 调用，便于让 AI 直接读写世界观数据。

## 八、数据与存储：全部留在本机

后端以工作区根目录的 `fatPen/` 作为数据仓库，典型结构如下：

```text
<工作区>/fatPen/
├── fictions.json                 # 项目列表与排序
├── settings.json                 # 全局设置：上次选中的项目、菜单状态
└── fictions/<项目 id>/
    ├── settings.json             # 项目级设置：菜单顺序 / 折叠状态 / 各类视图偏好
    ├── chapters.json             # 卷与章
    ├── paragraphs/<章 id>.json    # 正文段落（含 locked）
    ├── fictionStyle.json         # 风格设定
    ├── aiCache.json              # 字段级 AI 修改缓存
    ├── sensitiveWords.json / recommendedWords.json / inspirationSentences.json
    ├── names.json                # 收藏的名字
    └── world/
        ├── elements.json         # 9 个内置体系 + 自定义体系
        ├── role/ faction/ item/ timeline/ event/ storyline/ outline/
        ├── map/maps.json         # 地图、地形格、标记、边界、区域、图层
        └── system/<体系 id>/     # 自定义体系的节点 / 关系 / 关系类型 / 坐标
```

文件都是 UTF-8 JSON，写入采用「临时文件 + 原子替换」，因此即使中途退出也不容易写坏整个项目。前端通过 `sdk.backend.invoke` 调用约 180 个后端 handler，后端用 JSON-RPC 逐行通信；MCP 侧则走宿主的 `/app/pluginBackend/invoke`。

:::warning 使用前请留意
- **删除项目会级联删除该项目整个目录**，且没有整项目导出 / 备份功能，重要书稿请先自行复制 `fictions/<项目 id>/`；
- 没有全局快捷键，只有少量组件级键：`Esc` 取消编辑、`Enter` 提交输入、双击进入段落编辑、长按 2 秒拖拽分组排序；
- 地图不能导出图片，地形画笔没有独立橡皮擦；
- 插件仍保留脚手架示例贡献（`Block 1` / `Block 2` 卡片类型、底部面板、状态栏 `[fat-pen] ready`），正式创作时可忽略；仓库 README 也是未定制的脚手架模板，功能以本文为准。
:::

## 九、小结

肥笔把长篇创作拆成了**可管理的数据**：项目管全局，卷章段落管正文，九宫格管设定，地图管地理，词库管语料，风格设定管基调，AI 与 MCP 负责批量生成与改写。它适合写小说、系列文章、剧本或任何需要「人物不串、时间线不乱、地图对得上」的长篇内容——设定不再是散落的笔记，而是随时能查、能连线、能生成的结构化资料。
