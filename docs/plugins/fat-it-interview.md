# IT 面试题库（fat-it-interview）

> 装好插件后，左侧活动栏会多出一枚 **IT 面试图标**（aliwangwang）：点开是「左边分类 + 右边做题页」的双栏工作台。题库与算法演示都跑在前端，**不依赖任何后端**，做题与掌握记录只保存在本机浏览器里。

这是一枚「刷题型」插件：内置 **364 道题**，按 **Web 前端、Java、后端、运维、算法、数据库、网络、操作系统** 八个大方向组织，每个方向再细分二级分类。它最大的特色是 **21 道算法题可以逐步播放**——排序、查找、双指针、链表、树、图、动态规划都能看着一步一动地演下去，而不是只甩给你一段代码。

本文重点讲**题库怎么用**和**算法演示怎么看**，这是它和普通「题库 PDF」最不一样的地方。

## 一、它是什么：一枚「纯前端」的刷题插件

IT 面试题库和工具箱（FatTools）一样，走宿主的插件贡献点：

- **活动栏**：一枚「IT 面试」图标，点开插件；
- **主侧边栏**：只放分类树和搜索；
- **工作台整页**：总览和做题；
- **仪表盘卡片**：「今日面试题」「算法演示」两块（分类「其他」，不占用数据查询配置）；
- 插件页激活时，会请求**隐藏右侧次侧栏和底部面板**，给做题留出更大的空间。

题库和算法演示全部在前端完成，所以离线也能用；练习记录和掌握情况写在 `localStorage`，不会上传。

## 二、题库覆盖：八大方向，364 道题

![IT 面试题库总览页](pathname:///fat-notes-home/img/instruction/fatItInterview/zh/it-home.png)

打开插件首屏是**总览页**：八张大方向卡片，每张卡都标了题量和一句话介绍，下面还有一条**掌握进度条**（已掌握 x / 总题数）。首屏还给了几个快捷入口：**今日一题**（按当天日期稳定抽一道）、**随机一题**、**继续**（接着上次那道）、**算法演示（21）**。

八大类与题量如下（合计 **364**）：

| 方向 | 题量 | 二级分类 |
| --- | --- | --- |
| Web 前端 | 283 | HTML、CSS、JavaScript、React、Redux、Zustand、Vue、Webpack、Vite、浏览器、TypeScript、性能优化、手写题、工程化、Web 安全、AI 工程、设计题 |
| Java | 12 | JVM、集合、并发、Spring、语言基础 |
| 后端 | 12 | 接口设计、缓存、消息队列、分布式、系统设计 |
| 运维 | 10 | Linux、Docker、Kubernetes、交付与观测、Nginx |
| 算法 | 21 | 排序、查找、指针与窗口、链表、树、图、动态规划 |
| 数据库 | 10 | 索引、事务、SQL、Redis |
| 计算机网络 | 8 | TCP、HTTP、HTTPS、DNS、UDP |
| 操作系统 | 8 | 进程与调度、内存、同步、IO 与内核 |

> 题目分**简单 / 中等 / 困难**三档（绿 / 金 / 红标签），每道题由「题干（面试官的问法）＋ 参考答案（含要点列表与代码）＋ 追问」组成。

## 三、侧边栏：分类树 + 跨分类搜索 + 进度

![侧边栏：分类树、搜索框与进度统计](pathname:///fat-notes-home/img/instruction/fatItInterview/zh/it-sidebar.png)

左侧主侧边栏只有两样东西：**搜索框**和**分类树**。

- 顶部的统计行写着 **`364 题 · 已掌握 0`**，随时提醒你总量和进度；
- 分类树按八大方向展开，每个方向左边一个展开/收起箭头，右边是 `done/total` 的掌握进度；
- 子分类同样显示 `done/total`，做到哪、还差多少一目了然。

![跨分类搜索：输入「虚拟内存」直击操作系统 / 内存分类下的题目](pathname:///fat-notes-home/img/instruction/fatItInterview/zh/it-search.png)

搜索框支持**跨分类**查找：输入关键词、标签或分类名（如「虚拟内存」），结果会列出命中题目的**标题以及它所在的「父分类 / 子分类」路径**，点一下即可跳到该题。宿主的**全局搜索（⌘/Ctrl + K）**也能直达面试题，标签统一为「面试题」。

## 四、做题与练习模式

![题目页：左侧题目列表、右侧题干与参考答案](pathname:///fat-notes-home/img/instruction/fatItInterview/zh/it-question.png)

点进任意分类，是经典的三栏布局：**左边题目列表、右边题目详情**。

- 题目列表顶部有关键词搜索、难度筛选（全部 / 简单 / 中等 / 困难）和「只看未掌握」开关；
- 右侧详情展示**难度标签、题干提示框**，以及三个动作：**标为已掌握**、**加入复习**、**复制答案**；
- 参考答案默认**藏在「查看参考答案」按钮后面**——这是「练习模式」的用意：先自己想，再对答案；
- 答案下方常有**追问**（follow-up），帮你把一个问题挖深；底部还有「上一题 / 下一题」顺次刷题。

练习模式、掌握与复习状态都记在本机：标过「已掌握」的题目在卡片和列表上会打勾，标过「加入复习」的会出现在总览页的**待复习**区，方便二轮回看。

## 五、算法演示（重点特色）：看着算法一步步跑

这是本插件最值得单独拿出来说的能力。**21 道算法题不是只给答案，而是能逐步播放**：

冒泡、选择、插入、快排、归并、堆排、二分与左边界、双指针、滑动窗口、移动零、BFS、DFS、反转链表、判环、0/1 背包、爬楼梯、最大子数组和、最长公共子序列、二叉树中序与层序。

每道题都配了一个**算法播放器**，界面包含：

- **可视化舞台**：随算法类型不同，有六种画法——柱状图、数组（带指针）、网格（图搜索）、链表（SVG 节点 + 指针）、矩阵（DP 表）、树（遍历过程）；
- **单步控制**：`上一步 / 播放 / 下一步 / 重置`，可以一帧一帧看，也可以自动连播；
- **速度档**：`0.5x / 1x / 2x / 4x`；
- **进度滑块**：直接拖到第 N 步；
- **图例**：用颜色区分「比较 / 交换 / 枢轴 / 已就位 / 关注」等角色，看懂每一步在干什么；
- **可改输入**：多数演示允许你填自己的数据（如 `5,1,4,2,8`），点「重新演示」从你的输入重跑。

![算法演示：冒泡排序的柱状图可视化与播放控制条](pathname:///fat-notes-home/img/instruction/fatItInterview/zh/it-algo-bubble.png)

以**冒泡排序**为例：柱子高度表示数值，每一步高亮当前在「比较」或「交换」的下标，跑完一轮后最大值被染成「已就位」的绿色；下方的图例让你一眼认出每根柱子的状态，进度条和速度档随时可调。

![算法演示：反转链表的 SVG 节点图，prev / curr / next 三指针随步推进](pathname:///fat-notes-home/img/instruction/fatItInterview/zh/it-algo-list.png)

再看**反转链表**：节点画成带值的圆角方块，弧线表示指针方向，`prev / curr / next` 三个指针用不同颜色标注当前位置；逐步播放时你能看清「先记住 next，再把 curr.next 指向 prev，然后三个指针一起前进」的全过程，而不是盯着一段 Java/JS 代码脑补。

其它几类可视化也各有读法：二分与左边界用**数组 + lo/hi/mid 指针**，滑动窗口用**数组 + 窗口高亮**，BFS/DFS 用**网格（待扩展 / 已出队 / 最短路径）**，0/1 背包、LCS 用**矩阵（DP 表）**，中序 / 层序用**树（栈 / 队列 / 访问 / 已访问）**。对同一道题，题目页里既有**文字讲解 + 代码**，又有**可逐步播放的演示**，理论和实践对得上。

## 六、仪表盘卡片：把题和演示搬进工作台

插件提供两张可拖进任意仪表盘（分类「其他」，不使用数据查询）的卡片：

- **今日面试题**（`fat-it-interview.daily`）：展示当天的那道题，卡片内可看答案、也能「在题库中打开」跳回完整做题页；
- **算法演示**（`fat-it-interview.algo`）：带一个下拉框，任选 21 个演示之一，直接在仪表盘上逐步播放。

也就是说，你可以把「每日一题」或某个算法演示钉在常用看板上，打开 FatNotes 就能刷一道，不必每次都进插件。

## 七、命令与设置

- **命令 `fat-it-interview.openQuestion`**：按题目 id 直接打开对应题目（如脚本或快捷方式调用）；
- **命令 `fat-it-interview.ping`**：返回 `pong` 与当前题目数，用于自测插件是否就绪；
- **设置页**：说明插件内置题量、练习模式默认隐藏答案、掌握与复习记录只在本地、以及 `openQuestion` 命令的用法。

## 八、小结

IT 面试题库把「背题」和「看算法跑起来」合在了一起：

- **364 道题、八大方向**，分类清晰、可跨类搜索、带难度与掌握进度；
- **练习模式**先考自己再对答案，掌握与复习状态留在本机；
- **21 道算法题可逐步演示**，六种可视化 + 单步/播放/调速/改输入，是它最出彩的部分；
- 还能通过**今日面试题 / 算法演示**两张仪表盘卡片，把刷题嵌进日常工作台。

适合日常复习、面试前突击，以及把抽象算法「看明白」而不是「背下来」。
