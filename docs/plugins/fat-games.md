# 肥游（FatGames）

> 装好 FatGames 后，左侧活动栏会多出一枚**耳机图标**：点开是「左边游戏菜单 + 右边游戏舞台」的双栏工作台，菜单顶部写着「共 31 个游戏」。2048、扫雷、俄罗斯方块、赛车竞速……玩法各不相同，但**用法是同一套**：搜索找到 → 点开 → 按提示玩一局 → 成绩自动记账 → 到排行榜回看。本文重点讲**怎么用**和**所有游戏共用的机制**，游戏本身只挑几个代表。

## 一、它是什么：一枚「界面型」游戏插件

[热门插件总览](./index.md)里的肥游（`fat-games`，清单名 `Fat Games`）和[肥图表](./fat-charts.md)、[肥Ai基座](./fat-ai-base.md)不太一样：它不往流程画布里加节点，也不把查询结果画成图表，而是**直接贡献一整块界面**——活动栏入口、主侧边栏游戏菜单、工作台整页，以及每个游戏各自的路由页。

| 维度 | 说明 |
| --- | --- |
| 条目数量 | 当前版本 **31 个**：30 款可玩游戏 + 1 个「排行榜」；以菜单顶部「共 N 个游戏」为准 |
| 界面贡献 | 活动栏耳机图标、主侧边栏游戏菜单、工作台整页、`/games/<gameId>` 路由页、设置页、全局搜索项 |
| 运行位置 | 全部游戏是**纯前端实现**：棋盘、物理、动画和音效都在本机浏览器里算，不联网、不上传 |
| 插件后端 | 只负责成绩记录（`fatGames/history.db`）；不监听业务端口，也不参与任何一局游戏的计算 |
| 额外贡献 | 1 个仪表盘块类型「游戏」、2 个命令、显示配置面板；`plugin.json` 中 `panel` / `footer` 为 `false` |

![FatGames 在 FatNotes 中的位置](pathname:///fat-notes-home/img/instruction/fatGames/zh/fg-arch.png)

*自上而下：三段式界面 → 统一舞台的四段结构 → 路由 / 搜索 / 成绩 / 主题等公共机制 → 仪表盘块、命令与设置页等延伸入口。* · <a href="/fat-notes-home/img/instruction/fatGames/zh/fg-arch.png" target="_blank" rel="noopener">查看大图</a>

:::note 界面语言
游戏名、按钮、统计标签和操作提示都提供**中英两套文案**，跟随应用的语言设置切换（例如「贪吃蛇 / Snake」「重新开始 / Restart」）。宿主外壳文案同理。唯一的例外是 `Ctrl + K` 全局搜索里的游戏项，标题取注册表里的中文兜底文本，英文界面下仍显示中文。
:::

## 二、打开与使用：三步走

### 2.1 安装、入口与整体布局

在[扩展中心](../guides/extensions.md)安装并启用 `fat-games` 后，活动栏出现耳机图标。点一下，界面分成三块（下图红框）：最左细条是**活动栏**，中间是**游戏菜单**（搜索框 + 游戏卡片 + 底部音效开关），右边是**游戏舞台**。插件处于激活状态时会自动隐藏右侧次侧栏与底部面板，给游戏留出更宽的空间。

![肥游的三段式界面](pathname:///fat-notes-home/img/instruction/fatGames/zh/fg-layout.png)

*红框从左到右：活动栏耳机图标、游戏菜单（搜索框 + 31 张卡片）、右侧 2048 舞台；舞台下方那行小字就是统一的操作提示。* · <a href="/fat-notes-home/img/instruction/fatGames/zh/fg-layout.png" target="_blank" rel="noopener">查看大图</a>

### 2.2 找到游戏：四种方式

31 个条目不需要翻页找。菜单顶部的搜索框会同时匹配**标题、描述、分类和游戏 id**，并且支持中文、英文、拼音全拼与拼音首字母：

| 方式 | 操作 | 适合场景 |
| --- | --- | --- |
| 侧栏搜索 | 输入 `贪吃蛇`，列表立刻收敛到这张卡片 | 记得游戏名或大概用途 |
| 拼音首字母 | 输入 `tcs`，同样命中「贪吃蛇」（tan chi she） | 中文输入法不方便时 |
| 全局搜索直达 | `Ctrl + K` 后输入游戏名、分类或游戏 id | 手在键盘上，不想先去点菜单 |
| 命令 / 路由 | 命令 `fat-games.openGame` 传游戏 id，或直接访问 `/games/<gameId>` | 从流程、其它扩展或脚本里跳转 |

![侧栏搜索「贪吃蛇」](pathname:///fat-notes-home/img/instruction/fatGames/zh/fg-search.png)

*红框为搜索框与命中的卡片；卡片上有图标、描述和分类标签（这里是「休闲」）。* · <a href="/fat-notes-home/img/instruction/fatGames/zh/fg-search.png" target="_blank" rel="noopener">查看大图</a>

![拼音首字母 tcs 命中贪吃蛇](pathname:///fat-notes-home/img/instruction/fatGames/zh/fg-search-pinyin.png)

*只输入三个首字母就收敛到唯一结果；拼音全拼（如 `tanchishe`）和游戏 id（如 `snake`）同样有效。*

插件还把每个游戏注册成宿主的**全局搜索项**：`Ctrl + K` 输入「贪吃蛇」，结果里会出现带「游戏」标签的条目，按 `Enter` 直接打开对应游戏；同时命中的其它插件结果（例如 FatTools 的工具）也照常显示。

![全局搜索直达游戏](pathname:///fat-notes-home/img/instruction/fatGames/zh/fg-global-search.png)

*结果项右侧标着「游戏」标签；`↑/↓` 选择、`Enter` 打开、`Esc` 关闭。* · <a href="/fat-notes-home/img/instruction/fatGames/zh/fg-global-search.png" target="_blank" rel="noopener">查看大图</a>

### 2.3 打开与记忆

点任意卡片 → 插件调用 `sdk.router.navigate`，跳到 `/games/<gameId>`，右侧工作台整页随即渲染对应游戏。切换游戏不会刷新应用；同时这个游戏会被记进 `localStorage`，**下次打开游戏箱（甚至重启应用）会直接回到上次玩的那一款**。首次使用或记忆失效时，兜底打开注册表里的第一个游戏（2048）。

:::tip 舞台一直显示「正在打开游戏…」？
这是路由还没落到 `/games/*` 时的占位。回到活动栏再点一次耳机图标，或在菜单里随便点一张卡片即可恢复，不需要重启插件。
:::

## 三、公共特性：所有游戏共用的一套约定

![一局游戏的完整链路 · 公共特性速查](pathname:///fat-notes-home/img/instruction/fatGames/zh/fg-common.png)

*「找 → 开 → 玩 → 记 → 查 → 复用」六步，30 款游戏基本一致；表格里每条都给了可直接复现的例子。* · <a href="/fat-notes-home/img/instruction/fatGames/zh/fg-common.png" target="_blank" rel="noopener">查看大图</a>

### 3.1 统一舞台：GameFrame 的四段结构

每个游戏都被包进同一个「游戏厅」外壳（`GameFrame`）：渐变舞台 + 圆角 + 内阴影，顶部标题栏、统计胶囊行、内容区、底部操作提示。用 2048 看一次完整流程：按方向键合并方块 → 分数与最佳分数实时更新 → 卡住无处可走时结算 → 点「重新开始」清零再来一局。

![2048 的统一舞台](pathname:///fat-notes-home/img/instruction/fatGames/zh/fg-game-2048.png)

*红框分别是三个统计胶囊（当前分数 / 最佳分数 / 最大方块）、右上角「重新开始」，以及底部的操作提示。* · <a href="/fat-notes-home/img/instruction/fatGames/zh/fg-game-2048.png" target="_blank" rel="noopener">查看大图</a>

| 区域 | 所有游戏的共同约定 | 具体表现 |
| --- | --- | --- |
| 标题栏 | emoji + 游戏名，右侧放该游戏的动作 | 「重新开始」「开始」「暂停」等；按钮自带点击音效 |
| 统计胶囊 | 标签 + 数值，配色区分含义（金 / 蓝 / 紫 / 绿 / 红） | 分数、最佳分数、关卡、剩余地雷、用时、生命……数值变化时有跳动动画 |
| 内容区 | 键盘 / 鼠标 / 触摸操作，按游戏而定 | 2048 用方向键或 `W/A/S/D`；扫雷左键翻开、右键插旗；赛车用方向键控制 |
| 底部帮助 | 一行文字写清按键与目标 | 例如「操作：方向键 或 W/A/S/D 移动方块；相同数字合并；目标 2048。」 |

换两个玩法差别很大的游戏，外壳依旧不变：扫雷是格子棋盘 + 两个统计胶囊，俄罗斯方块是竖长场地 + 「下一个」预览 + 开始按钮，但标题栏、胶囊、按钮风格和底部提示都来自同一套组件。

![扫雷：益智类游戏](pathname:///fat-notes-home/img/instruction/fatGames/zh/fg-game-puzzle.png)

![俄罗斯方块：休闲类游戏](pathname:///fat-notes-home/img/instruction/fatGames/zh/fg-game-casual.png)

*上：扫雷（益智）；下：俄罗斯方块（休闲）。玩法不同，舞台结构、按钮与配色语言一致。*

### 3.2 动画、音效、主题与语言

- **动画**：共用一组关键帧——舞台入场、方块生成、合并闪亮、数值跳动、提示脉冲等，全部由 CSS 实现，不依赖图片资源。
- **音效**：Web Audio API 实时合成（正弦 / 方波 / 噪声），覆盖点击、移动、得分、命中、爆炸、胜利、失败等几十种事件；**没有外部音频文件**。同种音效有最小间隔节流，连续操作不会叠成爆音。
- **一个开关管全部**：菜单底部的「游戏音效」开关对所有游戏生效，状态写入 `localStorage`；浏览器要求首次用户手势之后才允许出声，所以刚打开页面时的静默是正常现象。

![菜单底部的全局音效开关](pathname:///fat-notes-home/img/instruction/fatGames/zh/fg-sound.png)

*红框内是音效开关与说明文字；关掉后所有游戏都不再发声，无需逐个设置。*

- **主题**：`ThemeShell` 跟随宿主的明暗主题，为插件内 antd 组件套用对应算法；舞台背景、边框和文字颜色也随明暗切换，不需要单独配置。
- **语言**：见前文说明，游戏内文案有中英两套，随应用语言切换。成绩记录里的游戏名使用注册表中文兜底文本，因此英文界面下排行榜里仍可能是中文名。

### 3.3 成绩自动记录：一局结束就落库

成绩不是某个游戏的私货，而是一套插件级机制：**30 款可玩游戏全部接入** `recordScore()`，一局结束、通关或达成目标时自动写一条，不需要点保存；未结束中途退出不会留下半局成绩。

| 机制 | 行为 |
| --- | --- |
| 记录字段 | 游戏 id / 游戏名、玩家名（默认「匿名」）、分数、详情（如关卡、用时、命中数）、时间 |
| 落库位置 | 工作区下的 `fatGames/history.db`，由插件 Python 后端用标准库 `sqlite3` 维护 |
| 后端接口 | `scores.add` / `scores.list` / `scores.clear` / `scores.stats` / `scores.dbPath` |
| 保留策略 | 每个游戏只保留最近 **500 条**，过长的字段与详情会自动截断 |
| 降级 | 后端不可用时自动改用浏览器 `localStorage`（最多 **200 条**），游戏功能完全不受影响 |
| 本机最佳 | 「最佳分数」「最大方块」等单游戏记录另存 `localStorage`，与成绩库互不依赖 |

:::caution 成绩只属于本机
成绩库在工作区里，不会跨设备同步；换一台电脑、清理工作区或卸载插件后，历史不会跟过去。若后端曾降级到浏览器本地存储，清理浏览器数据同样会清掉成绩。
:::

### 3.4 排行榜：全插件共用的成绩视图

菜单最后一张卡片「排行榜」是**记录视图，不是可玩游戏**：顶部两个统计胶囊显示总记录数与有成绩的游戏数，下面按游戏列出条数，右上角可筛选游戏、刷新、清空，表格按时间倒序展示明细。

![排行榜：成绩统计与明细](pathname:///fat-notes-home/img/instruction/fatGames/zh/fg-scores.png)

*红框内是「总记录数 / 游戏种类」统计胶囊；右上依次为游戏筛选下拉、刷新、清空；表格列有游戏、玩家、分数、详情与时间。* · <a href="/fat-notes-home/img/instruction/fatGames/zh/fg-scores.png" target="_blank" rel="noopener">查看大图</a>

| 操作 | 说明 |
| --- | --- |
| 按游戏筛选 | 下拉只列出已有成绩的游戏；选「全部游戏」看汇总 |
| 排序 | 默认时间倒序；点「分数」表头可切换按分数排序 |
| 翻页 | 每页 10 条，读取最近 100 条记录 |
| 清空 | 带二次确认；只清当前筛选的游戏或清空全部，按筛选状态决定 |
| 详情 | 把游戏自定义字段（如 `level=12`、`seconds=298`）显示出来，鼠标悬停可看完整内容 |

### 3.5 本地性与边界

- **不联网**：所有游戏逻辑都在浏览器内，没有账号、没有匹配服、没有文件上传；断网照常玩。
- **不与数据绑定**：游戏舞台不需要配置数据源、书籍或仪表盘查询，打开就能玩。
- **后端只是账本**：插件清单虽启用 Python 后端，但它只维护 `history.db`；后端没起来时成绩降级到本地存储，游戏照样能玩。

## 五、进阶：把游戏带出游戏箱

游戏不只存在于游戏箱里。插件注册了一个**仪表盘块类型**「游戏」，可以像普通组件一样拖到看板页面上：

| 块类型 | 分类 / 默认尺寸 | 用途 |
| --- | --- | --- |
| `fat-games.game`（游戏） | `other` / 6×30（最小 4×16） | 一张卡片内切换并直接游玩多个游戏；不查询数据源（`dataConfig: false`） |

它的私有配置写在 `options.gameSwitcher`，在组件配置抽屉的「显示配置」里可视化编辑：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `games` | 全部可玩游戏（不含排行榜） | 参与切换的游戏 id 列表；留空自动回退全部 |
| `defaultGame` | `2048` | 打开卡片时默认展示的游戏 |
| `showSwitch` | `true` | 是否显示切换控件 |
| `switchStyle` | `segmented` | `segmented` 按钮组或 `select` 下拉框 |
| `switchPosition` | `top` | 切换控件放在 `top` 或 `bottom` |

另外还有几个不显眼但好用的入口：命令 `fat-games.openGame(gameId)`（从流程或其它扩展里直达指定游戏）、`fat-games.ping`（自检插件是否加载），以及设置页里列出的**全部游戏名称与对应路由**。给插件开发者：这套「活动栏 + 主侧边栏 + 工作台整页」由 `registerActivityBarItem`、`registerPrimarySidebar`、`registerWorkbenchPage` 三个贡献点组成，活动栏项 id 必须与工作台页 id 一致；新增游戏只需在 `registry.tsx` 加一条记录，纯计算逻辑收敛到 `utils.ts` 便于单测，详见[插件开发](../plugin-dev/index.md)。

## 六、常见问题与边界

| 现象 | 优先检查 |
| --- | --- |
| 活动栏没有耳机图标 | 插件是否已在[扩展中心](../guides/extensions.md)安装并启用；也可在活动栏右键菜单里确认该项未被隐藏 |
| 右侧一直显示「正在打开游戏…」 | 当前路由不属于 `/games/*`，重点耳机图标或点一张游戏卡片即可 |
| 搜索不到某个游戏 | 换个关键词：中文名、英文名、游戏 id、拼音全拼或首字母；搜索会同时匹配标题 / 描述 / 分类 |
| 完全没有声音 | 菜单底部「游戏音效」是否被关掉；浏览器还要求先有一次点击等用户手势才允许播放 |
| 一局结束却没成绩 | 只有结算（失败 / 通关 / 达成目标）才记录，中途退出不写；另外确认后端或 `localStorage` 是否可写 |
| 排行榜是空的 | 先玩一局产生成绩；若此前后端不可用，成绩可能存在浏览器本地存储而非 `history.db` |
| 换电脑后成绩没了 | 成绩只在本机 `fatGames/history.db` 或浏览器本地存储中，没有云同步 |
| 英文界面里搜索项仍是中文 | 符合预期：宿主全局搜索项取注册表中文兜底标题；游戏内文案仍是英文 |
| 某个 3D / 物理游戏卡顿 | 渲染和计算都在浏览器里，取决于本机性能；可先关掉其它占用 GPU 的页面 |

最后几条边界值得记住：

- **它是界面插件，不是数据源插件**：游戏不与书籍、数据表或仪表盘查询绑定，也不需要登录账号。
- **后端不是游戏引擎**：插件清单虽启用 Python 后端，但只服务成绩库；后端不可用时游戏照常可玩，只是成绩降级到浏览器存储。
- **成绩属于本机**：包含玩家名与自定义详情，敏感场景下可在排行榜里清空对应记录；备份工作区时会一并带上 `fatGames/history.db`。
- **版本差异**：游戏数量、分类与部分按钮文案可能随插件版本调整，以当前安装版本的界面为准。
