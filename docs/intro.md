# 欢迎使用 FatNotes

FatNotes（肥仔笔记）是一个本地优先的桌面级知识工作台。它将笔记、数据看板、流程自动化与 AI 能力放进一个统一的专业界面，让知识不只被记录，还能被连接、分析和使用。

## 你可以用 FatNotes 做什么？

- **沉淀知识**：使用 Markdown、富文本及多种文档组件组织内容。
- **理解数据**：连接 SQLite、MySQL、PostgreSQL 等数据源并制作看板。
- **自动执行**：通过可视化流程编排数据处理和重复任务。
- **智能检索**：结合 AI 与知识库，让回答基于你自己的上下文。
- **按需扩展**：使用插件机制扩展侧边栏、工作流节点与业务能力。

## 从这里开始

第一次使用 FatNotes？请阅读[快速开始](./getting-started/quick-start.md)。

准备为官网补充内容？请阅读[如何编辑本站文档](./getting-started/write-docs.md)。保存在 `docs/` 下的 Markdown 文件会成为中文文档；提交并推送到 GitHub 后，官网将自动构建并更新。

:::tip 本地优先
FatNotes 以本地工作体验为核心。重要数据如何存储与同步，仍应根据你的数据安全要求进行配置。
:::
