# 数据看板

FatNotes 可以把数据库查询结果和可视化组件放在同一个工作空间中，帮助你把资料、分析过程与结论连接起来。做一张报表不再需要「数据库客户端查数据 → 复制到 Excel 画图 → 截图贴进笔记」三步走，查询和图表就在同一页面上。

## 可连接的数据源

内置数据库管理器，支持可视化浏览表结构与数据。当前架构支持以下数据源：

| 数据源 | 典型用途 |
| --- | --- |
| SQLite | 本地数据、个人记录、演示与学习场景 |
| MySQL / MariaDB | 业务系统数据库、网站后台 |
| PostgreSQL / TimescaleDB | 复杂分析、时序数据 |

不同版本的可用连接器可能不同，请以应用内显示为准。

## 建立看板的步骤

1. **新建数据源**：填写数据库连接信息（地址、端口、账号密码）。
2. **验证连接**：确保所用的账户只有完成任务所需的权限。
3. **编写或生成查询**：手写 SQL，或借助 AI 生成查询语句。
4. **绑定组件**：把查询结果绑定到表格、趋势图、仪表盘、饼图等组件上。
5. **安排布局**：按阅读顺序排列组件，重要指标放显眼位置。

## 让看板更好用的技巧

- **时间过滤器联动**：为看板绑定时间过滤器后，切换「今天 / 最近 N 小时 / 自定义区间」，页面上所有图表会一起刷新。
- **组件混排**：图表块可以和笔记、表格、输入框放在同一页，形成「数据 + 结论」的分析报告。
- **配合流程使用**：流程可以定时查询并写入数据，看板负责展示，两者组成完整的监控小应用。
