# 数据看板

FatNotes 可以将数据库查询结果和可视化组件放在同一个工作空间中，帮助你把资料、分析过程与结论连接起来。

## 可连接的数据源

产品架构支持 SQLite、MySQL、PostgreSQL、MariaDB 与 TimescaleDB。不同版本的可用连接器可能不同，请以应用内显示为准。

## 建立看板的步骤

1. 新建数据源并填写连接信息。
2. 验证连接，确保账户只有完成任务所需的权限。
3. 编写或生成查询。
4. 将查询结果绑定到表格、趋势图等组件。
5. 根据阅读顺序安排组件布局。

:::caution 保护凭据
不要在笔记、截图或公开仓库中提交数据库密码。连接生产数据库时，优先使用只读账户。
:::
