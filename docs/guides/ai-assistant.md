# AI 助手

FatNotes 把 AI 对话（Chat）做成了工作台里的常驻能力：你可以用自然语言让它创建图表卡片、生成 SQL 查询、基于自己的笔记问答、批量修改页面布局。它不是一个孤立的聊天框，而是能真正「动手」操作当前工作空间里的内容与数据的智能体。

## 一、它在哪里

- **次级侧栏（Chat）**：界面右侧为 AI 对话保留了一个常驻区域，随时唤起、随时收起。
- **命令面板**：按 `Ctrl + K` 打开命令面板，搜索并选择「打开 Chat」即可进入对话。

> 提示：左下角齿轮**上方**还有一个独立的 **AI 图标**，打开的是「AI 设置」（模型、记忆、MCP、TTS、ASR、Agent 策略），与对话窗口是两套独立页面。AI 能力本身在「AI 设置」里统一管理：

## 二、对话界面

![AI 助手对话窗口：模型选择、思考过程、图表卡片创建示例](pathname:///fat-notes-home/img/features/ai-assistant-chat.png)

对话窗口自上而下包含：

| 区域 | 说明 |
| --- | --- |
| 标题栏 | 显示「CHAT」与助手标识，并提供视图（眼睛）、固定、分屏、面板、全屏等窗口控制 |
| 消息区 | 用户气泡（右侧）与 AI 卡片（左侧，带机器人头像）交替出现；AI 回答可折叠「思考过程（N 步）」 |
| 输入区 | 底部输入框，可切换**模型**（如 `deepseek-v4-pro`），回车发送，支持多轮对话 |

AI 回复下方通常有 **复制** 与 **重新生成** 按钮，便于复用内容或微调结果。

## 三、核心能力

### 1. 自然语言创建组件与看板卡片

直接告诉 AI 你想要什么块，它会按要求在画布上创建组件。例如：

> 用户：「给我创建一个流量监控的折线图卡片」

AI 会创建一张 `fat-charts.trend`（时序图）卡片，并说明卡片类型、位置（画布左上角、尺寸 8×32）、图形（折线）与数据绑定状态，随后还能继续帮你补全查询配置。

支持的常见块类型包括：折线 / 柱状 / 面积趋势图、数字卡、仪表盘、排行榜、饼图、表格、文本、Markdown 等，完整清单见[系统组件](./system-components/overview.md)。

### 2. 生成与编写查询（SQL）

绑定数据看板时，不必手写 SQL——把表结构或需求描述给 AI，它能生成查询语句，再帮你绑定到图表组件上。详见[数据看板](./data-dashboard.md)的「编写或生成查询」一步。

### 3. 基于你的知识库问答

借助内置 **知识库（RAG）**，AI 的回答会基于你自己的笔记与文档上下文，而不是泛泛的通用答案。你可以用它总结周报、解释某段资料、跨文档检索要点。

### 4. 迭代式修改与排版

AI 支持多轮对话：创建后追加「把位置挪到右边」「换成柱状图」「接入数据源 ID 为 X 的表」，它会就地更新卡片配置，无需你手动打开配置抽屉。

### 5. 技能与工具扩展（MCP）

通过 AI 设置接入 **Skills** 与 **MCP Tools / Servers**，可以让对话具备专门能力（写报告、查资料、调用外部工具）。相关内容见[扩展中心](./extensions.md)。

## 四、使用技巧

- **描述越具体，结果越准**：说明卡片类型、数据维度、位置与尺寸，AI 一次就能贴近你的预期。
- **给出数据源线索**：想接入真实数据，告诉 AI 数据源 ID 或对应的表 / 指标，它会补上查询配置。
- **用多轮对话打磨**：先让 AI 搭骨架，再逐条微调，比一次写一大段要求更有效。
- **让 AI 读你的资料**：在知识库里准备好笔记，再让 AI 基于它们生成总结或周报，结论与依据同一页面可见。

## 五、安全与隐私

:::caution 不要在对话中提交敏感凭据
不要将数据库密码、API Key、个人隐私等敏感信息直接发到对话输入框。连接生产数据时，优先使用只读账户；相关配置见[系统设置](./system-settings/overview.md)与[数据库](./database.md)。
:::
