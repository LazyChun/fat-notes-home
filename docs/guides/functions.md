# 功能

> 「功能」是把一页里已经搭好的小应用**打包成一个可复用入口**：在页面上用「功能面板」块排好输入框、文本、图表或流程卡片，点一次「构建」，它就出现在活动栏的「功能列表」里——以后一点即开、只读使用，还能用 `Ctrl + K` 把关键词直接搜出来并填进输入框。

本文讲的是应用左侧活动栏里那个 **「功能」模块**（功能列表 + 功能页）。想快速了解 FatNotes 全部能力，请先看 [功能总览](./features.md)。

---

## 一、先分清几个「功能」

「功能」这个词在界面里出现好几次，指的却不是同一件事：

| 名称 | 在哪儿 | 作用 |
| --- | --- | --- |
| **功能面板块** | 组件面板 → **窗口** → 功能面板，放在页面画布上 | 功能的**源**：一个容器块，里面可以放输入框、文本、图表、按钮、流程卡片等子块 |
| **功能记录** | 工作区 `funcs/funcs.json` | 功能的**索引**：记录 ID、名称、描述、标签、源面板、尺寸与时间 |
| **功能页** | 活动栏「功能」→ 单击列表条目 | 功能的**成品**：在页签里只读渲染的画布 |
| **「功能」搜索结果** | `Ctrl + K` 全局搜索 | 功能的**快捷入口**：由查询匹配正则召回，打开源面板并回填输入框 |
| **func 扩展包** | 扩展中心 / FatHub | 功能的**分发形式**：把构建产物打包给别人安装 |

用一张图看完整链路：

![功能的生成与使用链路](pathname:///fat-notes-home/img/instruction/functions/zh/funcs-mechanism.svg)

:::info 功能列表一开始是空的
FatNotes **没有内置功能清单，也没有默认分组**。列表里的每一条都来自你自己的「构建」或安装的 func 扩展包。下文截图中的「自动化工作区」是本机演示工作区里的一条功能记录（名称，不是分组），文中用它当例子。
:::

## 二、认识功能工作区

### 工作台里的位置

活动栏默认有 7 个模块，按顺序从上到下：

| 顺序 | 活动栏入口 | 打开后 | 主要用途 |
| --- | --- | --- | --- |
| 1 | 文件管理 | 文件管理器 | 笔记本、页面树与页面内容 |
| 2 | 搜索 | 搜索侧栏 | 按名称 / 内容检索 |
| 3 | 数据库 | 数据库管理器 | 数据源、表结构与数据浏览 |
| 4 | 扩展 | 扩展中心 | 插件、功能、工作流、技能等目录 |
| 5 | **功能** | **功能列表 + 功能页** | **本文主角：打开自己构建的小应用** |
| 6 | 资源仓库 | 资源仓库 | 图片、音视频等素材 |
| 7 | 运行 | 运行面板 | 正在运行 / 已完成 / 定时运行规则 |

活动栏图标支持**拖动排序**和**右键隐藏**（顺序与隐藏状态会保存），所以你机器上看到的位置不一定和这张表一致。

点开「功能」后，界面分成三块：左侧**功能列表**、右侧**功能页内容区**、顶部贯穿全应用的**全局搜索框**。未选择功能时，右侧显示空态插画与提示「从左侧选择一个功能以查看内容」。

![功能工作区总览，红框标出活动栏「功能」图标、侧栏搜索框、列表条目与空态提示](pathname:///fat-notes-home/img/instruction/functions/zh/funcs-overview.png)

*红框从上到下是：活动栏的扳手「功能」图标、侧栏搜索框（含右侧的标签过滤按钮）、功能条目、右侧空态提示。*

### 功能列表的各个部件

| 部件 | 说明 |
| --- | --- |
| 标题 | 「功能列表」（英文界面为 Functions） |
| 搜索框 | 占位「请输入搜索内容」；按**功能名称 + 描述**过滤，支持**拼音模糊匹配** |
| 标签过滤 | 搜索框右侧那个**长得像铅笔的图标**，悬停提示「选择标签进行过滤」；点开是标签多选面板，可再按名称搜标签 |
| 列表条目 | 功能图标 + 名称 + 最多 2 个标签徽标 + 描述；按最后更新时间倒序 |
| 空态 | 未配置标签时显示「暂无数据」；搜索无结果时显示「暂无搜索结果」 |

![标签过滤弹层，红框标出标签按钮与过滤面板](pathname:///fat-notes-home/img/instruction/functions/zh/funcs-tag-filter.png)

*这个图标**不是编辑按钮**：它只负责过滤。标签来自系统数据里的标签定义，选中多个标签时按「全部命中」筛选；没有给功能打标签时，面板里就是空的。顺带一提，这个提示文案在当前版本固定为中文，英文界面下也显示中文。*

## 三、打开并使用一个功能

| 操作 | 结果 |
| --- | --- |
| **单击**列表条目 | 在**当前页签**打开功能（约 300ms 延迟用于区分双击） |
| **双击**列表条目 | **新开一个页签**打开功能 |
| 拖动 / 关闭页签 | 页签可重新排序、可关闭；最多缓存 10 个功能页签 |
| 在功能页里操作 | 输入框、按钮、图表、联动事件照常可用；**画布本身只读**，不能拖动、缩放、增删块或改配置 |

![打开后的功能页，红框标出功能页签、输入框与结果文本](pathname:///fat-notes-home/img/instruction/functions/zh/funcs-page.png)

*例子「自动化工作区」：页签、面板标题、一个「请输入 Unix 时间戳」输入框，以及显示 `转换结果：$value` 的文本块。功能页按构建时的尺寸只读渲染；`$value` 是变量占位，运行时会被实际值替换。*

:::tip 想改内容？
功能页是**构建时的快照**。要调整块、样式或配置，回到源面板修改并重新点「构建」，功能列表与功能页才会同步。
:::

## 四、从零做一个功能

### 操作步骤

1. **放容器**：打开（或新建）一个面板，从组件面板的**窗口**分类拖入「功能面板」块（默认 24 × 64 网格，可自由缩放）。
2. **填内容**：把需要的块拖进功能面板内部——输入框、文本、按钮、数据表格、图表、流程卡片等。**插件提供的块不能放进功能面板**。
3. **配显示**：在功能面板的显示配置里设置块名（会成为功能名）、Logo、AI 标记中的**描述**与**标签**、面板背景与边框等样式。
4. **配查询匹配**（可选）：给面板里的输入框绑定搜索正则，见下一节。
5. **保存并构建**：先保存页面，再点功能面板右上角的 **构建**。成功后会写入索引、复制面板与图标，功能立刻出现在左侧功能列表里。

![源面板上的功能面板块，红框标出「导出目录」「查询匹配」「构建」](pathname:///fat-notes-home/img/instruction/functions/zh/funcs-build.png)

*红框从左到右：「导出目录」（未设置时提示「构建后不会导出」）、「查询匹配」、「构建」。下方输入框里是查询匹配回填的 `1790000000`，右侧文本块已显示转换结果。*

### 构建会生成什么

| 产物 | 内容 |
| --- | --- |
| `funcs/funcs.json` | 功能主索引，JSON 数组；新增或按 `funcId` 更新一条记录 |
| `funcs/<funcId>/boards/<boardId>.json` | 源面板的副本，功能页从这里读取子块 |
| `funcs/<funcId>/icons/logo.*` | 功能图标（在显示配置里指定 Logo 时复制） |
| 导出目录中的 func 扩展包 | **可选**；仅在设置了导出目录时产出（初始版本 `0.0.1`） |

### 索引字段速查

| 字段 | 说明 |
| --- | --- |
| `funcId` | 功能 ID，**就是功能面板块的 id**，同时作为功能目录名；删掉块重建会得到新 ID |
| `funcName` | 功能名，取功能面板块的标题 |
| `description` / `tags` | 来自块的 AI 标记，分别用于列表描述与标签过滤 |
| `boardId` / `bookId` | 源面板 ID、所属笔记本 |
| `panelW` / `panelH` | 功能面板块的宽高，决定功能页的画布尺寸 |
| `createTime` / `lastUpdatedTime` | 创建 / 最后构建时间；列表按后者倒序 |

## 五、让全局搜索直接把它调出来

「查询匹配」是把功能和 `Ctrl + K` 连起来的关键：为功能面板里的**每个输入框**绑定一条正则。全局搜索的文本一旦命中正则，这条功能就会作为「功能」类型的结果出现；回车后**打开源面板页签，并把搜索文本填进对应输入框**。

![查询匹配弹窗，红框标出输入框下拉与搜索正则](pathname:///fat-notes-home/img/instruction/functions/zh/funcs-search-match.png)

*弹窗里一条规则 = 「选哪个输入框」+「搜索正则」。可以「添加」多条、用右侧垃圾桶删除，最后点「确定」保存。*

| 想搜什么 | 正则示例 | 典型输入 |
| --- | --- | --- |
| 10 位 Unix 时间戳 | `^\d{10}$` | `1790000000` |
| 订单号 | `^SO\d{8}$` | `SO20261105` |
| 手机号 | `^1[3-9]\d{9}$` | `13800138000` |

:::warning 弹窗里的示例写法
弹窗提示中出现的 `^\d{'10'}$` 是模板转义后的显示效果，**实际要填的是 `^\d{10}$`**（本例已验证可用）。正则会被校验合法性，写错会提示「正则表达式无效」；功能面板里没有输入框时无法添加规则。
:::

### 搜索结果长什么样

全局搜索统一检索**文件、插件、功能、工作流、技能、MCP Tool、MCP Server、高级插件、插件集合、插件功能**共 10 类结果，按相关度混合排序，用每条右侧的类型标签区分。`↑/↓` 选择、`Enter` 打开、`Esc` 关闭。

![全局搜索命中功能，红框标出功能结果与「功能」类型标签](pathname:///fat-notes-home/img/instruction/functions/zh/funcs-global-search.png)

*输入 `1790000000` 命中 `^\d{10}$`，结果标题是功能名「自动化工作区」，副标题显示所绑定输入框的占位文本与搜索词，右侧标签为「功能」。*

回车后打开的是**源面板**（不是只读功能页），输入框已被回填；源面板上的流程卡片随之执行，文本块把变量替换成结果：

![全局搜索回车后的源面板，红框标出被回填的输入框与转换结果](pathname:///fat-notes-home/img/instruction/functions/zh/funcs-search-hit.png)

*`1790000000` 自动填入输入框，右侧文本块显示 `转换结果：2026-09-21 22:13:20`。这就是「搜一个词 → 直接得到结果」的完整效果。*

![流程自动化运行演示](pathname:///fat-notes-home/img/features/flow-run.gif)

*同一套时间戳转换流程的运行录屏，可与 [功能总览](./features.md) 中的流程章节对照阅读。*

## 六、管理与分发

### 我的功能

**扩展中心 → 我的功能** 用卡片方式集中查看已构建的功能：

![扩展中心「我的功能」，红框标出功能卡片与导出目录](pathname:///fat-notes-home/img/instruction/functions/zh/funcs-my-funcs.png)

*卡片显示图标、名称、描述、标签、**导出目录**与最后更新时间；顶部支持按名称 / 描述 / 标签搜索。红框里的「导出目录」未设置时提示「未设置，构建后不会导出」。*

| 卡片字段 | 说明 |
| --- | --- |
| 名称 / 描述 / 标签 | 来自功能面板块及其 AI 标记 |
| 导出目录 | 设置后，每次「构建」会把该功能导出为 func 扩展包 |
| 最后更新 | 最近一次构建时间 |

### 分发与个性化

- **FatHub → 功能**：扩展中心里的「功能」分类用于浏览可安装的功能包；工作区功能列表始终以 `funcs/funcs.json` 中的记录为准。
- **活动栏**：图标可拖动排序、右键隐藏，把常用的「功能」放到顺手的位置。
- **功能页签**：可关闭、可拖动排序；功能没有独立 URL 或深链，页签只是当前会话的界面状态，重启后不会自动恢复。
- **设置 → 组件 → 组件添加栏**：这里可以调整「功能」分类里功能项的**顺序与隐藏**，作用对象是**添加块栏**，不是功能列表侧栏，别混淆。

## 七、典型组合

1. **随身小工具（时间戳转换）**：功能面板里放输入框 + 文本，源面板下方放一条 ETL DAG 做转换；查询匹配绑 `^\d{10}$`。之后 `Ctrl + K` 输入 10 位时间戳，一步得到格式化时间。
2. **业务查询台**：功能面板里放输入框 + 查询按钮 + 数据表格 / 图表，查询匹配绑单号正则；搜单号即打开源面板并带入单号，适合客服、运维高频查询。
3. **团队复用**：在「我的功能」里给功能设置导出目录 → 重新「构建」产出 func 扩展包 → 交给同事在扩展中心安装，把一次性搭的小应用变成团队工具。

## 八、注意事项

- **功能列表初始为空**，没有内置功能或默认分组；`funcs.json` 不存在时列表返回空。看到「自动化工作区」这类名字，是工作区里的一条功能记录。
- **改了源面板必须重新构建**：功能页、图标、描述、标签都是构建时的快照，不会自动跟着源面板变。
- **构建前先保存页面**：构建读的是磁盘上的面板文件；未保存的改动不会被带进功能。
- **功能页只读**：能输入、能点按钮、能看联动结果，但不能改结构；需要编辑请回源面板。
- **查询匹配只认功能面板内的输入框**：删除输入框后规则会提示「输入框已删除」；正则要写得足够精确，过宽会把无关搜索词也召回来。
- **标签过滤是「全部命中」**：选多个标签取交集；那个像铅笔的图标是标签过滤，不是新建 / 编辑功能。
- **没有 URL 深链**：功能靠活动栏 + 列表 + 页签打开，`Ctrl + K` 的「功能」结果打开的是源面板。
- **定时调度作用于工作区面板**：[定时任务](./scheduled-tasks.md) 调度的是面板里的工作流卡片，不是功能页签；想定时跑，请把流程卡片留在源面板上。
- **构建可能带副作用**：若设置了导出目录，构建会写文件 / 产出扩展包；正式分发前先确认目录与版本号。
