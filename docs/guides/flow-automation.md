# 流程自动化

流程编辑器将任务拆分为可连接的节点。一个流程通常包含触发器、处理步骤、条件分支与输出动作。

## 常见场景

- 定时查询数据库并生成报告。
- 对表格数据执行清洗、转换与汇总。
- 调用 HTTP 服务并保存响应结果。
- 通过 OCR、键鼠或浏览器节点处理重复操作。
- 将知识检索结果交给 AI 节点继续处理。

## 设计可靠流程

1. 每个流程只负责一个清晰目标。
2. 为外部调用设置合理的超时和失败分支。
3. 在修改数据前记录输入并验证处理结果。
4. 先用测试数据运行，再连接正式环境。

:::warning 自动化风险
屏幕自动化和数据写入可能产生不可逆操作。运行前应确认目标窗口、账户权限和数据备份。
:::
