# 系统设置总览

> 设置是 FatNotes 的**全局配置中心**：这里改的不是某一页、某一本书，而是整个应用的行为与外观。理解「哪些设置立即生效、哪些要重启、哪些只影响新建的卡片」，能避免大部分「改了没反应」的困惑。

系统设置共 **3 个分组、13 个页面**：基础设置管运行参数与外观，系统数据管全局字典，组件配置管表单校验、图标与组件添加栏。本文先讲清入口、界面结构和生效规则，再给出按主题展开的详细章节。

## 一、如何打开设置

点击窗口**左下角的齿轮图标**（活动栏最底部），即可进入设置页；也可以从顶部右侧的管理菜单里选择「设置」。进入后左侧活动栏保持不变，中间变为「设置目录树 + 配置区」的双栏布局。

![点击左下角齿轮进入设置，红框标注入口](pathname:///fat-notes-home/img/instruction/settings/settings-entry.png)

*红框为设置入口：左下角齿轮。点击后整个工作区切换为设置页，仍可随时点左侧其他图标回到笔记、数据库或插件页面。*

![设置页布局：左侧目录树与右侧配置区](pathname:///fat-notes-home/img/instruction/settings/settings-catalog.png)

*左侧红框是设置目录树（3 个分组 + 若干子项），右侧红框是配置区（当前选中的是「系统数据 → 变量」）。点击目录项即切换右侧内容，不需要额外保存确认。*

:::tip 两个容易混淆的入口
左下角齿轮**上方**还有一个 AI 图标，它打开的是「AI 设置」（模型、记忆、MCP、TTS、ASR、Agent 策略），与本文的系统设置是两套独立页面。此外，已安装的插件可以向目录里追加自己的设置页，它们会出现在「高级插件」分组下。
:::

## 三、三类生效逻辑（最重要）

设置项「改完没有变化」，几乎都能用下面三条解释。

| 类型 | 涉及页面 | 具体表现 |
| --- | --- | --- |
| **立即生效** | 语言、颜色、大屏、文件导出、系统数据、组件配置 | 保存（或切换开关）后界面、候选色、字典数据马上更新；已经打开的页面通常也能立刻读到新值 |
| **重启生效** | 启动端口 | 端口属于进程启动参数，保存后只写入配置，必须重启 FatNotes；页面会提示「端口已修改为 XXXX，重启应用后生效」 |
| **只影响新建** | 组件样式 | 保存的是「新建卡片的默认值」，已经存在的卡片不会被回溯修改；文本、表单等自带透明背景或特殊内边距的卡片还会保留各自的设置 |

还有两条补充规则：

- **全局性**：设置属于应用级配置，不随书、页面或数据源切换；在任何页面打开设置，改的都是同一份配置。
- **浮层例外**：组件样式里的「浮层」默认值只作用于带浮层的图表卡片（折线图、饼图、雷达图、热力图、K 线图等），普通容器块不会用到。

## 四、通用操作

不同页面长得不一样，但操作方式是统一的：

1. **切换页面**：点左侧目录项；右侧内容即时替换，未保存的修改不会自动保留。
2. **表单类页面**（启动端口、组件样式、颜色）：修改控件 → 点底部「保存」。按钮在未做任何修改时是灰色禁用状态；旁边的「恢复默认」把本页或本组配置还原为出厂值。
3. **开关类页面**（语言、大屏、文件导出）：点击选项或开关即生效，通常没有单独的保存按钮。
4. **表格类页面**（系统数据、校验规则、图标管理、组件添加栏、轮播列表）：右上角「添加…」按钮打开弹窗或抽屉 → 填写字段 → 「确定」；每行「操作」列提供编辑、删除、应用等动作，删除会弹出确认提示。
5. **筛选与分页**：国际化文本可按前缀 / 文本 / 标签过滤；图标管理可按「全部类型」筛选，默认每页 10 条。

:::caution 删除前先确认引用
系统变量、标签、成员、校验规则都属于可被页面 / 组件引用的全局数据。删除后，引用它们的查询、表单或卡片可能失去取值或校验能力，删除前建议先在工作区里检查使用情况。
:::

## 五、推荐配置顺序

新装 FatNotes 或准备把环境交给同事时，按下面顺序配置最省心：

1. **语言** — 先确定界面语言，后续所有说明文字都按这个语言显示。
2. **启动端口** — 需要固定端口给外部脚本 / 插件调用时再改，改完记得重启；一般保持「自动分配端口」即可。
3. **组件样式** — 在建大量卡片**之前**定好外框与浮层默认值，一次设置，之后新建的卡片自动统一。
4. **颜色** — 按团队视觉规范整理推荐色，之后所有颜色选择器都会用这份候选色板。
5. **系统数据 / 组件配置** — 按需录入变量、标签、成员、国际化文本，配置校验规则、图标与添加栏布局。
6. **大屏 / 文件导出** — 有投屏、轮播汇报或导出需求时再开启，避免右上角图标过多。

## 六、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 改了端口，地址还是原来的 | 端口需重启应用才生效；若目标端口被占用，应用会自动换用可用端口并给出提示，配置值本身不变 |
| 改了组件样式，旧卡片没变化 | 该设置只作用于之后新建的卡片；旧卡片请在块自身的配置里单独调整 |
| 「保存」按钮点不动 | 表单未发生修改时按钮禁用；修改任意控件后即可点击 |
| 右上角没有大屏 / 导出图标 | 对应开关未开启，去「大屏」「文件导出」页勾选 |
| 设置目录里多了没见过的项 | 已安装的插件可以注册自己的设置页，通常出现在「高级插件」分组 |
| 切换英文后部分文案仍是中文 | 「语言」同时作用于界面与系统文案；用户自建的笔记内容、自定义国际化文本需要自己维护中英两份 |
