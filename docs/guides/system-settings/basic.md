# 基础设置

> 「基础设置」决定 FatNotes **怎么运行、长什么样、如何展示和交付成果**：两个服务端口、界面语言、全局推荐色、新建卡片的默认外观，以及大屏与导出这两个演示出口。6 个页面彼此独立，改完互不影响。

| 页面 | 一句话作用 | 生效时机 |
| --- | --- | --- |
| 启动端口 | 固定或自动分配后端 / UI 服务端口 | 重启应用后 |
| 语言 | 切换简体中文 / English | 立即 |
| 颜色 | 维护外框与浮层的推荐色板 | 保存后立即 |
| 组件样式 | 定义新建卡片的外框与浮层默认值 | 仅之后新建的卡片 |
| 大屏 | 开启全屏预览与轮播，管理轮播列表 | 立即（右上角出现图标） |
| 文件导出 | 开启 PDF / PNG 导出入口 | 立即（右上角出现图标） |

## 启动端口

FatNotes 本机同时运行两个服务：**后端 API 服务**（默认 8022）和 **UI 服务**（默认 8888，也就是浏览器访问的地址）。这一页分别管理两者。

![启动端口设置页，红框标注后端服务端口配置区与保存按钮](pathname:///fat-notes-home/img/instruction/settings/settings-basic-port.png)

*上半部分为后端服务端口，下半部分为 UI 服务器端口；红框标出后端整块配置与底部「保存」按钮。*

### 字段与控件

| 分区 | 字段 | 控件 / 可选值 | 说明 |
| --- | --- | --- | --- |
| 后端服务端口 | 自动分配端口 | 开关（默认开启） | 开启后使用默认端口 **8022**；端口被占用时自动切换可用端口 |
| 后端服务端口 | 自定义端口 | 输入框（必填） | 关闭自动分配后可填写，界面显示当前配置值（如 8022） |
| 后端服务端口 | 当前运行端口 | 只读文本 | 显示本次启动实际使用的端口，例如 8022 |
| UI服务器端口 | 自动分配端口 | 开关（默认开启） | 开启后使用默认端口 **8888**；被占用时自动切换 |
| UI服务器端口 | 自定义端口 | 输入框（必填） | 关闭自动分配后可填写 |
| UI服务器端口 | 当前运行端口 | 只读文本 | 显示本次启动实际使用的端口，例如 8888 |
| 底部 | 保存 | 按钮 | 写入配置；未修改时禁用 |

### 操作步骤

1. 打开「基础设置 → 启动端口」，先看「当前运行端口」确认本次启动实际用的端口。
2. 需要固定端口时，关闭对应分区的「自动分配端口」，在「自定义端口」填入端口值。
3. 点「保存」。页面提示「端口已修改为 XXXX，重启应用后生效」。
4. 重启 FatNotes，用新端口访问（例如 UI 端口改为 9000 后访问 `http://127.0.0.1:9000/`）。

### 生效范围与注意事项

- 端口是**进程启动参数**，保存只写配置，不重启不会变；两个端口可以分别设置。
- 若目标端口被占用，应用会给出「端口 XXXX 已被占用，本次启动已自动使用端口 YYYY（配置值未修改）」的提示——这是自动分配的保护行为，配置里仍保留你填的值。
- 改 UI 端口后，浏览器书签、外部脚本、插件里写死的地址都要同步；改后端端口会影响直接调用 API 的集成。
- 日常单机使用建议保持「自动分配端口」开启，省去端口冲突排查。

## 语言

![界面语言设置页，红框标注语言切换区](pathname:///fat-notes-home/img/instruction/settings/settings-basic-language.png)

*红框内为语言切换控件：简体中文（当前选中）与 English，下方是生效说明。*

| 字段 | 可选值 | 说明 |
| --- | --- | --- |
| 界面语言 | 简体中文 / English | 点击即切换，按钮高亮表示当前语言 |
| 生效说明 | 只读文本 | 「切换后立即生效，将同时应用于界面与系统文案」 |

- **立即生效**，不需要重启，也不需要点保存。
- 同时作用于**界面控件**与**系统内置文案**（菜单、提示、错误信息等）；用户自己写的笔记内容不会被翻译。
- 选择会记在本地，下次启动沿用；非法或缺失的语言值会回退到简体中文。
- 需要和「系统数据 → 国际化文本」配合：后者维护的是你自己定义的双语词条，切换语言时按词条的中 / 英文本显示。

## 颜色

「颜色」维护的是**推荐色板**：配置外框与浮层各部位的候选颜色。之后在任意颜色选择器里挑颜色时，出现的就是这份候选色，保存后立即生效。

![推荐颜色上半部分：外框三组与浮层第一组，红框标注说明区与第一组色板](pathname:///fat-notes-home/img/instruction/settings/settings-basic-colors-1.png)

*上半部分：页面说明 + 外框-背景颜色（红框）等色板组。每组由色块、`+` 添加按钮、计数与「恢复默认」组成。*

![推荐颜色下半部分：其余浮层色板组与保存按钮](pathname:///fat-notes-home/img/instruction/settings/settings-basic-colors-2.png)

*下半部分：浮层-关键字体、浮层-字体、浮层-边框颜色，底部红框为「保存」按钮（未修改时呈禁用灰色）。*

### 7 组推荐色

| 色板组 | 用途 | 默认数量示例 |
| --- | --- | --- |
| 外框-背景颜色 | 卡片外框的背景候选色 | 21 / 64 |
| 外框-标题颜色 | 卡片标题文字的候选色 | 18 / 64 |
| 外框-边框颜色 | 卡片边框的候选色 | 21 / 64 |
| 浮层-背景颜色 | 图表提示浮层的背景候选色 | 30 / 64 |
| 浮层-关键字体 | 浮层中重点数值 / 文字的颜色 | 30 / 64 |
| 浮层-字体 | 浮层普通文字的颜色 | 30 / 64 |
| 浮层-边框颜色 | 浮层边框的候选色 | 21 / 64 |

### 控件与规则

| 控件 | 说明 |
| --- | --- |
| 色块 | 当前推荐色，点击或悬停可移除；第一个透明格表示透明色 |
| `+` 添加颜色 | 打开颜色选择器，追加一个候选色；重复颜色会被拒绝，格式无效会提示 |
| `n / 64` 计数 | 已配置数量 / 上限，**每组最多 64 个** |
| 恢复默认 | 只把**这一组**还原为系统默认色板 |
| 保存 | 把全部 7 组一次性写入配置，保存后立即生效 |

### 操作步骤与建议

1. 打开「基础设置 → 颜色」，按外框 / 浮层分类定位要调整的色板组。
2. 点组内 `+` 添加团队品牌色，或点已有色块移除不用的颜色。
3. 需要还原某一组时点该组的「恢复默认」，不影响其他组。
4. 点底部「保存」，之后所有颜色选择器都会使用新色板。

:::tip 配色建议
把「组件样式」理解成**默认的那个颜色值**，把「颜色」理解成**给用户挑的候选色列表**：先在这里收敛候选色，再在组件样式里挑一个作为新建卡片的默认值，团队视觉规范最容易落地。
:::

## 组件样式

「卡片默认样式」是整套设置里字段最多的一页：定义**之后新建的卡片**外框与浮层长什么样。它分「外框」「浮层」两个可折叠分区。

![卡片默认样式上半部分：说明文字与外框分区](pathname:///fat-notes-home/img/instruction/settings/settings-component-style-1.png)

*红框分别标出顶部作用范围说明、以及「事件标签」下拉。外框分区包含背景颜色、标题位置、阴影、内边距、边宽、圆角弧度与事件标签。*

![卡片默认样式下半部分：浮层分区与保存 / 恢复默认按钮](pathname:///fat-notes-home/img/instruction/settings/settings-component-style-2.png)

*红框为底部「保存 / 恢复默认」按钮组（未修改时禁用）。上方是浮层的内边距、边宽、圆角弧度等字段。*

### 外框分区字段

| 字段 | 控件 | 说明 |
| --- | --- | --- |
| 背景颜色 | 调色板 | 新建卡片外框的默认背景色，候选色来自「颜色」页 |
| 标题位置 | 左 / 居中 / 右对齐 + 粗体 B / 斜体 I / 字体颜色 A | 卡片标题的对齐与字形，默认居中 |
| 开启阴影 | 开关 | 是否给卡片外框加投影 |
| 内边距 | 上 / 右 / 下 / 左，单位 px | 内容与边框的间距，默认 8 |
| 边宽 | 颜色 + 宽度 + 方位下拉（全部）+ 添加按钮 | 边框粗细、颜色与作用方位，可分别设置四边 |
| 圆角弧度 | 全部方位 / 上左 / 上右 / 下左 / 下右，单位 px | 统一或分角设置圆角 |
| 事件标签 | 多选下拉「选择要隐藏的事件」 | 隐藏卡片上不需要显示的事件标签 |

### 浮层分区字段

| 字段 | 控件 | 说明 |
| --- | --- | --- |
| 展示 | 开关（默认开启） | 是否显示图表浮层 |
| 类型 | 下拉（显示全部 等） | 浮层内容的展示范围 |
| 关键字体 | 字体选择 + 粗体 / 斜体 + 颜色 | 重点数值、类目名的字形 |
| 字体 | 字体选择 + 粗体 / 斜体 + 颜色 | 浮层普通文字的字形 |
| 开启阴影 | 开关 | 浮层投影 |
| 内边距 | 上 / 右 / 下 / 左，单位 px | 浮层内部留白 |
| 边宽 | 颜色 + 宽度 + 方位下拉 | 浮层边框 |
| 圆角弧度 | 全部方位 / 四角，单位 px | 浮层圆角 |

### 作用范围（务必读一遍）

页面顶部的说明原文是理解这页的钥匙：

> 配置新建卡片外框与浮层的默认值，保存后**对之后新建的卡片生效，已有卡片不受影响**。文本、表单等自带透明背景或特殊内边距的卡片会**保留各自的设置**；浮层默认值作用于**折线图、饼图、雷达图、热力图、K线图等带浮层的卡片**。

也就是说：

- 已经建好的卡片不会变，要改请到块自己的配置里改（见[公共配置](../system-components/common-config.md)）。
- 文本、表单这类自带透明背景 / 特殊内边距的块，会保留自己的设置，不被这里的外框值覆盖。
- 浮层设置只对带图表浮层的卡片有意义，普通容器块用不到。
- 底部「保存」写入配置，「恢复默认」还原整页；两者在未修改时都是禁用状态。

### 操作步骤

1. 在**大量建卡片之前**打开这一页，先定外框：背景色、标题对齐、阴影、内边距、边框与圆角。
2. 再定浮层：是否展示、字形、颜色、内边距与边框。
3. 点「保存」，然后新建一张图表卡片验证效果。
4. 效果不理想时点「恢复默认」重来；旧卡片请单独调整。

## 大屏

「大屏」把当前仪表文件投到全屏，用于汇报、值守或展厅。它由两个开关和一个轮播列表组成。

![大屏设置页，红框标注两个开关说明区与新建轮播按钮](pathname:///fat-notes-home/img/instruction/settings/settings-basic-bigscreen.png)

*上方红框是两个开关及其说明，下方为轮播列表，右上角是「新建轮播」按钮。*

### 开关与列表

| 项目 | 说明 |
| --- | --- |
| 开启大屏预览 | 开启后窗口**右上角出现大屏预览图标**；点击后 FatNotes 铺满全屏，并以**预览模式**显示当前打开的仪表文件（只渲染、不可编辑） |
| 开启大屏轮播 | 开启后右上角出现**轮播图标**；点击后选择一个轮播，进入全屏并按顺序切换仪表文件 |
| 轮播列表 | 表格列：名称 / 轮播文件 / 切换间隔 / 操作；空状态提示「还没有轮播，点击右上角新建」 |
| 新建轮播 | 打开轮播编辑弹窗 |

![新建轮播弹窗：名称、切换间隔与轮播文件勾选列表](pathname:///fat-notes-home/img/instruction/settings/settings-modal-carousel.png)

*弹窗里可勾选要播放的仪表文件；提示写明「下方列表的顺序就是播放顺序，可以拖拽调整」。*

### 新建轮播的字段

| 字段 | 控件 | 说明 |
| --- | --- | --- |
| 名称 | 输入框 | 轮播方案名称，用于在右上角图标里选择 |
| 切换间隔 | 数字 + 秒 | 每个仪表文件停留多久 |
| 轮播文件 | 勾选列表（可拖拽排序） | 从工作区已有仪表文件中勾选；列表顺序即播放顺序 |
| 取 消 / 确 定 | 按钮 | 未选择文件时底部提示「还没有选择文件」 |

### 使用路径

1. 打开「基础设置 → 大屏」，按需要开启「大屏预览」或「大屏轮播」。
2. 需要轮播时点「新建轮播」，填名称与切换间隔，勾选仪表文件并拖拽排序，点「确定」。
3. 回到工作区，先打开一个仪表文件，再点右上角对应图标进入全屏。
4. 预览模式只渲染不可编辑，适合投屏；退出全屏后回到正常编辑状态。

## 文件导出

![文件导出设置页，红框标注 PDF 与图片两个勾选项](pathname:///fat-notes-home/img/instruction/settings/settings-basic-export.png)

*红框内为两个导出方式及其说明，勾选后窗口右上角才会出现导出图标。*

| 选项 | 说明 |
| --- | --- |
| PDF | 将**当前打开的仪表文件**导出为 PDF |
| 图片 | 将当前打开的仪表文件导出为 **PNG 图片** |

触发规则（页面顶部说明原文）：

> 勾选后，窗口右上角会出现导出图标。**只勾选一项时**，点击图标直接导出当前打开的仪表文件；**两项都勾选时**，点击图标后选择导出为图片或 PDF。

- 开关即时生效，没有单独的保存按钮。
- 导出对象是「当前打开的仪表文件」，不是整本书；想导出别的文件请先切换过去。
- 大屏预览 + 文件导出常常一起用：投屏展示，结束后导出 PDF / PNG 存档或发给同事。

## 配置速查

| 我想…… | 去哪一页 | 关键动作 |
| --- | --- | --- |
| 让外部脚本用固定地址访问 | 启动端口 | 关闭自动分配 → 填端口 → 保存 → 重启 |
| 把界面切成英文 | 语言 | 点 English，立即生效 |
| 统一团队可选颜色 | 颜色 | 7 组色板增删 → 保存 |
| 让新建卡片自动符合视觉规范 | 组件样式 | 外框 / 浮层逐项设置 → 保存 |
| 投屏或轮播看板 | 大屏 | 开启开关 → 新建轮播 → 右上角图标 |
| 把看板存成 PDF / PNG | 文件导出 | 勾选 PDF / 图片 → 右上角图标 |

## 注意事项

- 端口改动**必须重启**；组件样式改动**不回溯**已有卡片，这是两个最常被误判为「没生效」的地方。
- 「颜色」是候选色板，「组件样式」是当前默认值，两者是配合关系而非替代关系。
- 大屏与导出的入口都在窗口**右上角**，开启前那里不会出现图标。
- 表单页的「保存 / 恢复默认」在未修改时禁用，属正常现象；修改任意控件后即可点击。
- 预览模式只渲染不编辑，若发现全屏后点不动块，说明正处于大屏预览模式，退出即可。
