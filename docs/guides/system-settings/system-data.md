# 系统数据

> 「系统数据」是**全局字典**：变量存常量、标签做分类、成员记联系人、国际化文本提供中英双语文案。它们不属于某一页，也不随书切换，改一处整个工作区都能读到新值。

四张表采用完全相同的操作方式，先讲通用流程，再逐页说明字段与用途。

## 通用操作：增删改查

| 动作 | 操作 | 说明 |
| --- | --- | --- |
| 新增 | 点右上角「添加变量 / 添加标签 / 添加成员 / 添加 / 新建…」 | 弹出编辑弹窗，填写字段后点「确定」；新增成功会提示 |
| 编辑 | 行尾「编 辑」 | 弹窗回填原值，修改后「确定」 |
| 删除 | 行尾「删 除」 | 弹出「确定删除该项？」确认，确认后从全局字典移除 |
| 查看 | 表格 | 表头即字段名；国际化文本额外支持过滤，图标管理支持分页 |
| 生效 | — | 保存后立即生效，无需重启；首次进入设置页时应用会自动拉取这份配置 |

:::caution 删除是全局操作
变量、标签、成员、词条都可能被页面、流程或插件引用。删除前先确认没有地方在用它：标签常用于成员与功能卡片分类，变量常被流程与查询当作参数源，词条则直接决定界面上显示的文案。
:::

## 变量

「系统变量」是一张 **名称 / 值 / 描述** 的键值表，用来集中存放会被多处使用的常量。

![系统变量列表，红框标注「添加变量」按钮与行内操作列](pathname:///fat-notes-home/img/instruction/settings/settings-data-variables.png)

*列表显示变量名称、值、描述与操作列；红框标出右上角新增入口和行内「编 辑」。示例数据里有「小狗 / 哈哈哈哈 / 你好啊」「张姓 / 张 / 姓张的人」两条。*

![添加变量弹窗：名称、值、描述](pathname:///fat-notes-home/img/instruction/settings/settings-modal-variable.png)

*新增 / 编辑共用同一个弹窗，三个字段对应表格三列。*

### 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 名称 | 是 | 变量的标识，建议用简短、可读、不易重复的命名 |
| 值 | 否（占位可空） | 变量内容，按文本保存 |
| 描述 | 否 | 用途备注，方便团队理解这个变量是干什么的，界面提示「请输入描述（可选）」 |

### 用途与建议

- 把**会变但又被多处使用**的值集中管理：例如部门名、阈值、默认地区、接口前缀。修改一次，所有引用它的地方随之更新，避免逐页翻找硬编码。
- 配合流程自动化、查询条件与页面内变量使用；具体引用语法以所用组件或插件的说明为准。
- 名称相当于键，建议先定命名规范（如 `sales.target.q3`）再录入，后期维护成本最低。
- 描述字段别省：半年后回来看表，能省下大量猜测。

## 标签

「系统标签」是**名称 + 颜色**的全局分类字典，给其他对象打标记用。

![系统标签列表，红框标注「添加标签」按钮](pathname:///fat-notes-home/img/instruction/settings/settings-data-tags.png)

*表格列出标签名称与操作列；红框为右上角「添加标签」入口。示例数据里有「好玩」这一个标签。*

![添加标签弹窗：名称、颜色](pathname:///fat-notes-home/img/instruction/settings/settings-modal-tag.png)

*新增 / 编辑弹窗只有两个字段：名称与颜色。*

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 名称 | 是 | 标签显示文字，如「重点」「待复核」 |
| 颜色 | 否 | 标签的显示色，用于在列表、选择器里快速区分 |

### 用途与建议

- **成员**可以关联多个标签，用来标注组别、角色或技能。
- **国际化文本**支持按标签过滤，便于按模块批量管理词条。
- 功能卡片、扩展页等位置的标签选择器读的也是这份字典。
- 先规划一组稳定、颜色语义一致的标签（红=紧急、蓝=信息、绿=完成），比随用随建更好维护。

## 成员

「系统成员」是一张轻量通讯录，保存姓名与联系方式，并可关联前面定义的标签。

![系统成员列表，红框标注「添加成员」按钮与空状态](pathname:///fat-notes-home/img/instruction/settings/settings-data-members.png)

*表头为名称 / 电话 / 邮箱 / 标签 / 操作；当前无数据时显示「暂无数据」。*

![添加成员弹窗：名称、电话、邮箱、标签](pathname:///fat-notes-home/img/instruction/settings/settings-modal-member.png)

*标签字段为多选，占位提示「请选择标签（可选）」，选项来自「系统标签」。*

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 名称 | 是 | 成员姓名或显示名 |
| 电话 | 否 | 联系方式，占位提示「请输入电话（可选）」 |
| 邮箱 | 否 | 邮箱地址，会做格式校验，错误时提示「请输入正确的邮箱格式」 |
| 标签 | 否 | 从系统标签中多选，用于分组筛选 |

### 用途与建议

- 适合记录看板负责人、数据审核人、值班联系人等信息。
- 与「标签」联动：先建好角色标签，再给成员打标，之后按标签筛人。
- 邮箱填写要规范，格式不合法无法通过表单校验。

## 国际化文本

这是四页里最特殊的一张表：它维护**应用运行时使用的动态文案**，可以覆盖或补充系统内置语言包，并随「基础设置 → 语言」的切换显示中文或英文。

![国际化文本列表，红框标注过滤条件与「添加」按钮](pathname:///fat-notes-home/img/instruction/settings/settings-data-i18n.png)

*表格列：ID / 前缀 / 中文文本 / 英文文本 / 标签 / 创建时间 / 更新时间 / 操作；红框标出「按前缀过滤」「按标签过滤」与右上角「添加」。*

![添加国际化文本弹窗：前缀、中文文本、英文文本、标签](pathname:///fat-notes-home/img/instruction/settings/settings-modal-i18n.png)

*标签输入方式为「输入标签后回车」，可给词条打多个标记便于分组管理。*

### 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| ID | 是（表格列） | 词条标识，与前缀拼成完整键名 |
| 前缀 | 是 | 命名空间的键前缀，占位提示「请输入前缀，如 app.home」 |
| 中文文本 | 是 | `zh_CN` 下显示的内容 |
| 英文文本 | 是 | `en_US` 下显示的内容 |
| 标签 | 否 | 输入后回车添加，支持按标签过滤 |
| 创建时间 / 更新时间 | 自动生成 | 表格里的审计列，不需要填写 |

### 键名规则与显示逻辑（重点）

应用会把词条合并进当前语言的文案表，规则如下：

1. 完整键名 = `前缀.ID`，例如前缀 `app.home` + ID `title` → `app.home.title`。前缀或 ID 为空的词条不会生效。
2. 当前语言为**简体中文**时取「中文文本」，为 **English** 时取「英文文本」。
3. 若当前语言的文本为空，会**回退显示另一种语言**的文本；两种都为空则词条被忽略。
4. 词条与内置语言包合并，因此可以用相同键名覆盖系统默认文案，也可以新增自定义文案键。

### 过滤与维护

- 顶部支持**按前缀过滤**、**按中文/英文文本过滤**、**按标签过滤**；模块多时建议统一前缀，例如 `sales.*`、`ops.*`。
- 编辑后会刷新「更新时间」；新增词条排在列表前面。
- 改动即时合并进文案表，切换「基础设置 → 语言」即可验证中英两种效果。

:::tip 什么时候用国际化文本
- 想把界面上的某个内置提示改成团队说法；
- 自己写的块或插件需要按语言显示不同文案；
- 同一套工作区要交付给中英文两套使用者。

纯笔记内容不需要走这里——它不会被自动翻译，自己维护中英两个版本即可。
:::

## 配置速查

| 页面 | 字段 | 必填项 | 表格列 |
| --- | --- | --- | --- |
| 变量 | 名称 / 值 / 描述 | 名称 | 名称、值、描述、操作 |
| 标签 | 名称 / 颜色 | 名称 | 名称、操作 |
| 成员 | 名称 / 电话 / 邮箱 / 标签 | 名称（邮箱需符合格式） | 名称、电话、邮箱、标签、操作 |
| 国际化文本 | ID / 前缀 / 中文文本 / 英文文本 / 标签 | 前缀、中文文本、英文文本 | ID、前缀、中文文本、英文文本、标签、创建时间、更新时间、操作 |

## 典型组合

一个「团队协作看板」通常会这样把四张表串起来：

1. 在**标签**里建「数据组」「运营组」「审核」三个分类并配好颜色。
2. 在**成员**里录入负责人，按组别打上标签。
3. 在**变量**里存放默认地区、目标值等常量，供查询与流程读取。
4. 在**国际化文本**里用统一前缀（如 `team.dashboard.*`）维护标题与提示的中英双语文案。
5. 切换「基础设置 → 语言」验证两套文案；按标签过滤词条，确认模块级文案齐全。

## 注意事项

- 系统数据是**应用级**配置，不属于任何一本书；换书、换页面不会丢，也不会各自保存一份。
- 删除前检查引用，尤其是被成员关联的标签、被流程读取的变量。
- 国际化文本的完整键名是 `前缀.ID`，不是只有 ID；前缀或 ID 为空的词条会被跳过。
- 词条中英任一为空时会回退到另一种语言，不代表「留空即隐藏」。
- 成员邮箱有格式校验；电话、描述、标签等可选字段留空不会影响保存。
