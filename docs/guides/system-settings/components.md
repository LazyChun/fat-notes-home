# 组件配置

> 前两组设置管「应用怎么跑、有哪些数据」，**组件配置**管的是「搭页面时手上有哪些工具、工具好不好用」：表单怎么校验、能选哪些图标、组件面板里显示什么。

三页分别对应**规则库、图标库、面板布局**，都是全局生效，且都以「表格 + 添加弹窗 / 抽屉」的方式操作。

| 页面 | 管理对象 | 典型场景 |
| --- | --- | --- |
| 校验规则 | 可复用的表单校验函数 | 必填、格式、业务规则统一校验 |
| 图标管理 | 内置与自定义图标 | 按钮、菜单、卡片用统一图标 |
| 组件添加栏 | 多套组件面板布局 | 给不同角色精简组件面板 |

## 校验规则

「校验规则」把表单校验逻辑做成**可复用的命名规则**：起一个名字、写一段校验函数、配好报错提示，之后表单类块就能选用它，不必在每个输入框里重复写判断。

![校验规则列表，红框标注「添加规则」按钮](pathname:///fat-notes-home/img/instruction/settings/settings-comp-validate.png)

*表头为名称 / 描述 / 报错提示 / 校验函数 / 操作；红框是右上角「添加规则」。当前列表为空时显示「暂无数据」。*

![添加规则弹窗：名称、描述、报错提示与代码编辑器](pathname:///fat-notes-home/img/instruction/settings/settings-modal-rule.png)

*弹窗下半部分是带行号的代码编辑器，已经预填了一段默认校验函数模板。*

### 字段

| 字段 | 说明 |
| --- | --- |
| 名称 | 规则名，在表单块里选择规则时显示 |
| 描述 | 规则用途备注 |
| 报错提示 | 校验不通过时展示给使用者的文案，会作为参数 `errorMsg` 传入函数 |
| 校验函数 | JavaScript 函数体，在代码编辑器里编写 |

### 默认函数模板

新建规则时，编辑器里预填的是「必填校验」模板：

```js
(_rule, oldValue, errorMsg) => {
  if (!oldValue) {
    return Promise.reject(errorMsg || "校验失败");
  }
  return Promise.resolve();
};
```

三个参数的含义：

| 参数 | 含义 |
| --- | --- |
| `_rule` | antd 表单传入的规则对象，一般不用 |
| `oldValue` | 当前输入值 |
| `errorMsg` | 你在「报错提示」里填的文案 |

约定很简单：**通过就返回 `Promise.resolve()`，不通过就 `Promise.reject(提示文案)`**。把 `if (!oldValue)` 换成正则、长度、范围或跨字段判断，就能得到格式校验、数值区间校验等自定义规则；`errorMsg` 让你把提示文案留在表单配置里，函数只负责逻辑。

### 操作步骤

1. 打开「组件配置 → 校验规则」，点「添加规则」。
2. 填名称、描述、报错提示。
3. 在代码编辑器里修改默认模板，或粘贴自己的校验函数。
4. 点「确定」保存；回到表单类块（输入框、下拉框、单选等）的配置里选用这条规则并验证效果。

:::caution 函数错误会让校验异常
校验函数运行在页面里，语法错误或抛异常会导致表单无法正常校验。建议先在编辑器里确认括号、返回值完整，再保存；规则改动会影响所有引用它的表单块。
:::

## 图标管理

「图标管理」是全局图标库：内置图标开箱可用，也可以上传自己的 SVG / 图片，供按钮、菜单、卡片等位置的图标选择器统一调用。

![图标管理列表，红框标注「添加图标」按钮与分页控件](pathname:///fat-notes-home/img/instruction/settings/settings-comp-icons.png)

*表头为图标 / 图标名称 / 描述 / 类型 / 操作；红框分别标出右上角「添加图标」与底部分页（默认 10 条/页）。内置图标按名称排序，页数很多。*

![添加图标弹窗：图标名称、描述与上传区](pathname:///fat-notes-home/img/instruction/settings/settings-modal-icon.png)

*上传区支持「拖拽到此处或点击选择文件」，标注「上传SVG/图片」。*

### 页面控件

| 控件 | 说明 |
| --- | --- |
| 全部类型 | 按类型筛选图标（内置 / 自定义等） |
| 添加图标 | 打开新增弹窗 |
| 表格 | 图标预览、图标名称、描述、类型、操作（编 辑 / 删 除） |
| 分页 | 默认 10 条/页，内置图标数量多，可用页码跳转 |

### 新增图标字段

| 字段 | 说明 |
| --- | --- |
| 图标名称 | 图标在选择器里显示的名称，建议与用途一致，例如 `sales-report` |
| 描述 | 用途备注，可留空 |
| 图标 | 上传 SVG / 图片，支持拖拽文件到上传区或点击选择 |

### 使用建议

- 先按「全部类型」筛选，确认是否已有可用图标，避免重复上传。
- 自定义图标优先用 SVG，缩放不失真；名称保持统一前缀便于检索。
- 表格里内置图标也带有编辑 / 删除操作，批量清理前请确认没有组件正在使用。

## 组件添加栏

「组件添加栏」决定**搭页面时右侧组件面板显示哪些分类、组件与功能，以及它们的顺序**。它支持保存多套配置，适合给不同角色或不同项目切换不同的面板。

![组件添加栏设置页，红框标注说明文字与「添加配置」按钮](pathname:///fat-notes-home/img/instruction/settings/settings-comp-addbar.png)

*红框分别标出顶部作用说明与右上角「添加配置」。表格列为名称 / 描述 / 状态 / 操作；当前无配置时显示「暂无数据」。*

页面顶部说明原文：

> 保存多套添加栏配置。可调整**分类、组件、功能**的顺序，并隐藏不需要的项。**分类隐藏后，其下组件在添加栏中一并隐藏**。同一时间只能应用一个配置，应用后其他配置会取消应用。

![添加配置抽屉：名称、描述、分类 / 组件 / 功能页签与隐藏开关](pathname:///fat-notes-home/img/instruction/settings/settings-drawer-addbar.png)

*红框圈出名称 / 描述字段、三个页签以及可拖拽排序的分类列表。右侧每行都有「隐藏」复选框。*

### 配置字段与控件

| 区域 | 字段 / 控件 | 说明 |
| --- | --- | --- |
| 基本信息 | 名称（必填） | 配置方案名称，占位提示「请输入配置名称」 |
| 基本信息 | 描述 | 可选，说明这套面板给谁用 |
| 页签 | 分类 | 按分类拖拽排序、逐类隐藏（图表、窗口、布局、AI、数据、过滤、表单、办公、弹框、插件、其他…） |
| 页签 | 组件 | 调整组件顺序、隐藏单个组件 |
| 页签 | 功能 | 调整功能项顺序、隐藏不需要的功能 |
| 列表操作 | 拖拽手柄 + 隐藏复选框 | 列表顺序即添加栏中的显示顺序；提示「拖拽调整分类顺序。隐藏分类后，该分类及其下组件都不会出现在添加栏中」 |
| 底部 | 取 消 / 保 存 | 保存这套配置，不保存则不生效 |

### 应用规则

1. 点「添加配置」→ 填名称、描述 → 在三个页签里排序与隐藏 → 点「保存」。
2. 回到列表，在目标配置的「操作」列执行**应用**。
3. **同一时间只能应用一个配置**；应用新配置后，原先应用的配置会自动取消应用，「状态」列随之变化。
4. 打开组件面板验证分类与组件是否符合预期；不合适就编辑配置或换一套应用。

:::tip 典型用法
- **新人模式**：只保留文本、Markdown、表格、折线图、饼图等常用分类，隐藏 AI、终端、代码等高级项，降低上手难度。
- **数据团队模式**：把图表、过滤、数据源排到最前，隐藏办公与媒体类组件。
- **演示模式**：按汇报顺序排列组件，投屏时找组件更快。
:::

## 配置速查

| 页面 | 新增入口 | 关键字段 | 列表列 |
| --- | --- | --- | --- |
| 校验规则 | 添加规则（弹窗） | 名称、描述、报错提示、校验函数 | 名称、描述、报错提示、校验函数、操作 |
| 图标管理 | 添加图标（弹窗） | 图标名称、描述、图标文件 | 图标、图标名称、描述、类型、操作 |
| 组件添加栏 | 添加配置（右侧抽屉） | 名称、描述、分类 / 组件 / 功能排序与隐藏 | 名称、描述、状态、操作 |

## 典型组合

搭建一个「带规范表单的数据录入页」时，三页可以这样配合：

1. 在**校验规则**里建「必填」「手机号格式」「数值区间」三条规则，统一报错提示写法。
2. 在**图标管理**里上传部门图标，给提交按钮与提示卡片用。
3. 在**组件添加栏**里保存一套「录入页」配置：把表单分类排到最前，隐藏用不到的图表与终端组件。
4. 应用配置后打开组件面板，拖入输入框、下拉框、按钮，并在表单块里选用前面建好的校验规则。

## 注意事项

- 校验函数必须返回 Promise；语法错误会影响所有引用该规则的表单。
- 「报错提示」会作为 `errorMsg` 传入函数，函数里用 `errorMsg || "校验失败"` 兜底最稳妥。
- 隐藏**分类**会连带隐藏其下所有组件，比逐个隐藏组件更高效，但也更容易误伤，保存前先确认。
- 添加栏配置是全局的：应用另一套配置后，所有页面的组件面板都会跟着变。
- 图标库数量大，用「全部类型」筛选与分页定位，别在内置图标上做批量删除。
