# 块的公共配置

FatNotes 的页面由「块」组成。每个块除了自身的私有配置外，还共享一套**公共配置**——无论折线图、表单还是文本块，都可以用同样的方式设置标题、数据格式、外框、浮层和图例。掌握这一节，就能举一反三地配置所有块。

## 打开配置面板

把鼠标悬停在块的标题栏上，标题右侧会出现下拉箭头，点击打开操作菜单，选择**编辑**（快捷键 `e`）：

![块操作菜单：编辑、克隆、删除](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-common-1.png)

*悬停块标题 → 下拉菜单 → 编辑*

进入配置抽屉后，左侧是块的**实时预览**与**数据查询**配置，右侧就是**展示配置**面板。顶部提供「搜索属性」框，输入关键词可快速定位配置项，匹配的分组会自动展开：

![配置抽屉：左侧预览与查询，右侧展示配置](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-common-2.png)

*配置抽屉：左侧预览与查询配置，右侧展示配置面板*

展示配置由多个**折叠分组**组成，从上到下依次是：样式、序列样式、数据格式、关联标签、外框、浮层、图例、展示。其中「序列样式」属于块自身的私有配置（按查询项设置样式），其余分组都是所有块通用的公共配置。不同类型的块分组略有差异：图表类的分组最全；文本、表单、弹框等块只保留与其相关的分组。

## 样式

「样式」分组的第一项是**标题**：给块取一个名字，勾选「显示」后标题会展示在块的标题栏上；留空时显示默认名称。

标题下方是当前块**自身特有的样式项**，随块类型变化。例如折线图提供展示模式（折线 / 曲线 / 阶梯线）、色彩（经典 / 冷峻 / 热烈三套配色）、折线类型、数据缩放、展示标记点、线宽等：

![样式分组：标题与块特有样式](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-common-3.png)

*样式分组：标题 + 当前块的特有样式*

## 数据格式

「数据格式」分组控制块中数值的展示方式，主要包含：

- **自定义小数位** — 统一设置指标的小数位数，留空时使用系统默认精度。
- **数值换算** — 开启后数值自动进位换算，例如 `10000` 显示为 `1万`。
- **单项配置** — 针对每个查询项单独设置：
  - **单位** — 给指标追加单位（如 `%`、`元`）；
  - **英文单位 / 自动进位** — 使用英文单位缩写（K、M），并允许单位自动进位；
  - **自定义小数位 / 数值换算** — 覆盖上面的全局设置，仅对该查询项生效；
  - **查询项别名 / 指标别名** — 修改查询项和指标在提示、图例中显示的名称。

![数据格式分组：小数位、数值换算与单项配置](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-common-5.png)

*数据格式分组：全局设置 + 按查询项的单项配置*

## 关联标签

块之间通过连线联动时，标题栏上会显示「关联标签」标记，标识当前的联动关系。如果不想展示，打开该分组的**隐藏**开关即可。

## 外框

「外框」分组控制整个块卡片的外观：

- **背景颜色** — 卡片背景色。
- **标题位置** — 标题靠左 / 居中 / 靠右，并可设置加粗、斜体、字体颜色。
- **标题高亮** — 输入关键词，标题中命中的文字会以高亮色显示，还可以为关键词**添加链接**，常用于配合变量实现动态标题。
- **开启阴影** — 卡片投影效果。
- **内边距** — 卡片内容与边框之间的留白（上 / 右 / 下 / 左，单位 px）。
- **边宽** — 边框粗细，可分别设置全部 / 上 / 右 / 下 / 左四个方向，并选择边框颜色。
- **圆角弧度** — 卡片圆角，可整体设置，也可分别调整四个角。
- **事件标签** — 选择要隐藏的事件标签类型（触发事件 / 接收事件），让画面更清爽。

![外框分组：背景、标题、阴影、内边距、边框与圆角](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-common-4.png)

*外框分组：从背景颜色到事件标签*

## 浮层

「浮层」即鼠标悬停在图表数据点上时弹出的提示框（tooltip）：

- **展示** — 开关浮层。
- **类型** — 显示全部（同时列出当前时刻所有系列）或显示当前（只显示悬停的系列）。
- **关键字体 / 字体** — 分别设置系列名与数值的字体、加粗、斜体和颜色。
- **开启阴影 / 内边距 / 边宽 / 圆角弧度** — 浮层框自身的外观。

## 图例

「图例」分组控制图表图例的展示：

- **位置** — 顶部 / 底部 / 左侧 / 右侧，以及各个角落（如底部左侧、顶部右侧），也可选择隐藏。
- **标记** — 图例标记与文本的对齐方式（左对齐 / 右对齐 / 自动），以及标记形状（点、圆形、正方形、矩形等）。
- **布局方向** — 水平排列或垂直排列。
- **文本** — 图例文字的颜色、加粗、斜体，或直接隐藏文本。
- **值** — 选择图例中展示的数值或计算值（First、Last、Avg、Min、Max、Sum）。

## 展示

「展示」分组用于**隐藏指标名称**：可以分别在提示（浮层）、标识（数据标签）、图例中隐藏指标名，适合指标名较长或不需要重复展示的场合。

![浮层与图例分组](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-common-6.png)

*浮层与图例分组*

## 保存与生效

调整配置时左侧预览会实时更新；确认无误后点击右上角**保存**，配置才会写入并应用到页面上的块。若预览数据不是最新，可点击**运行**按当前配置重新查询。
