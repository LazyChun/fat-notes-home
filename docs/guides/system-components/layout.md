# 布局

> 布局类组件**不展示数据**，它们决定「哪些块在一起、怎么排列、什么时候出现」。掌握容器机制后，一张画布可以承载多层级、多视图的复杂工作台，而不会变成一堵图表墙。

## 分类速览

| 组件 | 组织方式 | 是否可见切换控件 | 典型场景 |
| --- | --- | --- | --- |
| **分组** | 折叠 / 展开一组块 | 折叠箭头 | 收起次要信息 |
| **块面板** | 带边框与标题的容器 | 无 | 视觉分区、划清边界 |
| **页签** | 多个可见标签页 | 标签栏 | 同页多视图对比 |
| **场景** | 多个隐藏页面 | 可选导航栏 | 多步骤向导、按事件切页 |
| **分割面板** | 可拖动分隔条分栏 | 分隔条 | 左右对照、主从布局 |
| **走马灯** | 轮播多张内容卡片 | 轮播箭头 | 轮播展示、海报位 |

## 核心机制：容器与子块

布局块内部维护一个或多个**子块容器（Box）**，每个 Box 记录一组子块 id。使用规则：

1. 先把容器块放到画布上，调整好大小；
2. 再把其他块**拖进容器区域**，这些块就成为子块；
3. 容器的配置抽屉里出现排列 / 切换相关的私有配置；
4. 移动或缩放容器时，子块跟着一起走；删除容器前先移出需要保留的子块。

:::tip 页签 vs 场景
两者都是「多页面容器」，区别在于**谁来切换**：页签把标签栏画出来让用户点；场景默认隐藏导航栏，只能通过事件（按钮点击、列表点击行、图表点击数据点）跳转。做向导、做下钻用场景，做视图对比用页签。
:::

### 1. 分组 `group`

**做什么**：把一组块收进可折叠区域，折叠时只留标题条，展开后显示整组内容。

![分组显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-group.png)

*显示效果：折叠态只保留标题条；展开后标题条下方出现子块内容区。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-group.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**样式**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 默认展开 `expand` | 开 / 关；默认 `关` | 低频内容（高级设置、调试信息）建议默认折叠。 |
| 展开高度 `expandedH` | 数值（行高单位）；示例页设为 `16` | 控制展开后容器占多高；设得太大会把整页撑长。 |
| 头部样式 `headerStyle` | 背景色 / 圆角 / 边宽；默认无边框 | 让标题条与内容区在视觉上区分开。 |
| 子块容器 `box` | 拖入子块自动生成 | 删除分组会连同内部子块一起移除。 |

### 2. 块面板 `blockPanel`

**做什么**：带边框与标题的通用容器，用来圈定一组相关内容，不承担切换逻辑。

![块面板显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-blockPanel.png)

*显示效果：带标题的边框容器，内部放了一个文本子块以显示边界。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-blockPanel.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**容器与公共外框**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 子块容器 `panel.box` | 拖入子块自动生成 | 与分组一样，移动 / 缩放容器时子块跟随。 |
| 外框（公共配置） | 背景 / 边框 / 圆角 / 阴影 / 内边距 | 块面板没有专属私有表单，视觉差异全靠[公共配置 → 外框](./common-config.md)。 |

### 3. 页签 `tabs`

**做什么**：用可见标签在同一区域内切换多组内容，每个标签对应一个独立的子块容器。

![页签显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-tabs.png)

*显示效果：页签 1 / 页签 2 两个标签，当前页显示一段说明文本。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-tabs.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**样式**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 位置 `tabsPosition` | 上 / 下 / 左 / 右；默认 `上` | 侧边页签适合层级导航，顶部页签适合视图切换。 |
| 类型 `tabsType` | 线性页签 / 卡片页签；默认 `线性` | 卡片页签视觉更重，适合内容分区明显的页面。 |
| 大小 `tabsSize` | 小 / 中 / 大；默认 `中` | 标签栏整体字号与间距。 |
| 页签居中 `tabsCentered` | 开 / 关；默认 `关` | 标签少于 3 个时居中更平衡。 |
| 内容边距 `contentMargin` | 数值；默认 `4` | 标签栏与内容区之间的留白。 |

**页签配置 / 性能**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 页签配置 `boxs` | 添加 / 删除 / 重命名页签；默认 1 个 | 删除页签会连同该页里的组件一起删除。 |
| 强制渲染 `forceRender` | 开 / 关；默认 `关` | 开启后预渲染所有隐藏页，切页更快但首屏更重。 |
| 失活销毁 `destroyOnHidden` | 开 / 关；默认 `关` | 切走后销毁页面内容，适合放重型图表的页。 |

### 4. 分割面板 `splitter`

**做什么**：用可拖动的分隔条把区域拆成两栏或多栏，适合左右对照、主从详情。

![分割面板显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-splitter.png)

*显示效果：左右两栏中间有可拖动分隔条，两栏各放一个说明子块。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-splitter.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**样式**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 分割方向 `direction` | 水平 / 垂直；默认 `水平` | 水平 = 左右分栏，垂直 = 上下分栏。 |
| 延迟渲染 `lazy` | 开 / 关；默认 `关` | 拖拽时不立即更新大小，松手才更新，适合重内容。 |
| 快速折叠 `collapsibleEnable` / `collapsible` | 默认 `关`；可设起点 / 终点折叠与折叠图标 | 给分隔条加一键收起某侧面板的箭头。 |

**面板配置 `panels`**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 默认 / 最小 / 最大尺寸 | 百分比或像素；默认按 `%` 均分 | 限制拖拽范围，避免某栏被压到看不见。 |
| 拖拽伸缩 `resizable` | 每面板开 / 关；默认 `开` | 关闭后该面板尺寸固定，适合放筛选表单。 |
| 添加 / 删除面板 | 按钮操作；默认 2 个面板 | 删除面板会连同面板内的组件一起移除。 |

### 5. 场景 `scene`

**做什么**：多页面容器，默认只显示当前页；配合动作实现向导式跳转，是联动的接收端。

![场景显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-scene.png)

*显示效果：示例页显示「页面 1」与其内容，导航栏在预览时可隐藏。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-scene.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**样式**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 初始页面 `selectedBox` | 从已建页面中选一个；默认第 1 页 | 决定打开页面时先看到哪一页。 |
| 页面配置 `boxs` | 添加 / 重命名 / 删除页面；默认 1 个 | 动作里用页面 id 指定跳转目标，重命名不影响 id。 |
| 预览时显示导航栏 `showNavigator` | 开 / 关；默认 `关` | 开启后用户可以自己点导航切页，关闭则只能由事件驱动。 |

> **提示**：按钮、列表、折线图、饼图、雷达、K线都能配置「切换页面」动作，指定目标场景与页面后纯前端切页，不刷新数据。

### 6. 走马灯 `carousel`

**做什么**：把多张内容卡片轮播展示，适合公告位、封面图、多报告轮换。该块没有独立的私有配置表单，可用项随安装版本变化。

![走马灯显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-layout-example.png)

*该块未单独放置于示例页，图中为本分类示例页总览；实际显示以本机组件面板为准。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-layout-example.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**版本相关配置**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 切换间隔 / 自动播放 / 指示器 | 以组件面板实际显示为准 | 该类型不在内置默认配置表里，若面板中提供了配置抽屉，以抽屉里的字段为准。 |
| 内容容器 | 每个轮播项一个子块容器 | 与页签类似，先把卡片放上画布，再把内容块拖进每个轮播项。 |

> **提示**：如本机组件面板里没有走马灯，可用「场景 + 时钟任务 / 按钮切换页面」实现相近效果。

## 配置速查

| 需求 | 用哪个组件 | 关键配置 |
| --- | --- | --- |
| 把次要内容收起来 | 分组 | 默认展开、展开高度、头部样式 |
| 给一组块加边框标题 | 块面板 | 公共配置 → 外框 |
| 用户自己切视图 | 页签 | 位置 / 类型 / 页签配置 |
| 由按钮控制切页 | 场景 | 初始页面 + 动作「切换页面」 |
| 左右分栏且可拖动 | 分割面板 | 方向 / 面板尺寸 / 快速折叠 |
| 自动轮播 | 走马灯 | 播放间隔、指示器 |

## 典型组合

1. **分区** — 用块面板把「核心指标」与「明细」圈成两块，再用分组收起调试区。
2. **对照** — 分割面板左放筛选[表单](./form.md)，右放[图表](./chart.md)，拖动分隔条调整比例。
3. **多视图** — 页签第 1 页放趋势图、第 2 页放列表，共享同一份查询。
4. **向导** — 场景建 3 页，按钮配置「切换页面」逐页前进；列表点击行跳到「详情页」。
5. **嵌套** — 页签里放分组，分组里再放图表，构成多层级看板。

## 注意事项

- 布局块本身不触发联动事件，但**场景**是常见的联动目标。
- 子块归属由容器记录，直接改画布坐标不会自动改变归属；需要拖入 / 拖出操作。
- 「强制渲染」会一次性渲染所有页签内容，页面很重时建议关闭或使用「失活销毁」。
- 删除容器会连同内部子块一起移除，操作前先确认。
