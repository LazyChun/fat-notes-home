# 图表

> 图表类组件把**查询结果**画成图形，是数据看板的核心。它们本身不存数据，只负责「取数 → 绘图 → 交互」；弄懂一套查询配置，六个图表就能举一反三。

在页面右上角打开「组件」面板，展开 **图表** 分类即可看到 6 个内置图表块。所有块共用的标题、外框、浮层、图例与数据格式，见[公共配置](./common-config.md)；本章只讲图表类特有的部分。

## 分类速览

| 组件 | 回答什么问题 | 数据形态 | 典型场景 |
| --- | --- | --- | --- |
| **折线图** | 指标随时间怎么变 | 时间序列，可多系列 | 每日销售额、访问量趋势 |
| **列表** | 每一条记录是什么 | 明细行，可分页 | 订单明细、指标台账 |
| **饼图** | 各部分占整体多少 | 类别 + 数值 | 品类占比、渠道构成 |
| **K线** | 开高低收如何波动 | 四个查询项 | 行情、价格区间 |
| **雷达** | 多个维度谁强谁弱 | 多指标对比 | 能力评估、产品打分 |
| **热力图** | 哪里密集、哪里稀疏 | 时间 × 数值 | 活跃度日历、时段分布 |

![图表分类的示例页面：六个内置图表块](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-chart-example.png)

*示例页把 6 个图表放在同一画布做对照；**红框**标出的是折线图——它是联动能力最完整的一个图表块。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-chart-example.png" target="_blank" rel="noopener">查看大图</a>

## 统一的工作方式：先查询，后绘图

六个图表块共用同一套**数据查询配置**，位于配置抽屉左下方。理解下面几个概念，就理解了所有图表：

| 概念 | 说明 |
| --- | --- |
| **查询项** | 一条独立的数据取数逻辑，按 `A / B / C…` 编号。一个图表可以有多条查询，用来叠加多个系列。 |
| **指标查询** | 按时间轴聚合：选数据表、维度列、聚合函数（求和 / 平均 / 最大 / 最小 / 计数）、过滤条件。第一行时间为 X 轴。 |
| **数据表查询** | 按类别取值：指定**名称项**（X 轴）、**值项**、聚合方式、排序与行数上限。适合饼图、列表类展示。 |
| **表达式** | 用已有查询项做二次计算，例如 `A + B`、条件表达式，不必回到数据源改表。 |

配置抽屉顶部是**时间范围**（支持相对时间快捷项与绝对时间）以及「运行」「保存」：改完配置先点**运行**按当前条件重查预览，确认后点**保存**才写入页面。

:::tip 一个常见误区
图表显示「暂无数据」，通常不是图表坏了，而是**查询项没配好**：数据表未选、名称项 / 值项为空、时间范围不覆盖数据，或 K线缺少四个映射项。先检查左下方「查询」，再看右侧样式。
:::

## 逐个组件详解

下面 6 个块共用左下角的「查询」配置，差异全部集中在配置抽屉右侧的「样式」分组。每节都给出**完整的私有配置项**、默认值和一张**单独截取的显示效果图**；标题、外框、图例、浮层等公共项见[公共配置](./common-config.md)。

![私有配置在配置抽屉中的位置](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-chart-config.png)

*配置抽屉右侧：**样式**分组上半部分是公共的标题，下半部分（展示模式、色彩、折线类型、线宽…）才是私有配置；下表逐项展开。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-chart-config.png" target="_blank" rel="noopener">查看大图</a>

### 1. 折线图 `line`

**做什么**：按时间或类别绘制趋势，可在同一张图里叠加多个查询项，适合看变化、比高低、找异常点。

![折线图显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-line.png)

*显示效果：蓝色折线呈现每日实付金额，X 轴为日期、Y 轴为金额，底部图例来自查询项别名。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-line.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**样式 · 基础**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 展示模式 `graphType` | 折线 / 面积 / 柱状 / 虚线 / 散点；默认 `折线` | 决定整张图的绘制方式；柱状适合离散对比，面积强调累积量，散点只看分布。 |
| 色彩 `graphTheme` | 经典 / 冷峻 / 热烈；默认 `经典` | 一次性切换整套系列配色，多系列时比逐条改颜色更省事。 |
| 折线类型 `lineType` | 斜角 / 圆角 / 直角（阶梯）；默认 `斜角` | 仅折线、虚线、面积模式可用；直角适合表现阶梯式变化。 |
| 数据缩放 `showDataZoom` | 开 / 关；默认 `关` | 在图底部加缩放滑轨，长时间序列可拖选局部区间。 |
| 展示标记点 `showSymbol` | 开 / 关；默认 `关` | 在每个数据点画圆点；点少时更精确，点上万时建议关闭。 |
| 线宽 `lineWidth` | 1–10；默认 `2` | 折线 / 面积 / 虚线的笔画粗细，大屏看板可适当加粗。 |
| 散点大小 `dotWidth` | 数值；默认由主题决定 | 仅在散点模式下生效，控制每个点的半径。 |

**序列样式 `queryGraphs`（按查询项逐条设置）**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 展示模式 / 线宽 | 继承或单独覆盖全局设置 | 让同一张图里 A 查询画柱、B 查询画线，做组合图。 |
| 自定义颜色 / 填充色 / 面积透明度 | 颜色值、0–1 透明度 | 逐个查询项设色；面积模式可调整填充透明度避免互相遮挡。 |
| 右 Y 轴 / 标记线 / 区域填充 | 按查询项或数值配置 | 量纲差异大的指标放右轴；水平 / 垂直标记线标出阈值，区域填充强调特定区间。 |

> **提示**：折线图是**动作最全**的块：联动、下钻、更新、过滤、跳转、切换场景页面都支持；点击数据点可把时间、维度、指标值传给其他块。

### 2. 饼图 `pie`

**做什么**：展示构成占比，支持饼图 / 环形图 / 玫瑰图三种形态；「标识」控制扇区上的文字标签。

![饼图显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-pie.png)

*显示效果：一个饼图按类别切分，扇区配色来自主题，下方图例列出各类别。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-pie.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**样式**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 展示 `graphType` | 饼图 / 环形图 / 玫瑰图；默认 `饼图` | 环形图中间可放总数说明；玫瑰图用半径大小强化差异。 |
| 玫瑰图等分 `roseType` | 半径 / 等分；默认按半径 | 仅玫瑰图可用：`半径`让扇区半径随数值变化，`等分`只按角度区分。 |
| 标识 `showLabel` | 开 / 关；默认 `开` | 在扇区上显示名称 / 百分比；类别多时关掉，改看图例。 |
| 查询项（左下） | 数据表查询：名称项 / 值项 / 行数上限 | 类别放「名称项」、数值放「值项」，行数上限例如 6，避免图例过长。 |

> **提示**：点击扇区可配置「切换场景页面」；饼图不参与时间轴合并，用类别列做名称项不会出现 `Invalid Date`。

### 3. 列表 `table`

**做什么**：以表格呈现明细，支持分页、排序、冻结列；「列设置」还能把某一列变成可编辑控件回写数据。

![列表显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-table.png)

*显示效果：Time 与 sum(实付金额) 两列明细，右下角是分页器（第 1 / 2 页）。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-table.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**表格**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 表格大小 `tableSize` | 小 / 中 / 大；默认 `小` | 控制行高与字号，密集台账用小，展示用大。 |
| 表格分页 `paging` / `pageSize` | 开 / 关；默认 `开`、每页 `10` 行 | 关闭分页后一次渲染全部行，数据量大时会拖慢页面。 |
| 对齐方式 `colAlign` | 左 / 中 / 右；默认 `左` | 全表默认对齐，数值列通常改成右对齐。 |
| 冻结列 `frozenLeft` / `frozenRight` | 前 N 列 / 后 N 列；默认不冻结 | 横向滚动时固定关键列（如时间、名称），操作列可固定在右侧。 |

**列设置 `tableCols`（逐列）**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 列宽 / 对齐 / 排序 | 像素或自动；左 / 中 / 右；可排序开关 | 按列覆盖全表默认值，长文本列给足宽度，指标列开启排序。 |
| 展示类型 `displayType` | 文本 / 链接 / 彩色背景 / 条形图 / 饼图 / 可修改文本 / 选择器 / 开关 / 按钮 / 下拉按钮 | 把单元格变成图形或控件；后四类可编辑，配合动作把改动写回数据表。 |
| 展示映射 `displayValue` | 按阈值添加颜色 / 文案规则 | 例如金额 > 5000 显示红底、状态 = 完成 显示绿色，用于条件高亮。 |

> **提示**：点击行可触发删除或「切换场景页面」，是「总览 → 明细」下钻最常用的入口。

### 4. K线 `candlestick`

**做什么**：用开盘、收盘、最低、最高四个值画蜡烛图，可叠加均线；红涨绿跌符合 A 股习惯。

![K线显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-candlestick.png)

*显示效果：红绿蜡烛配合一条蓝色连线（自定义连线），X 轴为日期、Y 轴为价格。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-candlestick.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**数据项映射**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 开盘 / 收盘 / 最低 / 最高 | 分别绑定到 4 个查询项 | 四个映射缺一不可，否则块显示「暂无数据」；同一指标可用不同聚合方式建 4 个查询项。 |

**颜色**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 阳线颜色 `upColor` / 边框 `upBorderColor` | 颜色值；默认 `#ec0000` / `#8A0000` | 上涨蜡烛的填充与描边。 |
| 阴线颜色 `downColor` / 边框 `downBorderColor` | 颜色值；默认 `#00da3c` / `#008F28` | 下跌蜡烛的填充与描边。 |

**连线与缩放**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 显示缩放 `showDataZoom` | 开 / 关；默认 `开` | 在底部显示区间缩放滑轨。 |
| 显示连线 `showLine` / 连线颜色 `lineColor` | 开 / 关（默认 `开`）；默认 `#1677ff` | 把收盘价等连成折线，便于叠加在蜡烛上看趋势。 |
| 自定义连线 `customLines` | 可添加多条：名称 / 绑定查询项 / 线宽 / 颜色 / 是否显示 | 用来叠加 MA5、MA10 等均线；每条线对应一个独立查询项。 |

> **提示**：K线是唯一要求「四条查询」的内置图表，先在左下角建好 A/B/C/D 四个查询项，再回右侧逐个绑定。

### 5. 雷达 `radar`

**做什么**：在多个维度上对比一组指标，可选基础雷达 / AQI 雷达与单雷达 / 多雷达展示模式。

![雷达显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-radar.png)

*显示效果：多边形网格上叠加彩色数据区域，下方按查询项列出图例。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-radar.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**样式**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 展示 `graphType` | 基础雷达图 / AQI 雷达图；默认 `基础` | AQI 形态按等级分段着色，适合空气质量、风险分级这类阈值场景。 |
| 展示模式 `displayMode` | 单雷达 / 多雷达；默认 `单雷达` | 多雷达把每个查询项拆成独立小图，系列多时更清爽。 |
| 指标最大值 `maxValues` | 按查询项填写数值与单位；默认空（自动取数据最大值） | 手动指定上限可让多张雷达图口径一致，避免「看起来差不多」的误导。 |
| 等级含义的颜色规则 | 按阈值配色 | 给不同区间配色，例如 0–60 红、60–80 黄、80–100 绿。 |

> **提示**：维度较多时给查询项设置别名，避免图例过长；点击图形可配置「切换场景页面」。

### 6. 热力图 `heat`

**做什么**：用颜色深浅表现密度或强弱，支持基础热力图与日历热力图（水平 / 垂直、不拆分 / 按年 / 按月）。

![热力图显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-heat.png)

*显示效果：横向日历格按日期排列，色阶条从 0 到 1，颜色越深数值越大。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-heat.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**样式**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 展示 `graphType` | 基础热力图 / 日历热力图；默认 `基础` | 日历形态按日期铺格子，适合活跃度、打卡、提交记录。 |
| 日历方向 `calendarOrient` | 水平 / 垂直；默认 `水平` | 仅日历热力图可用，决定周与日期的排布方向。 |
| 拆分日历 `calendarSplitType` | 不拆分 / 按年 / 按月；默认 `不拆分` | 数据跨年时按年或月切成多张小图，避免一整条长带。 |
| 标识 `showLabel` | 开 / 关；默认 `开` | 显示格子的数值或日期标签。 |
| 颜色范围 `colorRangeType` / 渐变 `gradientType` / 反转 `gradirentReverse` | 渐变 / 自定义；默认 `渐变` + 蓝色系；可反转 | 决定色阶从低到高怎么过渡；反转可让「深色 = 小值」。 |
| 等级含义 `displayValues` | 按阈值设置填充色、字体色与展示类型；默认一条 default 规则 | 例如 > 100 深红、10–100 橙色、其余浅灰，用于分级告警。 |

## 配置速查

| 配置分组 | 图表类关键项 | 作用 |
| --- | --- | --- |
| 查询（左下） | 查询项、数据表、维度 / 指标、过滤、聚合、表达式 | 决定画什么数据 |
| 样式（右侧） | 展示模式、图形参数、序列样式 | 决定怎么画 |
| 数据格式 | 小数位、数值换算、单位、查询项 / 指标别名 | 决定数值怎么显示 |
| 浮层 / 图例 | 提示类型、位置、标记、布局方向、图例值 | 决定读图体验 |
| 外框 | 背景、标题、阴影、边框、圆角 | 决定卡片外观 |

> 后三组属于[公共配置](./common-config.md)，所有块都能用。

## 典型组合

1. **数据接入** — 在「数据 → 数据源」注册表，或直接引用已注册的数据源。
2. **放图** — 从组件面板拖入折线图 → 建立查询项 → 选样式 → 保存。
3. **加筛选** — 放一个[时间过滤器](./filter.md)或通用过滤器，用联动连线指向图表，实现整页同步刷新。
4. **做下钻** — 列表点击行 → 切换[场景](./layout.md)页面，或跳转到[弹框](./dialog.md)显示明细。
5. **统一格式** — 在「数据格式」里给金额加单位、统一小数位，避免每张图各写一套。

## 注意事项

- 图表是**数据消费方**，不是数据源；原始数据由「数据源 / 数据加工」提供。
- 类别维度若用非时间列做名称项，多帧合并时可能出现 `Invalid Date` / `NaN`，趋势类图表建议用时间列。
- 查询项越多，图例与浮层越拥挤；长名称用「查询项别名」缩短。
- 组件面板里还会出现由插件提供的图表（时序图、数值、排行、蜂窝、仪表等），它们的配置项与本章内置图表不同，详见[热门插件](../../plugins/index.md)。
