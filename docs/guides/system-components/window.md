# 窗口

> 图表回答「数据长什么样」，窗口回答「页面里还能装下什么」。窗口类组件承载一个**独立视图或工具**：一个可组装的功能面板、一段代码、一台终端，都能直接嵌进同一张画布。

它们是组件面板里最容易被低估的一类：不参与指标计算，却决定了工作台是「一堆图表」还是「一个能干活的工具」。

## 分类速览

| 组件 | 定位 | 是否容器 | 典型场景 |
| --- | --- | --- | --- |
| **功能面板** | 带标题与 Logo 的功能入口容器 | ✅ 可放子块 | 工作台首页、常用操作区、工具集 |
| **代码** | 内嵌代码编辑器 | ❌ | 技术笔记、脚本片段、配置示例 |
| **终端** | 内嵌命令行终端 | ❌ | 运维看板、开发调试、命令速查 |

![窗口分类的示例页面：功能面板、终端与代码](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-window-example.png)

*示例页把三个窗口块并排放置；**红框**标出的是终端块——它是一台真正可执行的命令行，而不是一张截图。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-window-example.png" target="_blank" rel="noopener">查看大图</a>

## 与图表、布局类组件的区别

| 对比 | 窗口 | 布局 | 图表 |
| --- | --- | --- | --- |
| 主要目的 | 嵌入一个**工具 / 视图** | 组织**多个块** | 展示**一组数据** |
| 数据来源 | 不需要查询 | 不需要查询 | 必须有查询项 |
| 交互方式 | 在块内部直接操作 | 切换、折叠、拖动 | 悬停、点击、联动 |
| 配置重心 | 标题、内容路径、内部工具 | 排列、页面、分栏 | 查询与图形样式 |

:::note 关于子块
功能面板与[布局类](./layout.md)容器一样，内部可以放子块：先把面板放到画布上，再把按钮、文本、说明等块拖进面板区域。子块的事件照常生效，因此「面板 + 按钮 → 联动图表」是很常见的组合。
:::

## 逐个组件详解

窗口类块的私有配置普遍很少：功能面板是容器，代码与终端的能力主要在**块内部**。下面逐块列出可在配置抽屉里改的项，以及运行态可用的操作。

### 1. 功能面板 `functionPanel`

**做什么**：把一组常用功能入口、按钮与说明文字打包成带标题的面板，便于复用与整体搬移；是容器块。

![功能面板显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-functionPanel.png)

*显示效果：编辑态的功能面板，顶部为面板标题，内部是「导出目录 / 构建」等操作与子块区域。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-functionPanel.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**基础 / 容器**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 标题 | 文本；默认取组件名 | 显示在面板顶部，建议写清这组操作的用途。 |
| Logo 路径 | 图片路径 / 图标名 | 面板左上角图标，留空则只显示标题。 |
| 构建 | 按钮操作 | 把当前面板内容打包成可复用的功能面板；成功 / 失败 / 网络错误都有消息反馈。 |
| 子块容器 `box` | 由拖入的子块自动维护 | 不在配置抽屉里逐项列出；先把面板放上画布，再把按钮、文本等拖进去。 |

> **提示**：面板里可以放[表单](./form.md)按钮，再用「事件 → 联动」驱动同页图表；移动或缩放面板时子块跟着一起走。

### 2. 代码 `code`

**做什么**：在页面里嵌入代码编辑器，可展示或编写代码片段，支持语言切换与直接运行。

![代码显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-code.png)

*显示效果：代码块的编辑态，可见 JavaScript / Python 等语言标签与内容区。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-code.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**运行态操作**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 语言 / 内容 | 在块内直接选择与编辑 | 配置抽屉没有独立的私有表单；代码块以内容本身为主，外观走[公共配置](./common-config.md)。 |
| 联动输出 | 由块内运行 / 事件配置决定 | 需要把运行结果交给图表时，请用流程或数据源输出结构化数据。 |

### 3. 终端 `terminal`

**做什么**：内嵌命令行终端，可切换 PowerShell / CMD / Bash 等环境，直接在页面里执行命令并查看输出。

![终端显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-terminal.png)

*显示效果：终端块顶部有 PowerShell / CMD / Bash 切换标签，下方是命令行输出区。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-terminal.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**运行态操作**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| Shell 环境 | PowerShell / CMD / Bash | 在块顶部切换，切换后新命令使用对应解释器。 |
| 命令输入 / 输出 | 在块内直接键入 | 无右侧私有表单；工作目录、字体等由运行环境与[公共配置](./common-config.md)决定。 |
| 联动提示 | 可接收其他块的联动 | 示例页显示「尚未收到联动变量」；由按钮或表单传入变量后可作为参数使用。 |

> **提示**：终端执行的是本机命令，权限与当前应用一致；共享或演示页面里避免放置破坏性命令。

## 配置速查

窗口类块的私有配置很少，绝大多数外观都在[公共配置](./common-config.md)里完成：

| 需求 | 去哪里配 |
| --- | --- |
| 面板标题、Logo | 功能面板的「样式 / 基础」分组 |
| 卡片背景、边框、阴影、圆角 | 公共配置 → 外框 |
| 标题字体、对齐、高亮 | 公共配置 → 外框 |
| 块内留白 | 公共配置 → 内边距 |
| 隐藏右上角事件标签 | 公共配置 → 事件标签 |

## 典型组合

1. **工作台首页** — 功能面板（放常用按钮）+ 终端（固定项目目录）+ 一个[其他](./misc.md)分类里的 Markdown 说明卡。
2. **运维看板** — 上方是设备指标图表，下方常驻终端，出问题直接排查，不用来回切窗口。
3. **技术文档页** — 代码块展示脚本，Markdown 卡解释参数，右侧用[IFrame](./misc.md)嵌入参考文档。

## 注意事项

- 窗口块不需要数据查询，配置抽屉左侧通常没有「查询」区。
- 代码与终端的具体能力会随安装版本与插件变化；若组件面板里没有某项，以本机实际显示为准。
- 功能面板是容器：先放面板，再往里拖子块；直接改子块的画布坐标不会改变归属。
