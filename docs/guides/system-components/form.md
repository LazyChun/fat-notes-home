# 表单

> 表单类组件负责**收集输入并触发动作**。它们是页面里最主要的「触发源」：一个下拉框、一个按钮、一个开关，都能把值写进页面变量池，进而驱动图表、列表、流程与场景切换。

## 分类速览

| 组件 | 输入类型 | 常见用途 |
| --- | --- | --- |
| **表单** | 容器 | 统一排版多个控件 |
| **输入框** | 单行 / 多行 / 密码 / 数字 | 关键词、备注、数值 |
| **按钮** | 点击 | 提交、刷新、跳转、切页 |
| **日期选择器** | 日期 / 周 / 月 / 季 / 年 / 时间 | 统计日期、时间区间 |
| **开关** | 布尔 | 启停某个功能 |
| **单选** | 单选枚举 | 维度、口径 |
| **多选框** | 多选枚举 | 渠道、标签 |
| **滑动条** | 数值 / 数值区间 | 阈值、比例 |
| **下拉框** | 单选列表 | 地区、品类 |
| **多选下拉框** | 多选列表 | 多品类、多人 |
| **自动完成** | 输入 + 候选 | 城市、人名搜索 |
| **级联选择** | 层级树 | 省 / 市 / 区 |
| **评分** | 星级 | 满意度、评级 |
| **颜色选择器** | 颜色值 | 输出主题色 |

## 所有控件共有的配置

打开任一控件的配置抽屉，右侧「基础」分组都会出现这一组字段。它们比控件外观更重要：

| 配置 | 作用 |
| --- | --- |
| **变量名 `varName`** | 控件值写入页面变量池时使用的名字，建议英文 / 数字 / 下划线、全页唯一 |
| **表单项标题** | 控件左侧的说明文字 |
| **默认值 / 禁用 / 只读** | 初始状态与可编辑性 |
| **占位提示、前缀、后缀** | 输入类控件的引导信息 |
| **校验规则 / 校验触发** | 必填、长度、正则等；触发时机可选输入时（`onChange`）或失焦时（`onBlur`） |
| **输入框样式** | 背景色、尺寸、宽高、阴影、圆角、边宽 |

![输入框的私有配置：变量名、输入类型、长度与校验规则](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-form-config.png)

*配置抽屉右侧：**基础**分组里的「变量名」是联动的关键；下面还有「校验规则」「样式」「关联标签」「外框」等分组。*

:::tip 变量名 → 查询 → 图表
在[过滤](./filter.md)里讲过变量池：控件值以 `$变量名` 的形式被查询条件、块标题、流程入参引用。例如把下拉框变量名设为 `region`，再让查询过滤值填 `$region`，选择「华东」时图表就只显示华东数据。
:::

## 事件与联动（本类最重要的能力）

表单控件是系统的**主要触发源**。在块的「事件」配置里可以添加动作：

| 动作 | 哪些控件支持 | 效果 |
| --- | --- | --- |
| **联动** | 按钮、输入框、下拉 / 多选、单选、开关、滑动条、评分等 | 把当前值传给目标块，触发重新查询或更新 |
| **跳转** | 按钮、折线图 | 打开链接，或以**弹框 / 抽屉展开**方式打开目标内容 |
| **切换页面** | 按钮、列表、图表 | 跳转到[场景](./layout.md)的指定页面 |
| **过滤 / 下钻 / 更新** | 主要由折线图、列表提供 | 条件过滤、明细下钻、数据更新 |

**触发时机**因控件而异：点击、值改变、值改变完成、失焦、选择、悬停改变、输出时触发。

**出参**（联动时传出的数据）由控件类型决定：

- 按钮 → 按钮文本 + 变量名；
- 输入 / 选择 / 开关 / 滑动条 / 评分 → 选中值 `value`（多选为 `values`）+ 变量名；
- 所有控件另外附带 `triggerDate` 触发时间。

连线由三部分组成：**连线**（画布上可见）、**出参 / 入参**（传什么值）、**动作**（做什么）。配置界面里能看到「联动参数」「添加组件」「出参 / 入参」等条目。

## 逐个组件详解

每个控件都先共享一组「基础」配置（变量名、标题、默认值、校验等），再叠加自己的专有项。下面 14 个控件逐项列出，并各配一张显示效果图；事件与出参规则见前文的「事件与联动」。

**做什么**：把多个控件包成一个整体统一排版，可设标签对齐；容器型控件。

**私有配置**：

**基础（所有控件共有）**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 变量名 `varName` | 自定义；建议英文 / 数字 / 下划线 | 控件值写入页面变量池的名字，查询、标题、流程用 `$变量名` 引用。 |
| 表单项标题 `formItemLabel` | 文本；默认空 | 控件左侧说明文字，例如「关键词」「统计日期」。 |

| 占位提示 / 前缀 / 后缀 | 文本或图标 | 输入类控件的引导信息。 |
| 校验规则 / 校验触发 | 必填、长度、正则；`onChange` / `onBlur` | 值改变时或失焦时校验；重查询场景建议用失焦或按钮统一提交。 |
| 输入框样式 | 背景色、尺寸、宽高、阴影、圆角、边宽 | 控件本体的外观，与[公共配置 → 外框](./common-config.md)分开。 |

**该控件专有**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 标签对齐 `labelAlign` | 左 / 右；默认 `左`（示例页设为右） | 统一容器内所有控件标题的对齐方式。 |
| 子块容器 | 拖入控件自动生成 | 容器本身不产生值，值来自内部各控件的变量名。 |

## 典型组合

1. **参数化看板** — 表单容器里放「地区下拉框 + 日期选择器 + 查询按钮」→ 按钮联动刷新折线图与列表。
2. **即输即筛** — 输入框的 `varName` 写入变量，图表查询过滤值引用 `$varName`，无需按钮即可随输入更新。
3. **向导页面** — [场景](./layout.md)建 3 页，按钮配置「切换页面」逐页前进；最后一页提交表单。
4. **详情弹层** — 列表点击行 / 按钮配置「跳转 → 弹框展开」，把目标内容装进[弹框或抽屉](./dialog.md)。
5. **主题切换** — 颜色选择器输出色值，供其他块的样式引用。

## 注意事项

- 变量名全页唯一且只用英文 / 数字 / 下划线；重名会互相覆盖。
- 默认「值改变」可能在每次按键时触发，查询较重时改选「值改变完成」或「失焦」，或改由按钮统一提交。
- 联动需要同时配好**动作**与**连线 / 出入参**，只填变量名不会自动传给别的块。
- 校验规则不通过时，动作是否执行取决于具体配置；涉及写库的流程建议再加一层确认。
