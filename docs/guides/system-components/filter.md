# 过滤

> 过滤类组件**不画图、不存数据**，它们输出「条件」和「参数」，让同一页面的图表、列表与流程按用户的选择重新取数。它们是看板从「静态报表」变成「可探索工具」的关键。

## 分类速览

| 组件 | 输出什么 | 谁来用 | 典型场景 |
| --- | --- | --- | --- |
| **通用过滤器** | 字段 + 操作符 + 值的条件组合 | 图表查询、列表、流程 | 按地区 / 品类 / 状态筛选 |
| **时间过滤器** | `startTime` / `endTime` | 页面全局时间范围、所有查询 | 切换本周 / 本月 / 自定义区间 |
| **变量** | 页面级参数（名称 → 值） | 查询条件、块标题、流程入参 | 复用一个阈值、一个关键词 |

![过滤分类的示例页面：三个过滤块与一个联动目标](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-filter-example.png)

*示例页上方是三个过滤块，下方折线图作为联动目标；**红框**标出的是时间过滤器，它控制整页的时间范围。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-filter-example.png" target="_blank" rel="noopener">查看大图</a>

## 筛选如何传到图表

```
过滤器 / 变量  ──输出条件或参数──▶  查询项（WHERE / 时间范围）
                                      │
                                      ▼
                          图表、列表、流程重新取数并渲染
```

配置顺序建议固定为三步：

1. **先放过滤块** — 在画布上摆好通用过滤器、时间过滤器或变量；
2. **再引用** — 在图表查询的过滤条件里引用变量，或让时间过滤器接管页面时间范围；
3. **最后连线** — 在块的「事件 / 联动」里建立关系，指定出参与入参。

:::tip 变量是统一的桥梁
[表单](./form.md)控件也有「变量名」，它和「变量」块写入的是**同一个页面变量池**。因此一个下拉框选中的值，既能当查询条件，也能出现在块标题、流程入参里，不需要额外的转换块。
:::

## 逐个组件详解

过滤类 3 个块的配置**不在右侧样式分组**：通用过滤器与变量的字段在配置抽屉左侧 / 块内，时间过滤器主要在块上直接操作。下面逐块列出可配项、默认值与引用方式。

*配置抽屉右侧：变量块的私有配置很轻，真正的价值在于它向页面变量池写入了什么。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-filter-config.png" target="_blank" rel="noopener">查看大图</a>

### 1. 通用过滤器 `filter`

**做什么**：把一个或多个字段条件组合起来，用户现场改值，结果实时作用于同页组件。

![通用过滤器显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-filter.png)

*显示效果：过滤器卡片内提示先选择数据源、勾选维度或指标，再配置条件。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-filter.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**条件项（每条由三部分组成）**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 字段 `keyword` | 从数据源列 / 查询键中选择；默认空 | 必须用**物理列名 / 查询键**，写显示名不会生效。 |
| 操作符 | 等于 / 不等于 / 大于 / 大于等于 / 小于 / 小于等于 / 包含 / 不包含 / 介于 | 「介于」适合金额、日期区间；「包含」适合文本与多选。 |
| 值 | 文本 / 搜索文本 / 数值 / 数值区间 / 日期 / 日期区间 / 单选 / 多选 | 控件类型随字段类型变化；也可填 `$变量名` 引用页面参数。 |

**字段级配置**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 显示名称 | 文本；默认取字段名 | 给用户看的标签，可改得比物理列名更易懂。 |
| 可用操作符集合 | 从 9 种操作符里勾选 | 只留与字段类型匹配的操作符，避免用户选出无效条件。 |
| 候选值来源 | 静态列表 / 数据源字段 / 变量 | 枚举字段给候选值，用户就不用手输。 |
| 是否分页 | 开 / 关；默认 `关` | 候选项很多时开启，避免一次渲染上千项。 |

> **提示**：改完条件记得在块的「事件 → 联动」里连线，并确认出参 / 入参；只配条件不会自动影响图表。

### 2. 时间过滤器 `timeFilter`

**做什么**：输出 `startTime / endTime`，控制页面全局时间范围；所有基于时间轴的查询都会跟着变。

![时间过滤器显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-timeFilter.png)

*显示效果：时间过滤器显示当前快捷范围「今年」，点开可切其它范围或绝对时间。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-timeFilter.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**范围设置**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 快捷范围 | 今天、最近 15 秒 / 1 分钟 / 5 分钟 / 1 小时 / 1 天 / 7 天 / 30 天 … 1 年，本周 / 本月 / 本年 | 常用于看板顶栏，切换即整页重查。 |
| 绝对时间 | 手动选择起止日期时间 | 用于复盘固定区间；此时快捷范围的联动可能看起来「不跟着变」。 |
| 刷新间隔 | 不刷新 / 按秒 / 按分 / 按时；默认 `不刷新` | 实时监控看板可设自动刷新，配合相对时间范围使用。 |
| 默认值 / 显示清空 | 打开页面时的初始范围；清空开关 | 给一个默认范围，避免首次打开时所有图表「暂无数据」。 |

### 3. 变量 `variable`

**做什么**：集中管理页面级参数：目标阈值、当前地区、统计口径，供多处引用。

![变量显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-variable.png)

*显示效果：变量卡片内提示添加变量，并说明可用 `$变量名` 在文本、标题和过滤条件里引用。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-variable.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**变量定义**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 变量名 | 文本；建议英文 / 数字 / 下划线、全页唯一 | 重名会互相覆盖；系统变量与用户变量共用引用语法。 |
| 值 | 文本 / 数值 / JSON | 类型要和引用位置一致：把文本塞进数值过滤条件会被忽略。 |
| 描述 | 文本；默认空 | 说明这个变量的用途，方便多人协作时理解。 |
| 显示清空 | 开 / 关；默认 `关` | 让用户在运行时把变量重置为初始值。 |

**引用语法**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| `$变量名` | 取当前值 | 查询过滤值、块标题高亮、流程入参、动作 URL 参数都支持。 |
| `$变量名.子变量名` | 取对象字段 | 变量值是 JSON 对象时使用。 |
| `$变量名[索引]&` | 取数组某项 | 变量值是数组时使用。 |

## 配置速查

| 需求 | 用哪个块 | 在哪配 |
| --- | --- | --- |
| 让用户按字段筛选 | 通用过滤器 | 字段、操作符、候选值 |
| 让用户切时间范围 | 时间过滤器 | 快捷范围、绝对时间、刷新间隔 |
| 复用一个参数 | 变量 | 变量名 / 值 / 描述 |
| 把筛选结果给图表 | 联动 | 块「事件 → 联动」的连线与出参 / 入参 |
| 在标题里显示当前值 | 变量 + 标题高亮 | 公共配置 → 外框 → 标题高亮 |

## 典型组合

1. **常规筛选看板** — 时间过滤器（顶部）+ 通用过滤器（地区 / 品类）+ 折线图 / 列表；切一次条件整页刷新。
2. **参数化查询** — 变量 `threshold` 作为查询过滤值，[滑动条](./form.md)写入同名变量，拖动即改变图表口径。
3. **动态标题** — 变量 `region` 配合标题高亮，让「`{region}` 销售概览」随选择变化。
4. **流程入参** — 变量作为[Flow组件](./flow-widget.md)的输入，按钮触发流程时带上当前筛选条件。

## 注意事项

- 过滤块是**联动源头**，本身不渲染数据；没建立连线或没在查询中引用变量时，改值不会有任何效果。
- 时间过滤器的范围作用于页面时间轴，若某个查询用了固定绝对区间，可能看起来「不跟着变」。
- 变量名建议只用英文、数字与下划线，并全页唯一；重名会互相覆盖。
- 变量值类型要和查询字段一致：把文本塞进数值过滤条件会被忽略或报错。
