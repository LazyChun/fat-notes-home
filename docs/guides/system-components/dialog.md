# 弹框

> 弹框类组件承担**模态交互与轻量反馈**。它们通常不会常驻显示，而是作为动作的目标：按钮一点、列表一行被选中、图表上一个数据点被点击，才把内容推到用户面前。

## 分类速览

| 组件 | 形态 | 是否容器 | 典型场景 |
| --- | --- | --- | --- |
| **弹框** | 居中模态对话框 | ✅ 可放子块 | 确认操作、填写表单、查看详情 |
| **抽屉** | 从页面边缘滑出的侧栏 | ✅ 可放子块 | 筛选条件、侧边详情、设置项 |
| **消息** | 顶部轻量提示条 | 可选组件盒子 | 保存成功、操作失败 |
| **通知** | 带标题与描述的通知卡片 | 可选组件盒子 | 任务完成、数据同步、异常告警 |

![弹框分类的示例页面：四个反馈型块](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-dialog-example.png)

*示例页展示四个块在画布上的编辑态；**红框**标出的是通知块——运行时它会以通知卡片的形式浮现在页面角落。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-dialog-example.png" target="_blank" rel="noopener">查看大图</a>

## 核心机制：由动作唤起

弹框类块是**联动的接收端**，不是触发源。常见的唤起方式：

```
按钮点击 / 列表点击行 / 图表点击数据点
        │  事件 → 跳转（displayWay）
        ▼
   弹框展开 / 抽屉展开  →  显示目标块内部内容
        │
        ▼
   动作执行结果  →  消息 / 通知 反馈
```

在[按钮或图表](./form.md)的「事件 → 跳转」里，把展示方式选为「弹框展开」或「抽屉展开」，再指定目标块即可。消息与通知则常挂在动作执行成功 / 失败之后，用来给用户一个明确回执。

:::note 画布上看到的是编辑态
弹框、抽屉在画布上表现为一个普通的块卡片（可能看起来是空白的），这是**编辑态**；只有运行时被动作唤出，才会呈现真正的遮罩、浮层与动画。消息与通知同理，未触发时不会弹出。
:::

### 1. 弹框 `modal`

**做什么**：居中弹出的模态对话框，内部可放表单、明细、说明等子块；是容器。

![弹框显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-modal.png)

*显示效果：画布编辑态的弹框卡片（空容器），运行时以居中遮罩对话框出现。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-modal.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**外观**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 标题 `title` / 标题颜色 `titleColor` | 文本；留空则用组件名 / 颜色值 | 显示在弹框顶部。 |
| 宽度 `width` / 高度 `height` / 垂直居中 `centered` | 默认 `800` / `60vh`（可写 `400px`）/ `开` | 按内容量调整尺寸；内容多时关掉垂直居中更稳。 |

**关闭行为**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 显示关闭按钮 `closable` / 关闭图标 `closeIcon` | 默认 `开`；图标可写 `[icon]名称` | 右上角关闭入口与图标。 |
| 支持 ESC 关闭 `keyboard` / 显示遮罩 `mask` / 点击遮罩关闭 `maskClosable` | 默认均为 `开` | 表单未保存时建议关掉「点击遮罩关闭」，避免误关。 |

**Footer**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 显示 Footer / 确定 / 取消按钮 | 各自可开关 | 纯展示弹框可把 Footer 全部关掉。 |
| 按钮文案与确定按钮类型 `okType` | 主按钮 / 信息 / 成功 / 警告 / 危险 / 链接 | 删除确认用「危险」，普通提交用「主按钮」。 |

> **提示**：画布上看到的是编辑态：内部需要拖入子块，否则唤出后一片空白。

### 2. 抽屉 `drawer`

**做什么**：从页面边缘滑出的侧边面板，适合筛选条件、详情页或设置项，不打断主视图。

![抽屉显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-drawer.png)

*显示效果：画布编辑态的抽屉卡片，运行时从指定方向滑出。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-drawer.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**外观与方向**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 标题 `title` / 标题颜色 `titleColor` | 文本 / 颜色值；标题默认取组件名 | 抽屉顶部的说明。 |
| 抽屉方向 `placement` | 上 / 右 / 下 / 左；默认 `右` | 详情类常用右侧，筛选条常用顶部。 |
| 尺寸 `size` / 拖拽改变尺寸 `resizable` / 最大尺寸 `maxSize` | 默认 `480`，可写 `60%` / `default` / `large` | 开启拖拽后用户可拉宽抽屉，最大尺寸限制上限。 |
| 推动距离 `pushDistance` | 数值；默认由组件决定 | 多层抽屉叠放时，主内容被推动的距离。 |

**关闭行为 / Footer**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 关闭按钮 / ESC / 遮罩 / 点击遮罩关闭 | 默认均为 `开` | 与弹框一致。 |
| Footer 按钮与文案 | 显示、文案、确定按钮类型 | 与弹框一致，适合「应用筛选」这类提交动作。 |

### 3. 消息 `message`

**做什么**：一条轻量的全局提示，几秒后自动消失，用于保存成功 / 失败回执。

![消息显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-message.png)

*显示效果：编辑态消息卡片显示「保存成功」；运行时以顶部提示条短暂出现。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-message.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**基础**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 内容类型 `contentType` / 内容 `content` | 文本 / 组件盒子；默认 `文本`、内容空 | 选「组件盒子」可在提示里放子块，做带按钮的复杂回执。 |
| 类型 `type` | 成功 / 信息 / 警告 / 错误 / 加载中；默认 `信息` | 决定图标与配色；流程失败时用「错误」。 |
| 持续时间 `duration` | 毫秒；默认 `2000` | 太短容易看不见，重要结果建议 3 秒以上。 |
| 悬停暂停关闭 `pauseOnHover` / 图标 `icon` | 默认 `开`；图标可写 `[icon]名称` | 鼠标移上去时停止倒计时，便于读完长文案。 |

### 4. 通知 `notification`

**做什么**：带标题与描述的通知卡片，信息量比消息更大，适合任务完成、同步结果与告警。

![通知显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-notification.png)

*显示效果：编辑态通知卡片显示「销售订单同步完成，共 120 条记录」；运行时浮现在页面角落。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-notification.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**基础**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 标题 `title` / 描述类型 `descriptionType` / 描述 `description` | 标题默认取组件名；描述可选文本 / 组件盒子 | 标题写结论、描述写细节，例如耗时与记录数。 |
| 类型 `type` | 成功 / 信息 / 警告 / 错误；默认 `信息` | 决定图标与强调色。 |
| 位置 `placement` | 上 / 左上 / 右上 / 下 / 左下 / 右下；默认 `右上` | 多个通知同时触发时错开位置，避免遮挡关键内容。 |
| 持续时间 `duration` / 显示进度条 `showProgress` | 默认 `4500` 毫秒 / 默认 `关` | 进度条让用户知道还剩多久消失。 |
| 可关闭 `closable` / 关闭图标 `closeIcon` / 图标 `icon` / 悬停暂停关闭 `pauseOnHover` | 默认 `开` / 默认图标 / 默认图标 / `开` | 图标都支持 `[icon]名称`；重要告警建议保留手动关闭。 |

## 配置速查

| 需求 | 用哪个块 | 关键配置 |
| --- | --- | --- |
| 让用户确认再操作 | 弹框 | Footer 确定 / 取消按钮、遮罩关闭 |
| 侧边展开筛选或详情 | 抽屉 | 方向、尺寸、拖拽改变尺寸 |
| 一句话回执 | 消息 | 类型、内容、持续时间 |
| 带说明的结果提醒 | 通知 | 标题、描述、位置、进度条 |
| 点击后打开 | 按钮 / 图表 | 事件 → 跳转 → 弹框 / 抽屉展开 |

## 典型组合

1. **确认对话框** — 按钮 → 弹框展开，弹框内放说明文本与确定 / 取消按钮；确定后执行动作并弹出「操作成功」消息。
2. **明细下钻** — 列表点击行 → 抽屉展开，抽屉内放该行的详情[表单](./form.md)或[图表](./chart.md)。
3. **任务通知** — [Flow组件](./flow-widget.md)运行结束 → 通知卡片显示结果与耗时，失败时用「错误」类型。
4. **高级筛选** — 抽屉里放[过滤器](./filter.md)和一组控件，收起时主看板保持清爽。

## 注意事项

- 弹框 / 抽屉是容器，内容需要**拖入子块**；空容器唤出后就是一片空白。
- 消息 / 通知的持续时间过短容易看不见，涉及重要结果建议 3 秒以上，或开启「悬停暂停关闭」。
- 多个通知同时触发时注意位置设置，避免堆叠遮挡关键内容。
- 点击遮罩关闭虽方便，但表单未保存时容易误关；这类场景建议关闭该选项。
