# 系统组件总览

FatNotes 的页面由「块」组成，系统内置的块统称为**系统组件**。在页面右上角打开「组件」面板，可以按分类浏览，也可以用顶部搜索框按名称查找，再添加到当前页面。

系统组件共 **10 类、52 个**。下面按组件面板的分组顺序列出全部组件与功能简介；带链接的分组标题可进入对应章节查看详细说明。「插件」类组件由已安装的插件提供，不计入本清单。

## 组件清单

### [图表](./chart.md)

把查询数据以图形方式呈现，是搭建数据看板的核心组件。

- **折线图** — 按时间或类别展示数值变化趋势，可切换折线、面积、柱状等展示模式。
- **列表** — 以表格形式呈现明细数据，适合查看逐行记录。
- **饼图** — 展示各分类在整体中的占比。
- **K线** — 展示开盘、收盘、最高、最低等行情数据。
- **雷达** — 在多个维度上对比一组指标。
- **热力图** — 用颜色深浅表现数据密度或分布强弱。

### [窗口](./window.md)

承载独立视图与内容容器，用于组织页面中的代码、命令与快捷入口。

- **功能面板** — 集中放置常用功能入口与操作按钮的面板。
- **代码** — 在页面中展示或编写代码片段。
- **终端** — 内嵌命令行终端，可直接在页面里执行命令。

### [布局](./layout.md)

安排多个块的排列与切换方式，决定页面的整体结构。

- **分组** — 把多个块组合成一个整体，便于统一摆放。
- **块面板** — 带边框与标题的容器，用来包裹其他组件。
- **页签** — 用标签页在多组内容之间切换。
- **场景** — 多页面容器，可配置初始页面与页面导航。
- **分割面板** — 用可拖动的分隔条把区域拆成两栏。
- **走马灯** — 轮播展示多张内容卡片。

### AI

- **思维** — 承载 AI 的思考与推理能力，用于输出模型推理结果，也常作为流程中的思维节点。

### 数据

负责接入原始数据并做清洗加工，为图表和其他组件提供数据。

- **数据源** — 连接并管理数据库、数据表，供页面内的查询使用。
- **数据加工** — 以可视化流程编排数据的清洗、转换与加工（ETL）。

### [过滤](./filter.md)

按条件或时间范围筛选数据，并把筛选结果联动给同一页面的其他组件。

- **通用过滤器** — 按字段与条件组合筛选数据。
- **时间过滤器** — 按时间区间筛选，支持常用快捷范围。
- **变量** — 定义可在页面内复用的参数，供查询、组件与流程引用。

### [表单](./form.md)

提供输入、选择与交互控件，用来收集参数或触发动作。

- **表单** — 把多个输入项组织成可统一提交的表单容器。
- **输入框** — 单行文本输入。
- **按钮** — 触发提交或自定义动作。
- **日期选择器** — 选择日期或日期范围。
- **开关** — 切换开 / 关两种状态。
- **单选** — 从一组选项中只选一项。
- **多选框** — 同时勾选多个选项。
- **滑动条** — 拖动选择数值或数值区间。
- **下拉框** — 在下拉列表中选择一项。
- **多选下拉框** — 在下拉列表中选择多项。
- **自动完成** — 输入时实时提示候选值。
- **级联选择** — 按层级联动选择，例如省 / 市 / 区。
- **评分** — 以星级形式打分。
- **颜色选择器** — 拾取颜色值并输出给其他配置。

### [办公](./office.md)

在页面中直接查看和处理常见办公文档。

- **Excel** — 嵌入电子表格，查看与编辑表格数据。
- **Word** — 嵌入并预览 Word 文档。
- **PPT** — 嵌入并播放演示文稿。
- **PDF** — 嵌入并阅读 PDF 文件。

### [弹框](./dialog.md)

提供模态交互与轻量的操作反馈。

- **弹框** — 居中弹出的模态对话框，用于确认或表单交互。
- **抽屉** — 从页面边缘滑出的侧边面板。
- **消息** — 轻量的全局提示，反馈操作结果。
- **通知** — 带标题与内容的通知卡片提醒。

### [其他](./misc.md)

不便归入以上分类的内容展示与自动化组件。

- **文本** — 纯文本内容块。
- **Markdown** — 用 Markdown 语法编写结构化内容。
- **富文本** — 所见即所得编辑，支持粗体、斜体、颜色等样式。
- **图片** — 展示图片资源。
- **视频** — 播放视频文件或视频链接。
- **IFrame** — 嵌入外部网页。
- **二维码** — 把文本或链接生成二维码。
- **时钟任务** — 按设定时间触发事件，联动其他块。
- **屏幕操作** — 编排屏幕、鼠标与键盘操作，完成界面自动化任务。
