# Flow组件

> [流程自动化](../flow-automation.md)讲的是**怎么编排节点**；本章讲的是**怎么把编排好的流程当成一个组件复用**。前者面向画布内部，后者面向页面与流程之间的组合。

:::note 先澄清一个概念
「Flow组件」是**文档章节名**，不是应用组件面板里的分类。组件面板按 `图表 / 窗口 / 布局 / AI / 数据 / 过滤 / 表单 / 办公 / 弹框 / 其他` 分组，见[总览](./overview.md)。应用里与 Flow组件对应的是下面两层能力。
:::

## 两层复用机制

| 层级 | 在哪里用 | 有哪些 | 解决什么 |
| --- | --- | --- | --- |
| **① 工作流卡片** | 放在**看板页面**里，与图表、表单同页 | 数据加工 `etlDag`、思维 `think`、屏幕操作 `screenTask` | 把整张流程画布当成一个块，参与页面布局与联动 |
| **② 工作流组件节点** | 放在**流程画布**里 | ETL 工作流、屏幕精灵工作流、思维工作流 | 把已保存的流程作为子流程插入另一条流程 |

![Flow组件示例页：三张工作流卡片](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-flow-example.png)

*示例页把三张工作流卡片放在同一画布；**红框**标出的是数据加工卡片，它内部就是一张可编辑的 ETL 流程画布。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-blocks-flow-example.png" target="_blank" rel="noopener">查看大图</a>

## ① 工作流卡片

三张卡片的共同点：内部嵌一张流程画布，可配置**流程图样式**（连线路径、输出点 / 输入点大小与颜色、卡片背景与阴影）与**工具栏**（是否显示、鼠标移入还是常态化、位置与外观）。差异在于可用的节点分类：

| 卡片 | 在组件面板的位置 | 画布节点分类 | 典型用途 |
| --- | --- | --- | --- |
| **数据加工** `etlDag` | 数据 | 业务逻辑、工作流组件、输入输出、数据获取、数据处理、基础、消息、屏幕 / 鼠标 / 键盘等 | 采集 → 清洗 → 入库 |
| **思维** `think` | AI | 思维类节点排首位（LLM、TTS、ASR、Agent、记忆读写等），其余同上 | 推理、问答、内容生成 |
| **屏幕操作** `screenTask` | 其他 | 仅屏幕、鼠标、键盘、浏览器、剪切板、媒体、系统 | 界面自动化、批量操作 |

### 运行与调度

页面上只要存在工作流卡片，页签工具栏就会出现**「运行」**入口：

- **立即运行 / 停止** — 手动执行当前页的工作流；
- **定时运行** — 配置 Cron 表达式，也可选每 5 分钟、每小时、每天、每周等预设；
- **运行页面** — 集中查看当前面板有哪些工作流卡片、各自状态与执行结果。

### 与页面联动

工作流卡片是 `isFlowBlock`，既能**接收入参**（由表单变量、图表点击等传入），也能在流程结束时**输出时触发**联动，把结果交给图表、列表或其他块。思维卡片尤其常用作「输入 → 推理 → 输出」的中间节点。


## 逐个组件详解

三张工作流卡片的私有配置结构完全相同：**流程数据 + 流程图样式 + 工具栏**；差异在节点分类与内部画布。下面逐张列出配置项与显示效果，运行 / 定时 / 联动机制见前文。

### 1. 数据加工 `etlDag`

**做什么**：把「采集 → 清洗 → 入库」的 ETL 流程画布整张放进看板，可立即运行或定时运行。

![数据加工显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-etlDag.png)

*显示效果：内嵌流程画布，「开始 → 输入」节点带触发时间等参数，右侧是节点面板。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-etlDag.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**样式 / 画布**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 流程数据 `etlFlow` | 节点与连线 JSON；默认空 | 节点分类最全：业务逻辑、工作流组件、输入输出、数据获取、数据处理、基础、消息、屏幕 / 鼠标 / 键盘等。 |
| 流程图样式 `flowStyle` | 连线路径 / 输出点 / 输入点大小与颜色 / 卡片背景与阴影 | 只管画布外观；节点逻辑在画布里编排。 |
| 工具栏 `toolbar` | 是否显示（默认 `开`）、悬停或常态化、位置与外观 | 三种卡片共用同一套工具栏配置。 |

> **提示**：页面上有工作流卡片时，页签工具栏会出现「运行」入口：立即运行 / 停止、定时运行（Cron 或预设）、运行页面。

### 2. 思维 `think`

**做什么**：AI 推理流程卡片：思维类节点排在首位（LLM、TTS、ASR、Agent、记忆读写等），其余节点同数据加工。

![思维显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-think.png)

*显示效果：与数据加工相同的流程画布形态，节点面板首屏为思维类节点。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-think.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**样式 / 画布**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 流程数据 `thinkFlow` | 节点与连线 JSON；默认空 | 适合「输入 → 推理 → 输出」：把表单变量作为入参，结果写入变量或触发联动。 |
| 流程图样式 / 工具栏 | 与数据加工一致 | 连线、节点端口、卡片配色与工具栏显隐。 |

### 3. 屏幕操作 `screenTask`

**做什么**：界面自动化流程卡片，节点面板只保留屏幕、鼠标、键盘、浏览器、剪切板、媒体、系统七类。

![屏幕操作显示效果](pathname:///fat-notes-home/img/instruction/sysBlocks/zh/sys-block-screenTask.png)

*显示效果：横宽的自动化流程画布，节点与连线清晰可见。* · <a href="/fat-notes-home/img/instruction/sysBlocks/zh/sys-block-screenTask.png" target="_blank" rel="noopener">查看大图</a>

**私有配置**：

**样式 / 画布**

| 配置项 | 可选值 / 默认 | 说明 |
| --- | --- | --- |
| 流程数据 `screenFlow` | 节点与连线 JSON；默认空 | 常用节点：找图、找色、找文本、点击、移动、滚轮、按键、读写剪切板、启动程序。 |
| 流程图样式 / 工具栏 | 与数据加工一致 | 三类卡片共用；差异只有可用节点分类。 |

> **提示**：工作流卡片既能接收入参（表单变量、图表点击），也能在流程结束时「输出时触发」联动，把结果交给图表、列表或其它块。

## ② 工作流组件节点

在任意流程画布里打开节点面板，找到 **工作流组件** 分类，会看到三个节点：

| 节点 | 复用哪种流程 |
| --- | --- |
| **ETL 工作流** | 已保存的数据加工流程 |
| **屏幕精灵工作流** | 已保存的屏幕操作流程 |
| **思维工作流** | 已保存的思维流程 |

拖入节点后会弹出**工作流选择器**：按名称 / 描述搜索，按流程类型过滤，选中后把该工作流的画布数据载入当前流程。这样，一条调好的流程就能像函数一样被多条流程调用。

:::tip 什么时候用节点、什么时候用卡片
需要在**页面上看结果、定时跑、和图表联动** → 用工作流卡片；需要在**另一条流程里复用一段逻辑** → 用工作流组件节点。两者引用的是同一批已保存的工作流。
:::

## 流程节点分类速查

工作流画布的节点面板按分类组织，常用分类如下（具体节点随版本与插件增减）：

| 分类 | 代表节点 |
| --- | --- |
| 流程控制 | 开始、结束 |
| 业务逻辑 | 代码、条件、循环、表达式、迭代、列表变量 |
| **工作流组件** | ETL / 屏幕精灵 / 思维工作流 |
| 输入 & 输出 | 输入、输出 |
| 数据获取 | HTTP 请求 |
| 数据处理 | 数据增 / 删 / 改 / 查 |
| 基础组件 | 变量组、文本、日志、等待、JSON 转换 |
| 消息 | 消息发送、消息接收 |
| 静态节点 | 注解、富文本、背景、画板 |
| 屏幕 / 鼠标 / 键盘 | 找图、找色、找文本、点击、移动、滚轮、按键 |
| 剪切板 / 系统 / 媒体 | 读写剪切板、启动程序、性能信息、音视频转码 |
| 思维 | LLM、TTS、ASR、Agent、问题分类、文档提取、记忆读写 |
| 浏览器操作 | 打开网页、点击元素等（部分由插件提供） |

## 典型组合

1. **定时数据管道** — 数据加工卡片编排「抓取 → 清洗 → 写入数据表」，配置每天 8 点运行；[图表](./chart.md)直接查询加工后的表。
2. **AI 问答看板** — [输入框](./form.md)的变量传入思维卡片 → 推理结果写入变量 → [文本](./misc.md)块用标题高亮显示结果。
3. **流程复用** — 把「登录 + 导出」的屏幕操作存成工作流，在多条自动化流程里用「屏幕精灵工作流」节点调用。
4. **异常通知** — 流程失败分支输出时触发[通知](./dialog.md)块，把错误摘要推到页面。

## 注意事项

- 工作流卡片的配置重心在**画布内容**，右侧样式分组只管画布与工具栏外观。
- 定时运行作用于**当前页的工作流卡片**；页面被删除或卡片移除后，调度随页面失效。
- 工作流选择器只列出**已保存**且类型匹配的流程；临时编辑未保存的画布不会被检索到。
- 组件面板的 AI、数据两类还包含思维卡、数据源、数据加工等块，它们与本章是同一批能力的不同视角。
