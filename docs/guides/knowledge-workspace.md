# 知识工作台

FatNotes 使用接近专业 IDE 的布局承载复杂知识工作。你可以同时查看目录、编辑内容、运行工具，并随时切换到数据或自动化视图。

## 建议的组织方式

1. 按项目建立工作空间，避免不相关内容混杂。
2. 用目录表达稳定分类，用标签表达跨目录主题。
3. 在入口笔记中维护项目目标、关键链接和当前进展。
4. 将原始资料与提炼后的知识分开保存。

## 支持的内容

工作台可承载 Markdown、富文本、表格、PDF 等不同类型内容。实际支持范围取决于当前版本和已安装插件。
