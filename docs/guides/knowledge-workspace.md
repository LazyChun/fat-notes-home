# 知识工作台

FatNotes 采用接近专业 IDE 的界面布局来承载复杂的知识工作。目录树、编辑区、工具面板同屏呈现，你可以一边浏览资料、一边编辑内容、一边运行工具，并随时切换到数据看板或自动化流程视图。

## 界面布局

| 区域 | 用途 |
| --- | --- |
| 活动栏（最左侧） | 快速切换资源管理、搜索、插件等核心功能入口 |
| 主侧栏 | 浏览工作空间内的文件目录与资源 |
| 编辑区 | 打开和编辑笔记、看板、流程，支持多页签 |
| 次级侧栏 | AI 对话（Chat）常驻区域，随时唤起 |
| 底部面板 | 终端、输出、问题等信息区域 |
| 命令面板（`Ctrl + K`） | 全局搜索文件、功能与命令的快捷入口 |

## 建议的组织方式

1. **按项目建立工作空间**：一个项目一个目录，避免不相关内容混杂。
2. **用目录表达稳定分类，用标签表达跨目录主题**：分类不宜过深，两到三层通常够用。
3. **在入口笔记中维护项目概览**：写清项目目标、关键链接和当前进展，打开工作空间先看这一页。
4. **原始资料与提炼后的知识分开保存**：比如 `资料/` 存放原始文档，`笔记/` 存放自己整理的结论，方便追溯来源。

## 支持的内容类型

工作台可以承载多种内容形态，同一页面内可以混排：

- **文档类**：Markdown、富文本、代码（Monaco 编辑器）、类 Excel 电子表格（Univer）、Word、PPT、PDF。
- **图表类**：折线、饼图、热力、K 线等 ECharts 图表块。
- **工具类**：终端、流程图、思维导图、数据看板组件。

实际支持范围取决于当前版本和已安装插件，部分能力（如 OCR、浏览器自动化）通过插件按需提供。
