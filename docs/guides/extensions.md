# 扩展中心

> 「扩展中心」是 FatNotes 统一收纳、浏览与安装**扩展**的地方。它把 **FatHub 应用市场**（社区共享的扩展）和你**自己创建的扩展**放在同一个面板里，是 FatNotes 插件生态的「入口与管家」——你在这里找扩展、装扩展、管扩展。

本文讲的是活动栏里的 **「扩展」模块**（扩展中心）。想快速了解 FatNotes 全部能力，请先看 [功能总览](./features.md)；想了解现成的热门扩展，请看 [热门插件](../plugins/index.md)；想自己动手开发，请看 [插件开发](../plugin-dev/index.md)。

---

## 一、扩展中心在哪里

活动栏默认有 7 个模块，按顺序从上到下，**「扩展」排在第 4 位**（在数据库之后、功能之前）：

| 顺序 | 活动栏入口 | 打开后 | 主要用途 |
| --- | --- | --- | --- |
| 1 | 文件管理 | 文件管理器 | 笔记本、页面树与页面内容 |
| 2 | 搜索 | 搜索侧栏 | 按名称 / 内容检索 |
| 3 | 数据库 | 数据库管理器 | 数据源、表结构与数据浏览 |
| 4 | **扩展** | **扩展中心** | **本文主角：插件、功能、工作流、技能等目录** |
| 5 | 功能 | 功能列表 + 功能页 | 打开自己构建的小应用 |
| 6 | 资源仓库 | 资源仓库 | 图片、音视频等素材 |
| 7 | 运行 | 运行面板 | 正在运行 / 已完成 / 定时运行规则 |

点开「扩展」后，界面分成两块：**左侧导航树**（按类型组织扩展）与**右侧内容区**（搜索框 + 列表 / 详情）。

![扩展中心界面总览，红框标出左侧导航树标题「扩展中心」、FatHub 与自定义分组、右侧搜索框「搜索应用名称、描述或slug」](pathname:///fat-notes-home/img/instruction/extensions/zh/extensions-overview.png)

*图中左侧为扩展中心导航树：上方「FatHub」市场（展开态）下包含插件、功能、工作流、高级插件、Skills、MCP Tools、MCP Servers、插件集合；下方为「我的功能 / 我的工作流 / 自定义插件 / 自定义 Skills …」等自定义分组。右侧顶部是搜索框，占位文字为「搜索应用名称、描述或slug」。*

### 界面部件速查

| 部件 | 说明 |
| --- | --- |
| 扩展中心标题 | 面板左上角，带云上传图标，是扩展的总入口 |
| 导航树 | 左侧按「FatHub 市场」与「我的 / 自定义」分组列出全部扩展类型 |

## 二、结构总览：FatHub 市场 + 我的 / 自定义

扩展中心把扩展分成两大部分：**从社区来的**和**自己做的**。

![扩展中心结构示意图：中心节点「扩展中心」分出 FatHub 应用市场（插件/功能/工作流/高级插件/Skills/MCP Tools/MCP Servers/插件集合）与我的/自定义扩展（我的功能/我的工作流/自定义插件/自定义Skills/自定义MCP Tool/自定义MCP Server/自定义高级插件/自定义插件集合）](pathname:///fat-notes-home/img/instruction/extensions/zh/extensions-structure.svg)

- **FatHub 应用市场**：社区共享的扩展仓库。里面按类型分了 8 个栏目——插件、功能、工作流、高级插件、Skills、MCP Tools、MCP Servers、插件集合，你在里面浏览、搜索、安装别人做好的扩展。
- **我的 / 自定义扩展**：你自己创建和拥有的扩展。包括「我的功能 / 我的工作流」（你发布的功能与工作流）以及「自定义插件 / 自定义 Skills / 自定义 MCP Tool / 自定义 MCP Server / 自定义高级插件 / 自定义插件集合」等可新建的分组，每个自定义分组右侧都有一个 `+` 用于新建。

:::tip 两类扩展的关系
FatHub 上的扩展是「别人做、你装」，自定义扩展是「你自己做」。二者最终都会被 FatNotes 的功能、流程与 AI 调用，区别只是来源不同。安装到本地的 FatHub 扩展，也会出现在你对应的「我的 / 自定义」列表里。
:::

## 三、FatHub 应用市场

FatHub 是 FatNotes 的扩展商店，按扩展类型分了 8 个栏目。点左侧导航树的 **FatHub** 即可展开：

| 栏目 | 里面是什么 | 典型用途 |
| --- | --- | --- |
| **插件** | 通用插件（界面 / 能力增强包） | 安装后增强 FatNotes 的某类功能或界面 |
| **功能** | 打包好的「功能」应用 | 一键安装一个小应用，出现在活动栏「功能」里直接打开 |
| **工作流** | 预置的流程自动化模板 | 安装后可被 [流程自动化](./flow-automation.md) 直接调用 |
| **高级插件** | 能力更强、可能带配置的插件 | 复杂的数据处理、外部系统集成等 |
| **Skills** | 给 AI 用的「技能」 | 让 AI 对话具备某项专门能力（如写报告、查资料） |
| **MCP Tools** | 符合 MCP 协议的工具 | 把外部工具暴露给 AI，作为可调用函数 |
| **MCP Servers** | 符合 MCP 协议的服务器 | 提供一组 MCP 工具 / 资源的服务端 |
| **插件集合** | 多个扩展的打包合集 | 一次安装一组相关扩展，省去逐个添加 |

:::info 当前选中哪种类型，右侧就显示哪种
导航树里点哪个栏目（如「插件」），右侧内容区就列出该栏目下的扩展。截图示例中当前选中「插件」，但列表为空——说明该环境尚未安装或发布任何插件，安装后这里会列出具体条目。
:::

## 四、我的 / 自定义扩展

这一区是你**自己创建**的扩展，也是扩展中心的「创作台」：

| 分组 | 说明 | 如何新建 |
| --- | --- | --- |
| **我的功能** | 你发布 / 拥有的功能应用 | 在「功能」模块中发布后归集于此 |
| **我的工作流** | 你创建的工作流 | 在流程自动化中保存后归集于此 |
| **自定义插件** | 你自己写的插件 | 点分组右侧 `+` |
| **自定义 Skills** | 你自定义的 AI 技能 | 点分组右侧 `+` |
| **自定义 MCP Tool** | 你接入的 MCP 工具 | 点分组右侧 `+` |
| **自定义 MCP Server** | 你接入的 MCP 服务器 | 点分组右侧 `+` |
| **自定义高级插件** | 你写的高级插件 | 在分组内新建 |
| **自定义插件集合** | 你整理的扩展合集 | 点分组右侧 `+` |

带 `+` 的分组（自定义插件、自定义 Skills、自定义 MCP Tool、自定义 MCP Server、自定义插件集合）是最常用的「新建入口」：点 `+` 后按表单填写名称、类型、配置等信息，即可创建一个新的自定义扩展。

![扩展中心导航树局部：自定义插件与自定义 Skills 分组各含一个示例条目（adf / adsf），右侧带 + 新建按钮](pathname:///fat-notes-home/img/instruction/extensions/zh/extensions-overview.png)

*截图示例里，「自定义插件」下已有一个名为 `adf` 的条目，「自定义 Skills」下有一个名为 `adsf` 的条目——这就是「自定义」分组里挂着的你自己的扩展。*

## 五、搜索与安装

右侧内容区顶部的搜索框是扩展中心的「搜索引擎」：

- **占位文字**：`搜索应用名称、描述或slug`
- **匹配范围**：扩展的**名称**、**描述**，以及 **slug**（扩展在系统中的唯一短标识）
- **作用范围**：仅过滤**当前选中类型**下的扩展。例如选中「插件」时，只在插件里搜；切到「MCP Tools」时，就在 MCP Tools 里搜。

安装流程通常是：在 FatHub 对应栏目找到扩展 → 进入详情 → 点安装（或「获取」） → 安装完成后，它会出现在你对应的「我的 / 自定义」列表，并可在功能、流程或 AI 中被调用。

:::warning 安装前先看清楚类型
不同类型安装后的落点和用法不同：功能会出现在活动栏「功能」里、工作流会出现在流程自动化里、Skills / MCP 会出现在 AI 配置里。装错类型可能找不到入口，建议安装前确认它属于哪个栏目。
:::

## 六、扩展如何被使用

扩展不是「装完就完事」，它们最终都要被 FatNotes 的具体能力消费：

- **功能 / 工作流**：安装或创建后，直接在活动栏「功能」「运行」中打开即用，是看得见、点得开的小应用 / 自动化。
- **Skills**：接入 AI 对话后，让 AI 具备某项专门能力，出现在 AI 的可用技能里。
- **MCP Tools / MCP Servers**：把外部工具 / 服务暴露给 AI，作为 AI 可调用的函数或资源。
- **插件 / 高级插件**：增强 FatNotes 的界面或数据处理能力，通常随应用启动自动加载。
- **插件集合**：一次引入一组相关扩展，统一生效。

![扩展消费链路：扩展中心安装/创建 → 落入功能/流程/AI → 被用户直接使用](pathname:///fat-notes-home/img/instruction/extensions/zh/extensions-structure.svg)

## 七、与「热门插件」「插件开发」的关系

扩展中心是扩展的**管理入口**，而文档站里还有两个与它紧密相关的分类，三者各管一段：

- **[热门插件](../plugins/index.md)**：展示社区里受欢迎、值得一试的现成扩展清单——相当于 FatHub 的「精选推荐」，适合先来这里挑。
- **[插件开发](../plugin-dev/index.md)**：教你怎么从零写一个插件 / 功能 / 工作流并发布——写完的成果，就是回到扩展中心以「自定义扩展」的形式被创建和管理。
- **扩展中心（本文）**：连接上面两者的「中枢」，负责把别人的扩展装进来、把自己的扩展管起来。

一句话：**热门插件**告诉你有什么可装，**插件开发**教你自己做，**扩展中心**负责装和管。

## 八、注意事项

- **两类来源别混淆**：FatHub 是社区共享、你安装；自定义是你自己创建。二者入口都在左侧导航树，按分组区分。
- **搜索只限当前类型**：搜索框只过滤当前选中的扩展类型，切栏目后再搜。
- **安装看类型落点**：功能→功能模块、工作流→流程自动化、Skills/MCP→AI 配置，装前确认类型以免找不到入口。
- **自定义分组用 `+` 新建**：自定义插件 / Skills / MCP Tool / MCP Server / 插件集合分组右侧的 `+` 是新建入口。
- **扩展最终要被消费**：装完记得去对应的功能、流程或 AI 配置里启用 / 调用，否则只是躺在列表里。
- **slug 是身份标识**：搜索支持按 slug 查找，slug 是扩展在系统中的唯一短标识，重名时靠它区分。
