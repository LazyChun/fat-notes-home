# 快捷输入

> 在看板空白处**双击**，会弹出一个小输入框：直接写字，回车就生成一张 Markdown 卡片；写一个以 `$` 开头的命令，回车就生成指定类型、指定数据、指定样式的卡片。它把「打开组件面板 → 找到组件 → 拖进画布 → 打开配置抽屉」压缩成一次键盘输入。

![双击空白处唤起的快捷输入浮层，红框标出输入区与快捷键提示](pathname:///fat-notes-home/img/instruction/quick-input/zh/qi-overview.png)

*红框里就是快捷输入浮层：上方是输入框（占位文字已经说明了两种用法），下方是一行快捷键提示。它出现在你双击的位置附近。*

---

## 一、在哪里唤起

| 场景 | 操作 | 结果 |
| --- | --- | --- |
| 看板画布空白处 | **双击** | 唤起浮层，新卡片追加到当前看板底部 |
| 分组 / 块面板等容器内部空白处 | **双击** | 唤起浮层，新卡片追加到**该容器**底部 |
| 双击在已有卡片上 | — | 不触发快捷输入，按看板原有逻辑进入卡片编辑 |
| 预览模式、只读模式、配置态、功能页 | 双击 | 不唤起，避免误改 |
| 点击浮层外 / 输入框失焦 | — | 直接关闭，不创建任何东西 |

浮层本身没有菜单入口，也不在活动栏里 —— 它只有一个触发方式：**双击空白**。空输入直接按回车同样只会关闭浮层。

### 键盘操作

| 按键 | 作用 |
| --- | --- |
| `Enter` | **有建议时**：把当前高亮建议补进输入框；**没有建议时**：解析并创建卡片 |
| `↑` / `↓` | 在建议列表里循环切换高亮项（鼠标悬停也会改变高亮） |
| `Tab` | 采纳当前高亮建议 |
| `Shift + Enter` | 在输入框里换行，写多行 Markdown 内容 |
| `Esc` | 取消并关闭 |

:::tip Enter 的两副面孔
命令输入到一半时，建议列表还在，`Enter` 只是**补全**；等你把类型名写完整、或用 `}` 闭合配置段后，建议列表消失，此时 `Enter` 才是**创建**。这是新手最容易困惑的一点。
:::

## 二、两种输入，一张对照表

| 输入 | 生成 | 适合做什么 |
| --- | --- | --- |
| 不以 `$` 开头的任意文本 | **Markdown 卡片**，文本原样成为卡片内容 | 速记、清单、会议纪要、章节标题 |
| `$` 开头的命令 | 指定类型的**组件卡片**，可带查询与样式 | 图表、数值、表格、表单、容器等各类块 |

---

## 三、纯文本：一句话变一张卡片

输入内容支持多行 Markdown，写完按 `Enter` 即可。

![输入多行 Markdown 并回车生成卡片的动图演示](pathname:///fat-notes-home/img/instruction/quick-input/zh/qi-markdown.gif)

*动图：双击空白 → 输入标题与清单 → 回车 → 画布上出现 Markdown 卡片。*

生成的卡片使用 Markdown 块的默认尺寸，追加到当前容器已有内容的下方；内容就是你在浮层里写的原文，之后仍可在卡片的配置抽屉里继续编辑。

## 四、`$` 命令语法

一条完整命令长这样（对应本机的演示数据源 `test_dog` / 指标「销售订单」）：

```text
$时序图:test_dog-销售订单{agg:sum title:销售趋势}
```

![快捷输入命令的四段语法结构](pathname:///fat-notes-home/img/instruction/quick-input/zh/qi-syntax-map.svg)

抽象成一行：

```text
$卡片类型[:数据源-指标][{配置项 配置项 ...}]
```

| 段 | 写法 | 说明 | 必填 |
| --- | --- | --- | --- |
| 卡片类型 | `$折线图`、`$时序图`、`$数值`、`$line` | 写**展示名**、**type id** 或 **id** 都行；精确匹配优先，其次包含匹配与拼音匹配 | 是 |
| 数据源 | `:test_dog` | 冒号引出，匹配工作区里的数据源名称；查询类配置必须写这一段 | 否 |
| 指标 | `-销售订单` | 短横线连接，匹配该数据源下的指标实体表名 | 否 |
| 配置段 | `{agg:sum title:销售趋势}` | 花括号内是**空格分隔**的 `key:value`，用来配置查询与外观 | 否 |

名称里含空格也能用（例如英文界面的 `$Time Series`），只要写全即可；但配置段的**值不能含空格**，因为空格就是配置项之间的分隔符。

### 建议列表跟着语法走

输入 `$` 后，浮层会按当前输入位置给出对应候选，边写边选，不必背名字：

![输入 $ 后的卡片类型建议列表](pathname:///fat-notes-home/img/instruction/quick-input/zh/qi-types.png)

*`$` 之后列出所有可用于快捷创建的卡片类型，右侧是 type id。内置类型与已加载的插件类型（如「时序图」「数值」）都在里面；布局框架类系统块不在列表中。*

![冒号之后的数据源建议](pathname:///fat-notes-home/img/instruction/quick-input/zh/qi-source.png)

*输入 `:` 后列出数据源，右侧显示该数据源下的指标数量；选中会自动补上 `-`，直接进入指标输入。*

![短横线之后的指标建议](pathname:///fat-notes-home/img/instruction/quick-input/zh/qi-metric.png)

*输入 `-` 后列出该数据源下的指标表；选中会自动补上 `{`，直接进入配置段。*

## 五、配置段：查询 + 样式

花括号里每输入一个关键字，建议列表都会给出下一层候选：

![配置段的关键字建议](pathname:///fat-notes-home/img/instruction/quick-input/zh/qi-options.png)

*`{` 之后列出全部可用关键字；继续写 `agg:`、`groupBy:`、`filters:{`、`bgColor:` 等，会分别提示聚合函数、维度列、过滤列和推荐色值。*

### 配置项速查

| 关键字 | 取值 / 写法 | 作用 | 是否要求 `数据源-指标` |
| --- | --- | --- | --- |
| `agg:` | `sum` `avg` `min` `max` `count` `topk` `bottomk` | 指标的聚合方式，写入查询的聚合函数 | **需要** |
| `groupBy:` | 维度列名，多个用逗号分隔，如 `groupBy:地区,产品类别` | 按维度分组 | **需要** |
| `filters:{...}` | `列名=值`，多个用逗号分隔，如 `filters:{地区=华东,状态=完成}` | 等值过滤条件 | **需要** |
| `title:` / `name:` | 不含空格的文本 | 卡片标题；不写时用类型展示名 | 不需要 |
| `bgColor:` | `#rgb` / `#rgba` / `#rrggbb` / `#rrggbbaa` | 卡片背景色 | 不需要 |
| `padding:` | `0`–`100` 的整数 | 卡片四边内边距（px） | 不需要 |
| `theme:` | `classic` / `cold` / `hot` | 图表配色主题 | 不需要 |
| `graphType:` | 热力图：`basic` / `calendar`；雷达图：`basic` / `aqi` | 切换这两种图的图形形态，其它类型不支持 | 不需要 |

只写样式不写查询完全可以，例如：

```text
$数值{title:销售总额 bgColor:#e6f4ff padding:16}
```

反过来，只要用了 `agg`、`groupBy`、`filters` 中的任意一个，就必须先把 `:数据源-指标` 写全，否则会提示「配置查询条件前需先指定 数据源-指标」。

### 一条完整命令

![完整命令输入示例](pathname:///fat-notes-home/img/instruction/quick-input/zh/qi-syntax.png)

*`$时序图:test_dog-销售订单{agg:sum title:销售趋势}`：创建一张时序图卡片，对「销售订单」的金额求和，标题为「销售趋势」。*

![命令创建出的卡片效果](pathname:///fat-notes-home/img/instruction/quick-input/zh/qi-result.png)

*上图是两种输入各创建一张卡片后的画布：Markdown 卡片与带数据的时序图卡片。*

用动图看整个过程：

![使用 $ 命令创建图表卡片的动图演示](pathname:///fat-notes-home/img/instruction/quick-input/zh/qi-command.gif)

*动图：双击空白 → `$` 调出类型建议 → 依次补全类型、数据源、指标与配置 → 回车 → 图表卡片出现在画布上。*

:::info 创建的是「默认配置的卡片」
快捷输入负责把卡片**建出来并填好上面这些配置**。时间范围、联动事件、坐标轴、图例、颜色映射等更细的设置，仍然在卡片的配置抽屉里完成；生成后按常规方式继续编辑即可。
:::

## 六、常用组合速查

把下面命令里的 `test_dog`、`销售订单` 换成你工作区里的名称即可。

| 想要什么 | 输入 |
| --- | --- |
| 随手记一段文字 | `本周待办：核对报表、约评审` |
| 一张空白图表稍后再配 | `$折线图` |
| 指定标题与底色的数值卡 | `$数值{title:销售总额 bgColor:#e6f4ff padding:16}` |
| 对销售额求和的时序图 | `$时序图:test_dog-销售订单{agg:sum title:销售趋势}` |
| 按地区分组的占比图 | `$饼图:test_dog-销售订单{agg:sum groupBy:地区 title:地区占比}` |
| 只看华东的金额 | `$数值:test_dog-销售订单{agg:sum filters:{地区=华东} title:华东销售额}` |
| 换一套冷色主题 | `$折线图:test_dog-销售订单{agg:avg theme:cold}` |
| 日历形态的热力图 | `$热力图:test_dog-销售订单{graphType:calendar}` |

## 七、报错与注意事项

解析失败时不会关闭浮层，错误文字直接显示在输入框下方，改完再按 `Enter` 就行。

![未知卡片类型的错误提示](pathname:///fat-notes-home/img/instruction/quick-input/zh/qi-error.png)

| 提示 | 常见原因 |
| --- | --- |
| `未知卡片类型: X` | `$` 后的名字没匹配上，或对应插件尚未加载；从建议列表里选一个 |
| `未找到数据源` / `未找到指标` | `:数据源-指标` 名称写错，或两者之间的 `-` 漏了 |
| `配置查询条件前需先指定 数据源-指标` | 只写了 `{}` 里的 `agg` / `groupBy` / `filters` |
| `未找到维度` / `过滤条件格式错误` / `无法识别的配置` | 维度列只认维度类型的列；过滤必须写 `列名=值`；关键字拼错或值里带了空格 |
| `无效颜色值` / `无效内边距` / `未知图表色彩` / `当前卡片类型不支持配置` | 超出取值表范围，或把 `graphType` 用在了不支持的卡片上 |
| `卡片创建失败` | 后端没有返回新块，可重试或检查应用日志 |

另外几条容易踩的边界：

- **配置值不能带空格**：`title:Sales Trend` 会被拆成两个配置项，后半截报「无法识别的配置」；请用 `title:SalesTrend` 或连字符。
- **名称里的分隔符有歧义**：数据源、指标、列名若自带 `:`、`-`、`{`、`}`，解析会按这些符号切段，建议改用不带符号的名称。
- **新卡片不在双击的位置**：它统一追加到目标容器已有内容的**底部**（`x=0`），尺寸取该类型的默认尺寸，之后可自由拖动缩放。
- **插件类型以本机为准**：建议列表里的类型由内置块 + 当前已加载插件共同决定，不同机器、不同插件安装情况，列表会不一样。
- **双击卡片本体无效**：只有双击在网格空白处才触发，双击卡片会走原有的看板编辑逻辑。
