# 数据库

> 「数据库」是 FatNotes 统一存放和浏览**结构化数据**的地方。它把本地 SQLite 库注册成**数据源**，组织成「库 → 表 → 列」的层级；你在左侧活动栏就能直接看数据、筛数据、增删行，它也是[数据看板](./data-dashboard.md)、[功能](./functions.md)、[流程自动化](./flow-automation.md) 共用的**数据底座**。

本文讲的是活动栏里的 **「数据库」模块**（数据库管理器）。想快速了解 FatNotes 全部能力，请先看 [功能总览](./features.md)。

---

## 一、数据库模块在哪里

活动栏默认有 7 个模块，按顺序从上到下，**「数据库」排在第 3 位**（在搜索之后、扩展之前）：

| 顺序 | 活动栏入口 | 打开后 | 主要用途 |
| --- | --- | --- | --- |
| 1 | 文件管理 | 文件管理器 | 笔记本、页面树与页面内容 |
| 2 | 搜索 | 搜索侧栏 | 按名称 / 内容检索 |
| 3 | **数据库** | **数据库管理器** | **本文主角：数据源、表结构与数据浏览** |
| 4 | 扩展 | 扩展中心 | 插件、功能、工作流、技能等目录 |
| 5 | 功能 | 功能列表 + 功能页 | 打开自己构建的小应用 |
| 6 | 资源仓库 | 资源仓库 | 图片、音视频等素材 |
| 7 | 运行 | 运行面板 | 正在运行 / 已完成 / 定时运行规则 |

点开「数据库」后，界面分成三块：**左侧数据库树**、**右侧表数据区**、以及右侧表格上方的**筛选 / 工具行**。

![数据库工作区总览，红框标出活动栏数据库图标、数据库管理器面板标题、添加数据库按钮与筛选输入框](pathname:///fat-notes-home/img/instruction/database/zh/db-overview.png)

*红框从上到下：活动栏的数据库（圆柱）图标、左侧「数据库管理器」面板、蓝色「添加数据库」按钮、右侧表格上方的筛选输入框。图中树里展开了 `test_db`，其下是一张名为 `goodman` 的表。*

### 界面部件速查

| 部件 | 说明 |
| --- | --- |

:::

## 二、库、表、列：数据的三层结构

数据库管理器里的数据按 **库 → 表 → 列** 三级组织：

- **库（Database）**：一个独立的数据源，对应工作区里的一个物理 SQLite 文件。
- **表（Table）**：库下的二维表，由若干**行（记录）**和**列（字段）**组成。
- **列（Column）**：表的字段，有**列名**与**字段类型**。例：`goodman` 表包含 `ID`、`name`、`age`、`createDate`、`score`、`lastName` 等列。

![表数据区，红框标出工具栏（添加行/删除）与筛选行，表中为 排序/ID/name/age/createDate/score/lastName 各列与多条记录](pathname:///fat-notes-home/img/instruction/database/zh/db-table.png)

*一张表长这样：左侧「排序」是拖拽手柄，其后依次是各列；底部 `共 8 条` 表示当前表共有 8 行记录。列（字段）的结构由「添加数据库 / 建表」时确定。*

:::tip 物理存储在哪里？
库的物理文件位于工作区 `dbs/sqlite3_dbs/<8位hex>.db`，库的元数据（库 / 表 / 列）记录在 `dbs/items.json` 与 `dbs/databaseSources.json`。这是「数据库管理器」背后真正读写的地方，改前记得备份。
:::

## 三、浏览与筛选表数据

打开任意一张表，默认展示全部行。常用操作：

| 操作 | 位置 | 效果 |
| --- | --- | --- |
| **按列筛选** | 筛选行 `字段 = 值`，点 `+` 可叠加多条 | 只显示满足条件的行，多条件为「且」关系 |
| **排序** | 首列「排序」拖拽手柄 | 手动调整行的上下顺序 |
| **翻页** | 底部分页条 | 控制每页条数、切换页码 |
| **查看字段** | 表头 | 每一列即一个字段，列名即字段名 |

筛选输入框的占位为「请输入过滤条件」，直接输入关键字即可实时过滤。需要按多个字段组合过滤时，点筛选行末尾的 `+` 继续添加条件。

## 四、添加数据库（新建数据源）

点左侧蓝色 **「添加数据库」** 按钮，弹出「新建数据库」对话框：

![新建数据库对话框，红框标出表单区（名称/类型/默认/ID）与取消/确定按钮](pathname:///fat-notes-home/img/instruction/database/zh/db-adddb.png)

*对话框包含：必填的**名称**、**类型**（默认 `默认`，即本地 SQLite 库）、只读的 **ID**（系统自动生成）。填好名称后点「确定」即创建。*

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 名称 | 必填（带红星） | 数据库的显示名，会出现在左侧树里 |
| 类型 | 默认 `默认` | 当前为本地库类型 |
| ID | 只读 | 系统自动生成的 8 位标识，对应物理文件名 |
| 取消 / 确定 | — | 取消放弃，确定创建并写入数据源 |

创建成功后，新库立即出现在左侧数据库树中，可继续在其中建表、录入数据，随后就能被看板、功能、流程直接消费。

## 五、编辑行数据

在表数据区顶部工具栏可以对手动做轻量编辑：

![点击「添加行」后顶部出现一条新空行（自动生成 ID），红框标出该空行与工具栏的添加行/删除按钮](pathname:///fat-notes-home/img/instruction/database/zh/db-edit.png)

*点「添加行」会在表头下方插入一条**新空行**（ID 由系统自动生成，其余字段留空待填）；选中行后点「删除」可移除。编辑会直接落盘。*

| 操作 | 效果 |
| --- | --- |
| 添加行 | 在表头下插入一条新记录，ID 自动生成 |
| 删除 | 删除当前选中的行 |
| 单元格编辑 | 直接点击单元格修改内容，改动即时保存到物理库 |

:::warning 改动直接落盘
数据库管理器是**轻量编辑**入口，增删改会直接写入工作区的 SQLite 文件，**没有撤销**。对演示库或重要数据操作前，先备份 `dbs/` 目录。
:::

## 六、与其他模块的联动

数据库是 FatNotes 各数据相关能力的共同底座，它和这些模块连成一条链：

![数据库模块数据链路：建库→注册→结构→读写→被看板/功能/流程消费](pathname:///fat-notes-home/img/instruction/database/zh/db-mechanism.svg)

- **数据看板**：图表、表格块通过查询直接读取这里的表，把行数据变成可视化。
- **功能**：功能页可以把输入回填到查询，从数据库捞取对应记录。
- **流程自动化**：ETL / 思维 / 屏幕任务可对数据库做抽取、加工与回写。
- **系统组件**：表格类、表单类等组件能绑定数据源，呈现或录入表数据。

---

## 七、注意事项

- **物理库位于 `dbs/sqlite3_dbs/`**：库、表、列元数据在 `dbs/items.json` 与 `dbs/databaseSources.json`；结构与数据改动都会直接落盘。
- **添加数据库的类型**：默认是本地 SQLite 库，名称必填，ID 自动生成。
- **管理器以浏览与轻量编辑为主**：结构调整（建库 / 建表）走「添加数据库」，行级增删改在表格工具栏完成。
- **没有撤销**：编辑直接写盘，重要或演示数据操作前先备份。
- **演示数据用完清理**：自带的 `test_db` 等演示库仅用于体验，正式使用前建议清理，避免与工作区真实数据混淆。
- **数据源要注册才可见**：只有登记进 `databaseSources.json` 的库才会出现在管理器树中。
