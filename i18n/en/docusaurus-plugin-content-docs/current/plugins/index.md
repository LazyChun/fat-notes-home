# Overview

Popular FatNotes plugins, all in one place.

| Plugin | Description | GitHub |
| --- | --- | --- |
| [Toolbox (FatTools)](./fat-tools.md) | 100 local mini tools in 11 categories (text, encoding, dev, numbers, files...), with a three-part workbench, search shortcuts, copy/export and restorable usage history | [LazyChun/fat-tools](https://github.com/LazyChun/fat-tools) |
| [FatCharts (fat-charts)](./fat-charts.md) | Chart blocks for dashboards — trend, number, distribution, rank, honeycomb and dial — turning query results into configurable visual cards (ECharts) | Not open-sourced yet |
| [FatAiBase (fat-ai-base)](./fat-ai-base.md) | Heavy AI capabilities (chromadb vector store / PaddleOCR / OpenCV); supplies the OCR / Knowledge Base settings tabs and the Knowledge Retrieval flow node | [LazyChun/fat-ai-base](https://github.com/LazyChun/fat-ai-base) |
| [FatBrowserUse (fat-browser-use)](./fat-browser-use.md) | Browser automation (Playwright): 13 flow nodes for navigation, element interaction, data extraction and file transfer, an element selector tool, and a resident Python backend | [LazyChun/fat-browser-use](https://github.com/LazyChun/fat-browser-use) |
| [FatGames](./fat-games.md) | 31 entries (30 mini games + a leaderboard): a three-part game workbench, a shared stage and sound engine, automatic score recording, plus a dashboard Game card | [LazyChun/fat-games](https://github.com/LazyChun/fat-games) |
| [肥剪 (fat-cut)](./fat-cut.md) | A CapCut-style video editor with an asset library, multi-track timeline, preview and project saving; AI / MCP can generate an arrangement graph and lay it out on the timeline | [LazyChun/fat-cut](https://github.com/LazyChun/fat-cut) |
| [FatPhoto (fat-photo)](./fat-photo.md) | A built-in canvas image editor with multi-tab documents, layers and blend modes, brush / text / shape / crop tools, plus adjustments and history | [LazyChun/fat-photo](https://github.com/LazyChun/fat-photo) |
| IT Interview Bank (fat-it-interview) | 364 questions covering frontend / Java / backend / ops / algorithms / databases, with progress tracking | [LazyChun/fat-it-interview](https://github.com/LazyChun/fat-it-interview) |
| 肥笔 | A project-based writing workspace for long-form writing (books, columns, article series) | Not open-sourced yet |
| 3D Human Anatomy | An interactive 3D human body built from 2,234 modeled parts, with per-system filtering and layer-by-layer disassembly | [LazyChun/human-atlas-fat-notes-ext](https://github.com/LazyChun/human-atlas-fat-notes-ext) |
| FatChess | A collection of board games — Go, Gomoku, Xiangqi, Chess, Jungle (Dou Shou Qi) and Junqi (open-board) — with three play modes: vs. local AI, vs. LLM, and local two-player | [LazyChun/fat-chess](https://github.com/LazyChun/fat-chess) |
