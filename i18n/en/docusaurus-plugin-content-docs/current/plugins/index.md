# Overview

Popular FatNotes plugins, all in one place.

| Plugin | Description | GitHub |
| --- | --- | --- |
| 3D Human Anatomy | An interactive 3D human body built from 2,234 modeled parts, with per-system filtering and layer-by-layer disassembly | [LazyChun/human-atlas-fat-notes-ext](https://github.com/LazyChun/human-atlas-fat-notes-ext) |
| 肥游 | 31 built-in mini games: 2048, Tetris, Snake, Minesweeper, Gomoku... | [LazyChun/fat-games](https://github.com/LazyChun/fat-games) |
| Toolbox (fat-tools) | A collection of visual gadgets, e.g. a Tesla Model X 3D showcase with exploded-view disassembly | [LazyChun/fat-tools](https://github.com/LazyChun/fat-tools) |
| IT Interview Bank (fat-it-interview) | 364 questions covering frontend / Java / backend / ops / algorithms / databases, with progress tracking | [LazyChun/fat-it-interview](https://github.com/LazyChun/fat-it-interview) |
| 肥笔 | A project-based writing workspace for long-form writing (books, columns, article series) | Not open-sourced yet |
| [FatAiBase (fat-ai-base)](./fat-ai-base.md) | Heavy AI capabilities (chromadb vector store / PaddleOCR / OpenCV); supplies the OCR / Knowledge Base settings tabs and the Knowledge Retrieval flow node | [LazyChun/fat-ai-base](https://github.com/LazyChun/fat-ai-base) |
| 肥・浏览器控制 (fat-browser-use) | Browser automation (Playwright) | [LazyChun/fat-browser-use](https://github.com/LazyChun/fat-browser-use) |
| [FatCharts (fat-charts)](./fat-charts.md) | Chart blocks for dashboards — trend, number, distribution, rank, honeycomb and dial — turning query results into configurable visual cards (ECharts) | [LazyChun/fat-charts](https://github.com/LazyChun/fat-charts) |
| 肥剪 (fat-cut) | A CapCut-style video editor with an asset library, multi-track timeline, preview and project saving; AI / MCP can generate an arrangement graph and lay it out on the timeline | [LazyChun/fat-cut](https://github.com/LazyChun/fat-cut) |
| 肥图 (fat-photo) | A built-in canvas image editor with multi-tab documents, layers and blend modes, brush / text / shape / crop tools, plus adjustments and history | [LazyChun/fat-photo](https://github.com/LazyChun/fat-photo) |
