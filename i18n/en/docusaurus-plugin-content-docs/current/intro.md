# Welcome to FatNotes

FatNotes is a **local-first desktop knowledge workspace** for Windows. It brings notes, data dashboards, workflow automation, and an AI assistant into one professional interface—so knowledge is not just stored, but connected, analyzed, and put to work automatically.

## What can you do with FatNotes?

- **Capture knowledge**: organize notes with Markdown, rich text, tables, and PDFs. Pages are built from 60+ draggable block types you can arrange freely.
- **Understand data**: connect directly to SQLite, MySQL, PostgreSQL, and other databases, and turn query results into chart widgets—no more juggling a database client, a spreadsheet, and your notes.
- **Automate work**: orchestrate repetitive tasks with visual workflows—scheduled queries, data cleaning, API calls, screen automation. Drag, drop, and connect.
- **Retrieve intelligently**: built-in AI chat and a knowledge base (RAG) ground answers in your own notes and data instead of thin air.
- **Extend the workspace**: the plugin system adds sidebar views, custom block types, and flow nodes—or turn your own tools into plugins.
