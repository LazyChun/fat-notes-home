# Knowledge Workspace

FatNotes uses an IDE-inspired layout for serious knowledge work. Browse resources, edit content, run tools, and move between data and automation views without leaving the workspace.

## A practical structure

1. Create one workspace per project.
2. Use folders for stable categories and tags for cross-cutting topics.
3. Keep an index note with goals, important links, and current progress.
4. Separate raw source material from refined knowledge.

## Supported content

The workspace can host Markdown, rich text, tables, PDFs, and other widget types. Availability depends on the current release and installed plugins.

Once your knowledge is structured, use [data dashboards](./data-dashboard.md) to monitor metrics or [workflow automation](./flow-automation.md) to handle repetitive work.
